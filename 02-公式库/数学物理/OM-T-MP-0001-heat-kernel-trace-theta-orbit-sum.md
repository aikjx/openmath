# OM-T-MP-0001 · 一维盒的热核迹＝绕数轨道和

\[
\sum_{n\ge 1}e^{-a n^{2}}=\frac12\Big(\sqrt{\frac{\pi}{a}}\Big(1+2\sum_{n\ge 1}e^{-\pi^{2}n^{2}/a}\Big)-1\Big)\qquad
1+2\sum_{n\ge1}e^{-\tau n^{2}}\cos(nx)=\sqrt{\frac{\pi}{\tau}}\sum_{m\in\mathbb Z}e^{-(x-2\pi m)^{2}/(4\tau)}
\]

## 一、这张面在判什么，五条判定各自独立

全部读数出自 `scratch/T15_MP0001_face_final.txt`（判定 1–5，抓到红 0 条，rc=0，耗时 2.6s）；牙齿读数出自 `scratch/T15_MP0001_selftest_final.txt`（rc=0）。

**判定 1：谱侧＝轨道侧，两条生产者都是自写的逐项循环。** 谱侧 `terms_sum` 逐枚加 \(e^{-an^2}\)（不调任何 theta 库），轨道侧逐枚加像电荷 \(e^{-\pi^2n^2/a}\) 再乘 \(\sqrt{\pi/a}\)。六格横坐标 \(a\in\{1/50,\,1/4,\,1,\,\pi/7,\,25,\,400\}\)：\(a=1/50\) 现值 **5.76657068657750119**，80 位档 abs **1.684491e-93**／rel **2.921131e-94**，160 位档 abs **3.989402e-173**／rel **6.918152e-174**，放大倍数 **4.222414382e+79**；\(a=25\) rel **3.535626e-83 → 3.521956e-163**（倍数 **1.003881455e+80**）。**RESOLVED 6 格／BELOW_FLOOR 0 格**，最差相对残差 **2.1660859e-74**（格 a=400, dps=234），最小放大倍数 **8.0216375e+59**（同一格）。

**\(a=400\) 那格是本轮的裁判，不是配角。** 那里 \(|S|\sim1.9\times10^{-174}\)，而轨道侧要先算 \(\sqrt{\pi/a}(1+2\sum e^{-\pi^2n^2/a})\) 再减 1 取半——两个 \(O(1)\) 数相消。**相对残差是一种货币，不是无条件可读的数**：80 位档付不起 `rel<=1e-40`，读到的 **2.5031917e+80** 是算术的必然（旧面 `scratch/T15_MP0001_face_v2.txt` 就把它判成了红），按本格尺度定档到 234/294 位后同一格读到 abs **4.148422e-248**／rel **2.166086e-74** 与 rel **2.700304e-134**。定档规则由对象自己给出：`dps = 相消深度 + 40 + 20`，深度现量（面上每格先印一行「尺度定档」）。

**判定 2：机制侧符号归零，且恒零的针先被证明会红。** \(\int e^{-ax^2}\cos(2\pi kx)\,dx=\sqrt{\pi/a}e^{-\pi^2k^2/a}\) 在 \((a,k)\) 五格上由 sympy 积分通道返回**形状 `Zero`**、残差 **0.0**（不是小数近似，是符号归约）。五格全绿不算证据，所以同格造两枚错：指数少一次 \(\pi\) ⇒ 偏离 **3.289082e-01**，prefactor 写成 \(a\) ⇒ **2.640634e-01**（对照格取 \(a=4,k=1\)；旧稿在 \((1,2)\) 取对照，那里两个候选都是 \(e^{-39}\) 量级、偏离只有 5.5e-18，是「看不见」而不是「没错」）。

**判定 3：物理参数化是代数重排的复算，不当第二台生产者。** \(a=\beta\pi^2\hbar^2/(2mL^2)\) 代回后 \(\sqrt{\pi/a}\to L\sqrt{2m/(\pi\beta\hbar^2)}\)，三点残差 **4.687033e-163／2.558639e-165／1.887805e-162**；丢掉那枚 `sqrt` 的排布给出 **8.440305e-02／4.604544e-02／1.389131e-01**——同一条尺一边判归零、一边判 \(10^{-2}\) 量级的错。

**判定 4：逐点恒等（\(x\ne0\)）＋截断可见。** 这条不是判定 1 的特例：谱侧带 \(\cos(nx)\)、像电荷侧按 \(x-2\pi m\) 展开，\(x=0\) 才退化回去。五格里 \(x=0.7,\tau=1/50\)（定档 229/289）rel **1.853350e-258 → 1.130274e-318**（倍数 **1.639732698e+60**）、\(x=2.5,\tau=3/2\) rel **1.291579e-111 → 1.607503e-171**（倍数 **8.034690221e+59**，本轮最小）。另外三格在两档之一读到**恰好 0**（\(x=1,\tau=3/10\) 的 140 位档、\(x=\pi/3,\tau=8\) 的 80 位档、\(x=\pi/7,\tau=1/4\) 的 140 位档），判语是「两条独立生产者落在同一个数上」，**不是**「针瞎了」——判瞎与否由**该档自己的地板** \(10^{-(\mathrm{dps}+28)}\) 决定，三格的第一像电荷 **2.560399028e-10／0.2660443324／5.837043155e-15** 全在 1e-168 或 1e-32 的地板之上，所以 \(\sim170\) 位的全同是强读数。**这正是旧面的三枚假阳**：`face_v2` 把地板钉成常数 1e-60，于是把三格正确读数判成「看不见它该看见的东西」；改口径后牙齿面用五格对照证明这把尺随档位翻判决（\(10^{-40}\) 在 dps=4 档判瞎=True、同一条 \(10^{-20}\) 在该档判 False、\(2.56e\text{-}10\) 在两档都 False）。反对照：高斯宽度 \(4\tau\) 写成 \(\tau\) ⇒ 偏离 **2.741614e-02**，丢掉前因子 \(\sqrt{\pi/\tau}\) ⇒ **2.522864e-02**。截断侧（4b）三格差 **6.938894e-18／1.081038e-02／3.692259e-01**，\(a=25\) 的尾巴序列 **0.083889712 > 0.010810379 > 1.8575206e-5 > 4.5939386e-15** 单调收缩——轨道侧那几项是真实绕数扇区，不是拟合出来的常数；\(a=1/50\) 那格 \(c\sim10^{-214}\)，截与不截同值，选择判据印在面上而不是藏在代码里。

**判定 5：Weyl 主项的先验界是不等式，且必须按界的量级定档。** \(|S(a)-\tfrac12(\sqrt{\pi/a}-1)|\le \sqrt{\pi/a}\,e^{-c}/(1-e^{-c})\)，\(c=\pi^2/a\)。这条界的量级就是 \(e^{-c}\)，所以求值位数由 \(c\) 现定（\(a=1/50\)：275 位）。牙齿面 G2 把「为什么要定档」做成对照：**50 位读数 4.661009e-81 越界=True**（一条真的不等式被低位读数判成反例），**275 位读数 6.057919e-214 越界=False**，与界 **6.057919e-214** 咬合比 **1.000000e+00**——界被咬住而不是被绕开。其余格：\(a=1\) **9.167696e-05 / 9.168170e-05**（比 0.999948）、\(a=4\) 比 0.915753、\(a=25\) 比 0.440728、\(a=400\) 比 0.128449（后两格面上明写「偏松：界成立但没被咬住」）。前导项比值只在 \(a\le1/50\) 断言（\(a=1/50\) 与 \(a=10^{-4}\) 都是比值 **1.0**、主项 **5.766571e+00**／**8.812269e+01**）；\(a\) 大时 \(\tfrac12(\sqrt{\pi/a}-1)<0\)，前导项读法出定义域。

## 二、通用引擎：一条残差、两个档位、一处口径发现

`python -m openmath verify --id OM-T-MP-0001`（面 `scratch/T15_VERIFY_MP0001.txt`）：

```
A. 不带 --precision（CLI 默认档 50）：  L2 PASS   最大绝对残差 3.229e-100（容差 1e-40，已求值 2/2）
B. 带 --precision 80（记录声明档）：     L2 PASS   最大绝对残差 4.789e-161（容差 1e-40，已求值 2/2）
```

**口径发现（登记为债，不在本卡修）**：记录的 `verification.levels.L2.precision_digits` 声明 80，但 `verify` 子命令的 `--precision` 有自己的默认值 50 并**覆盖**记录声明——不带该旗标时，面上印的「50 位精度」不是本卡声明的那一档。本卡以 **B 行（80 位）** 作读数载体。附带好处：A→B 就是同一条表达式在两个档位上的重跑，残差 **3.229e-100 → 4.789e-161** 随之收缩，与判定 1 的定档逻辑同向。**B 行的 4.789e-161 与铸卡前的字段可用性预演（`scratch/_t15_theta_probe4.py`，按引擎口径 float 代入＋`sp.N`）同值**——两条独立生产者比同一条表达式，不是同一份代码跑两遍。

机器读数要求每枚采样点钉满 `a, b, c, k, k2, m, L, hbar, bt` 九个自由符号，少钉一个整条判 `UNKNOWN`（机制同第 13 批，已写进 yaml 的 `assumptions`）。符号名 `bt` 不是笔误：`beta` 在 sympy 里是全局贝塔函数 `FunctionClass`，当符号代入会让 `sympify` 崩。

## 四、诚实边界与红线

- 红线一：以上 PASS 只覆盖脚本点名的横坐标、采样点与通道，**不证明**任何一条恒等式，也不构成对开放问题的进展；\(\vartheta\) 模变换、Poisson 求和与 Weyl 律的定理地位来自文献，不由本面授予。
- 红线八：`fact_check.status` 停在 **UNVERIFIED**——Jacobi 虚数变换、Poisson 1827、热核迹谱几何表述本轮都未经目录/DOI/页码逐条核对；`proposed_year: 1827` 是形态标签不是核对结果。
- L3 不登记：一般陈述需要 Poisson 求和的收敛条件与 Fourier 反演假设，本库未做成判据；判定 2 的符号归零出自 sympy 规则集，不等于对一般 \((a,k)\) 的证明。
- L4 不填：未核对 mathlib/Lean 里 \(\vartheta\) 模变换／热核迹的绑定名。
- 已知留白：本卡是**周期轨／圆**上的迹（谱为 \(n^2\)），不是 Dirichlet 盒（谱为 \(n\)）——标题里的「一维盒」指的是物理参数化下 \(\beta\pi^2\hbar^2/(2mL^2)\) 那个盒，谱侧 \(n\ge1\) 逐项求和承担的是圆上绕数；高维盒（乘积形式）、带势情形、\(a\le0\) 均无读数。相依情形在此不出现（这里是求和指标而非观测）。
- 仪器债（本轮登记、未修）：`verify` 的 `--precision` 默认值覆盖记录声明档位（见第二节）；`_镜像/` 未动；本卡落盘后 `graph`/`index` 的域覆盖与记录数一律现读，本卡不复制。
