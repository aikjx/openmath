# OM-F-NT-0003 · 区间素数计数的 Legendre 窗口恒等式（方块窗口）

\[
c(n):=\#\{p\ \text{素数}:\ n^2<p\le (n+1)^2\}=\pi\big((n+1)^2\big)-\pi\big(n^2\big)
\]

\[
c(n)=\phi\big((n+1)^2,\ a\big)-\phi\big(n^2,\ a\big),\qquad a=\pi(n+1),\qquad n\ge 2
\]

## 一、陈述

把相邻两个完全平方数之间的区间 \((n^2,(n+1)^2]\) 称为**方块窗口**，
其长度恰为 \(2n+1\approx 2\sqrt{x}\)（\(x=n^2\)）。第一式只是 \(\pi\) 的差分，
是定义式重述，**不携带任何素数分布信息**。

本条目的实质内容是第二式：窗口计数可以写成两个 Legendre \(\phi\) 值之差，
而 \(\phi\) 的每一个递归节点代表**一整块** \(\lfloor x/p\rfloor\) 个整数
（见 OM-F-NT-0001）。于是"数一数这个窗口里有几个素数"这件事，
无需对窗口内 \(2n+1\) 个数逐个判素。

## 二、第二式为什么成立

取 \(a=\pi(n+1)\)，即筛掉所有 \(\le n+1\) 的素数。此时：

- 若 \(m\le (n+1)^2\) 为合数，则 \(m\) 必有素因子 \(\le\sqrt{m}\le n+1\)，会被筛掉；
- 故 \((n^2,(n+1)^2]\) 中**未被筛掉的整数**只能是素数；
- 反之，若 \(p\) 是窗口内的素数且 \(n\ge 2\)，则 \(p>n^2\ge n+1\)，不会被筛掉。

因此两族整数完全一致，\(\phi\) 之差精确等于 \(c(n)\)。

**例外 \(n=1\)**：窗口 \((1,4]\) 含素数 \(2=n+1\)，它会被 \(a=\pi(2)=1\) 筛掉，
故 \(\phi(4,1)-\phi(1,1)=1\ne c(1)=2\)。本条目显式把第二式限制在 \(n\ge 2\)。

## 三、例外为什么**恰好**是 n=1（符号层）

第二式要求窗口内的每个素数都 \(>n+1\)（否则会被 \(a=\pi(n+1)\) 筛掉），即要求

\[
p>n^2\ \ge\ n+1\quad\Longleftrightarrow\quad n^2-n-1\ \ge\ 0
\]

用 sympy 在整数域上解这条不等式：

```
solveset(n**2 - n - 1 >= 0, n, Integers)
  = Union(Range(-oo, 0, 1), Range(2, oo, 1))
```

与 \(n\ge1\) 求交得 \(n\in\{2,3,4,\dots\}\)。

> 所以**例外集合恰为 \(\{1\}\)**，这不是从枚举里"看出来的"，而是解集的直接推论：
> 两个根是 \(\frac{1\pm\sqrt5}{2}\)，负根落在非正整数区，正根 \(\approx1.618\) 与正整数集的交从 \(2\) 开始。

第二步（合数必带 \(\le n+1\) 的素因子）是纯初等的：若 \(m\le(n+1)^2\) 为合数，写作 \(m=ab\ (1<a\le b)\)，
则 \(a\le\sqrt m\le n+1\)。引擎对该依赖链做了穷举核实：\(n=2..120\) 全窗口内每个合数做 `factorint`，
最小素因子均 \(\le n+1\)，无反例。

## 五、失效模式

1. **第一式不可当成果用**：\(\pi\) 的差分在 \(n\) 很大时无法直接求值，
   除非先解决 \(\pi(x)\) 的计算，而那正是 Legendre/Meissel/Lehmer 的主题。
2. **第二式的代价随 \(n\) 增长**：\(a=\pi(n+1)\) 增大时 \(\phi\) 递归节点数上升，
   比逐个判素快，但**不是**免费。
3. **对本条目的唯一正确使用**：作为 OM-P-NT-0003（Legendre 猜想）的**等价重述**——
   "Legendre 猜想成立"\(\iff\)"对所有 \(n\ge 1\)，\(c(n)\ge 1\)"。
   本条目**不**对该断言提供任何证据。

## 六、先验归属（红线七）

Legendre 的 \(\phi\) 属于 **Legendre（1808）**；\(\pi(x)-\pi(y)\) 计数区间素数属于常识。
本条目的新增内容**仅有**：把方块窗口的计数还原为 \(\phi\) 差分并给出 \(n=1\) 例外的精确定位，
以及逐点一致的实测证据。**不构成任何优先权主张。**
