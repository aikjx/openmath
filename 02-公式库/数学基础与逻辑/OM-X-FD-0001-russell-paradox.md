# OM-X-FD-0001 · 罗素悖论（朴素概括原则的反例）

\[ \mathcal{R} = \{x : x \notin x\},\qquad \mathcal{R} \in \mathcal{R} \leftrightarrow \mathcal{R} \notin \mathcal{R} \]

## 一、要点

把 φ(x) 取为 x ∉ x，概括原则给出 R，然后对 R 是否自属两问各推一次即得双向矛盾。这不是「技术上的小漏洞」：朴素集合论在任何模型里都不存在，因为矛盾在系统内部被推导出来，而不是被外部语义发现。两条出口各自付价——Zermelo 的分离公理把「性质成集」降级为「已给定集合的子集成集」，代价是全集不再自动存在；Russell 的类型分层把 ∈ 限制在同层之间，代价是自然数这类跨层的对象需要重编码。本库把两条出口都留作后续记录，不在本卡替它们裁决。
