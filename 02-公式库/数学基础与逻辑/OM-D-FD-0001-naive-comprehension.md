# OM-D-FD-0001 · 朴素概括原则

\[ \forall x\,\bigl(x \in \{y : \varphi(y)\} \leftrightarrow \varphi(x)\bigr) \]

## 一、要点

弗雷格《算术基本规律》第五律的原形：任何性质都确定一个集合。它是朴素集合论的发动机——自然数序列、函数外延、基数比较都由它一步生成，也正是它的无限制形态使罗素取 φ(x) 为 x ∉ x 就能在系统内造出矛盾。本条之所以值得单独立卡，是因为「后来公理被修好了」这句话把这一步的历史代价抹掉了：损失的不是一个技巧，而是「任何性质都成集」这一整条原则。

## 二、前提

- φ 是任意带一个自由变量的性质（不受任何层或分离条件约束）
- 默认约定：语言为一阶逻辑加属于关系 ∈
- 默认约定：未对可形成的集合作任何限制
