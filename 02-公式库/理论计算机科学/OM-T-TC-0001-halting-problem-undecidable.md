# OM-T-TC-0001 · 停机问题不可判定

\[ \nexists e\ \forall x\ \bigl(\varphi_e(x) \downarrow\ 0 \leftrightarrow \neg \varphi_x(x) \downarrow\ 0\bigr) \]

## 一、要点

对角线证明三行：若判定器存在，其索引 e 在枚举里，取输入 e 自身即得「它在自己身上说停机 ⟺ 它在自己身上不停机」。本卡要防的读法是把它当成「机器不能做到的事」的清单来源：它说的是**没有一个统一的程序**能判定全体程序的停机，而单个具体程序是否停机完全可能有专门的判定办法（甚至事实上可由人验证）。同理，它不蕴含「物理世界可计算」这一类论题——那是把论题当成了定理。

## 二、前提

- φ 是部分递归函数的标准枚举
- ↓0 表示停机且输出 0
- 默认约定： Church-Turing 论题（把「可有效计算」等同于部分递归）
