# OM-F-AN-0001 · 欧拉恒等式

\[
e^{i\pi} + 1 = 0
\]

## 一、陈述

**欧拉恒等式**把五个最基本的数学常数联系在一个等式中：

| 常数 | 含义 | 来源 |
| --- | --- | --- |
| \(0\) | 加法单位元 | 算术 |
| \(1\) | 乘法单位元 | 算术 |
| \(e\) | 自然对数底 | 分析 |
| \(i\) | 虚数单位 | 代数 |
| \(\pi\) | 圆周率 | 几何 |

它常被称为"数学中最美的公式"。**本库对此类美学评价不做收录**，只记录数学内容与验证状态。

## 二、一般形式

欧拉恒等式是**欧拉公式**在 \(\theta = \pi\) 时的特例：

\[
e^{i\theta} = \cos\theta + i\sin\theta
\]

其来源是把复指数函数定义为幂级数

\[
\exp z = \sum_{n=0}^{\infty}\frac{z^n}{n!}
\]

代入 \(z = i\theta\) 后，按实部与虚部分离级数，恰好得到 \(\cos\theta\) 与 \(\sin\theta\) 的 Taylor 级数。

## 三、为什么 \(\theta = \pi\) 特别

代入 \(\theta = \pi\)：

\[
e^{i\pi} = \cos\pi + i\sin\pi = -1 + 0i = -1
\]

即 \(e^{i\pi} + 1 = 0\)。

## 五、已知陷阱（`caveat`）

1. **分支约定**：复指数 \(e^{z}\) 是单值整函数，但复对数 \(\log z\) 是多值的。涉及 \(\log\) 的推广需显式声明分支。
2. **数值实现的"伪通过"**：用双精度计算 `exp(1j*pi) + 1` 会得到约 `1.22e-16 + 0j`，不是精确的 0。**残差的数量级必须与精度设置相匹配**（本库 L2 默认 50 位，此时残差应 ≤ 10^{-45} 量级）。
3. **"证明"的循环风险**：若把 \(e^{i\theta} = \cos\theta + i\sin\theta\) 当作定义，则恒等式是定义的推论（平凡）；若先独立定义三角函数与指数，则它是定理。**两种讲法都正确，但必须声明采用哪一种**。本记录采用幂级数定义，故为定义性推论。
