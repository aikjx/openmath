# OM-F-AN-0002 · Riemann ζ 函数函数方程

\[
\zeta(s) = 2^{s}\,\pi^{s-1}\,\sin\!\left(\frac{\pi s}{2}\right)\,\Gamma(1-s)\,\zeta(1-s)
\]

## 一、陈述

Riemann ζ 函数最初由级数定义（收敛域 \(\operatorname{Re}(s) > 1\)）：

\[
\zeta(s) = \sum_{n=1}^{\infty} \frac{1}{n^{s}}
\]

该级数在 \(\operatorname{Re}(s) \le 1\) 时发散，但 ζ 可**解析延拓**为 \(\mathbb{C}\setminus\{1\}\) 上的亚纯函数，唯一极点位于 \(s=1\)（留数为 1）。函数方程描述了延拓后函数在变换 \(s \mapsto 1-s\) 下的对称性。

## 二、对称形式（更优雅的写法）

定义 **完成 ζ 函数（completed zeta function）**：

\[
\xi(s) = \frac{1}{2}\,s(s-1)\,\pi^{-s/2}\,\Gamma\!\left(\frac{s}{2}\right)\zeta(s)
\]

则函数方程等价于一个简洁的对称式：

\[
\xi(s) = \xi(1-s)
\]

这一形式把"临界线" \(\operatorname{Re}(s) = \tfrac12\) 凸显为变换 \(s \mapsto 1-s\) 的不动轴——这正是**黎曼假设**所断言的零点所在位置。

## 三、为什么这个方程重要

1. **零点对称性**：若 \(s\) 是零点，则 \(1-s\) 也是零点。故非平凡零点关于临界线对称分布。
2. **平凡零点**：\(s = -2, -4, -6, \dots\)（由 \(\sin(\pi s/2)\) 的零点给出）。
3. **临界带**：所有非平凡零点位于 \(0 < \operatorname{Re}(s) < 1\)（由 Euler 乘积与函数方程共同推出）。
4. **黎曼假设的表述基础**：RH 断言非平凡零点的实部**恰好**为 1/2。

## 五、数值验证的关键陷阱（本条目的核心价值）

### 陷阱 1：不能用级数直接计算

在 \(\operatorname{Re}(s) < 1\) 时，\(\sum n^{-s}\) **发散**。任何"用前 N 项求和验证函数方程"的尝试都是无效的。

正确做法：使用实现了解析延拓的库（mpmath 的 `zeta`、SymPy 的 `zeta` 在部分区域）。

### 陷阱 2：平凡零点是无效检验点

在 \(s = -2, -4, \dots\) 处，等式两边**同时为零**，残差恒为 0，无论实现是否正确。

正确做法：选取**非平凡**检验点，例如第一个非平凡零点 \(s \approx 0.5 + 14.134725i\)，或随机点 \(s = 0.3 + 7.2i\)。

### 陷阱 3：\(0 \times \infty\) 型数值不稳定

在 \(s\) 接近正整数时，\(\Gamma(1-s)\) 发散而 \(\sin(\pi s/2)\) 趋于 0，二者相乘有限。低精度下会灾难性抵消。

正确做法：≥ 50 位有效数字（本库 L2 默认）。

### 陷阱 4：分支与约定

\(\pi^{s-1}\) 与 \(\Gamma\) 均为多值/需分支选择的函数。不同实现的约定差异会导致"看似正确实则错误"的结果。
