# 99-沙箱

> **自由探索区。不进质量门禁，不计入统计，不做评审要求。**

## 一、沙箱存在的理由

一个只有严格规则的社区会**扼杀早期想法**。数学中的新想法在最初往往：

- 表述模糊
- 缺少证据
- 甚至可能是错的

如果这些都直接提交到正式目录，要么被拒绝（打击积极性），要么被迫过早精确化（扼杀创意）。

**沙箱是解决这个问题的阀门。**

## 二、规则（很少，但有）

| 规则 | 说明 |
| --- | --- |
| **不进质量门禁** | CI 不检查本目录 |
| **不计入统计** | 看板不统计沙箱条目 |
| **不得被正式条目引用** | 沙箱内容不可作为证据（未验证） |
| **必须标注为草稿** | 文件名或标题中含 `DRAFT` |
| **禁止恶意内容** | 行为准则仍然适用 |
| **保留期** | 12 个月无更新 → 移入 `12-归档/` |

## 三、什么放这里

| 适合 | 不适合 |
| --- | --- |
| 模糊的初步想法 | 已有明确表述的内容（应进正式目录） |
| 大胆的猜想（无证据） | 已知错误的断言（应进反例库） |
| 探索性的纲领草案 | 已完成的工作 |
| "我不确定这是否是已知的" | 可核查的标准内容 |
| 与主线无关的有趣观察 | |

## 四、从沙箱到正式目录

```
沙箱草稿
   │
   ├─ 表述精确化（写出全部假设）
   ├─ 查重（是否已被研究过）
   ├─ 找到证据（至少 L2）
   ├─ 填写完整 schema
   └─ 提交为正式条目（原沙箱文件标注"已毕业"并链接新条目）
```

**毕业标准**：能通过 `openmath lint`，且至少达到 L1。

## 五、特别提醒：AI 生成内容

AI 生成的**未经验证**的数学内容**必须**放这里，而不是正式目录。

原因：[红线五](../00-宪章/02-诚实红线.md)——AI 生成的内容不能单独作为证据，未经 L2/L3 验证不得进入正式目录。

**沙箱是 AI 实验的合法场所**，只要标注清楚。
