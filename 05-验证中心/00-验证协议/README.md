# 00-验证协议

> 每一层的**精确判定标准**。本文件是引擎实现者的规范文档。

## 通用约定

### 结果状态

| 状态 | 含义 |
| --- | --- |
| `PASS` | 该层级**未发现**问题（注意：不是"证明正确"） |
| `FAIL` | 发现问题（反例/类型错误/编译失败） |
| `SKIP` | 依赖缺失或条件不满足，**明确不参与** |
| `ERROR` | 引擎自身出错（不算验证结论，需修引擎） |
| `UNKNOWN` | 无法确定（如不可判定问题） |

**禁止**：把 `SKIP` 计为 `PASS`；把 `ERROR` 静默吞掉。

### 结果对象结构

```yaml
result:
  target_id: OM-F-AN-0002
  level: L2
  status: PASS
  engine: {name: mpmath, version: "1.3.0"}
  environment:
    python: "3.11.4"
    platform: "win32"
    precision_digits: 50
    seed: 20260910
  metrics:
    sample_count: 20
    max_abs_residual: "1.0e-45"
    max_rel_residual: "2.1e-46"
  artifacts:
    - "05-验证中心/03-结果/2026/09/OM-F-AN-0002-L2-20260910.json"
  timestamp: "2026-09-10T12:00:00Z"
  duration_ms: 1234
```

## L0 · 结构合规

**输入**：记录文件（`.yaml`）
**输出**：错误清单
**依赖**：无（纯标准库）

**检查项**（详见 [schema](../../02-公式库/schema/记录schema.md) 第七节）：

1. 文件可解析
2. `id` 与文件名一致
3. `id` 全局唯一
4. 必填字段齐全
5. 枚举值合法
6. `status: VERIFIED` 必须带级别
7. `assumptions` 字段存在
8. `verification.script` 路径存在
9. 引用 ID 可解析
10. AI 生成不违反 L4 规则
11. 不引用 `UNVERIFIED` 条目作 L3+ 证据
12. 中文字段非空

**判定**：12 项全过 = `PASS`，任一失败 = `FAIL`。

---

## L1 · 良构性

**检查项**：

| 项 | 说明 |
| --- | --- |
| 符号表完整性 | `latex` 中出现的每个符号都在 `symbols` 声明 |
| 类型一致性 | 同一符号在全文类型一致 |
| 自由/绑定变量 | 无变量捕获、无重复绑定 |
| 定义域非空 | 不出现空集上的量化、不出现 1/0（未说明） |
| 量纲一致性 | （物理/几何条目）量纲可约 |
| 可解析性 | LaTeX → 内部表示转换成功 |

**注意**：L1 **不判断**数学正确性，只判断"这句话是否有意义"。

---

## L2 · 数值验证

**强制参数**：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `precision_digits` | 50 | mpmath 有效数字位数 |
| `sample_count` | ≥ 1000 | 随机采样数 |
| `seed` | 必填 | 随机种子 |
| `include_boundaries` | true | 是否含边界值 |
| `include_extremes` | true | 是否含极端值 |

**必须报告**：

- 绝对残差与相对残差的**最大值、中位数、p99**
- **条件数**（若适用）
- 失败样例的完整取值（若 FAIL）

**判定**：

- 所有样例残差 < 容差 → `PASS`
- 任一反例 → `FAIL`（**并立即把条目标为 `FALSIFIED` 候选**）

**容差设定规则**：容差必须**预先**声明，且应与精度匹配（50 位精度则残差应 ≤ 10^{-40} 量级）。**事后放宽容差以通过 = 红线四**。

**核心纪律**：L2 `PASS` **永不**升级条目的"证明性"状态。它只说明"在这些点上没出问题"。

## L3 · 符号验证

**检查项**：

| 类型 | 方法 |
| --- | --- |
| 恒等式 | `simplify(lhs - rhs) == 0`（需显式声明假设） |
| 极限/级数 | 符号求值 + 与 L2 数值交叉 |
| 微分方程 | 残差代入后符号归零 |
| 积分 | 闭式求解 + 数值交叉 |
| 量纲 | 量纲向量相等 |

**交叉要求**：至少满足其一：

- (a) 两个独立引擎一致（如 SymPy + SageMath）
- (b) 单引擎符号结果 + 高精度数值确认（≥ 20 个采样点）

**已知风险**（必须记入 `caveat`）：

- SymPy 的假设传播：未声明 `positive=True` 等会导致错误化简
- 分支切割：复函数主值选择
- 特殊函数的定义差异：不同库对同一函数的规范化可能不同

## L4 · 形式化

**要求**：

| 项 | 说明 |
| --- | --- |
| 构建成功 | `lake build` / `coq_makefile && make` / `isabelle build -D .` |
| 无未授权公理 | 无 `sorry` / `admit`；`axiom` 必须在白名单 |
| 依赖锁定 | mathlib commit / AFP 版本固定 |
| 公理声明 | 显式列出所用公理（LEM、AC、单价、大基数…） |
| 可复现构建 | 提供 `nix` / Docker / 锁定的 lake-manifest |

**判定**：全部满足 = `PASS`（**此时才允许使用"已证明"**）。

**白名单公理示例**（依项目而定）：经典逻辑（排中律）、选择公理、商类型、泛函外延性、命题外延性。

---

## L5 · 对抗性验证

**五项攻击，至少通过三项**：

1. **反例搜索**：SAT/SMT/穷举/随机搜索（记录搜索空间与上界）
2. **多证明交叉**：≥ 2 条**方法上独立**的证明路径
3. **退化测试**：空集、零维、平凡群、零测度等边界
4. **文献一致性**：与权威文献一致，或明确标注分歧
5. **专家复核**：≥ 2 名不同机构的人类专家独立复核

**关键**：未找到反例时记录**搜索上界**，**不升级证据等级**。

## 失败处理流程

```
发现 FAIL
    │
    ├─ 是反例？─── 是 ──> 条目 status := FALSIFIED（终态，保留）
    │                      记录 counterexample{value, method, discoverer, date}
    │
    ├─ 是假设缺失？──> 退回补充 assumptions
    │
    ├─ 是引擎 bug？──> 报 ERROR，修引擎，重跑
    │
    └─ 是依赖缺失？──> 标 SKIP，记录原因
```

**绝不**：修改断言、放宽容差、删除样例、吞异常。
