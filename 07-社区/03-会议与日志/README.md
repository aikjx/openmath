# 03-会议与日志

> **决策必须落到仓库里。** 群里说的、会上说的，不写进本目录就不算数。

## 一、为什么

知识库项目最大的风险是**决策蒸发**：讨论发生了，结论消失了，半年后没人记得为什么这么做。

本目录是**唯一**的正式决策记录处。

## 二、文件命名

```
YYYY-MM-DD-<类型>-<简述>.md
```

类型：`meeting`（会议）、`decision`（决策）、`dispute`（争议裁决）、`quarterly`（季度报告）、`incident`（事件）

示例：

```
2026-09-10-decision-采用L4无sorry政策.md
2026-Q4-quarterly-季度报告.md
```
