# 04-翻译

> **中文为源语言，英文为第一翻译层。**

## 一、语言层级

```
        中文（源语言 · 权威）
              │
              ├──> 英文（第一翻译层）
              │
              └──> 其他语言（按需）
```

**权威规则**：

- 中英冲突时，以**中文**为准（除非能证明中文有误）
- 这是为了保证**单一真相源**，避免多语言版本各自漂移

## 二、翻译优先级

| 优先级 | 内容 | 理由 |
| --- | --- | --- |
| 1 | 宪章与红线 | 所有人必读 |
| 2 | README 与各目录 README | 导航 |
| 3 | 难题条目 | 关注度最高 |
| 4 | 公式条目 | 数量大，按需 |
| 5 | 其他 | 渐近 |

## 三、翻译规则

### 3.1 必须翻译

- 叙述性文本
- 标题与说明
- 术语（按[术语表](../../00-宪章/05-中英术语对照表.md)）

### 3.2 **禁止**翻译

| 对象 | 原因 |
| --- | --- |
| 字段名（`id`、`status`、`evidence_level`） | 机器可读性 |
| 枚举值（`VERIFIED(L3)`、`OPEN`、`FALSIFIED`） | 跨语言一致性 |
| 状态括号中的层级（`L0`–`L6`） | 同上 |
| 代码标识符、函数名 | 技术正确性 |
| 文件路径 | 可运行性 |
| 人名（可括注中译） | 可检索性 |
| 数学符号与公式 | 通用性 |

**最常见的错误**：把 `status: VERIFIED(L3)` 翻译成 `状态：已验证（L3）` 并写进 YAML 文件。**字段名与枚举值永不翻译。**

### 3.3 术语统一

翻译前**必须**查 [00-宪章/05-中英术语对照表](../../00-宪章/05-中英术语对照表.md)：

- 表中已有的 → 用表中的译法
- 表中没有的 → 翻译后**补充到表中**（这是一项贡献）

**有歧义的术语必须登记**并注明本库采用哪种译法。

## 四、数学术语翻译的特殊风险

| 风险 | 例子 |
| --- | --- |
| **同一英文词多义** | `field`（域/场）、`distribution`（分布/广义函数）、`consistency`（一致性/相合性） |
| **两岸译法差异** | prime：素数/质数；topology：拓扑学/拓朴学 |
| **历史译法过时** | 旧译"拓扑斯/拓扑空间"混用 |
| **音译不统一** | Kähler：凯勒/卡勒 |

**处理原则**：

1. 查术语表
2. 无对应时，采用**使用频次最高的权威中文教材译法**
3. 术语争议**不投票**，按上述标准裁定
4. 首次出现时括注英文原名

## 五、翻译的质量要求

| 要求 | 说明 |
| --- | --- |
| **不增删内容** | 翻译不是改写 |
| **不"优化"数学陈述** | 数学表述的改动必须由领域评审者批准 |
| **标注译者与日期** | 便于追溯 |
| **标注 AI 参与** | `provenance.ai_assisted: true` |

**高风险**：AI 翻译数学内容时容易出现**术语不一致**（同一术语多种译法）与**强度改变**（把"猜想"译成"定理"）。因此 AI 翻译**必须人工核对术语一致性**。

## 六、文件组织

| 方案 | 说明 | 本库采用 |
| --- | --- | --- |
| 目录分层（`en/`、`zh/`） | 清晰但易不同步 | ❌ |
| 文件名后缀（`.en.md`） | 并置，易比对 | ✅ |
| 单文件双语 | 冗长 | ❌ |

**采用后缀方案**：`README.md`（中文）与 `README.en.md`（英文）并置，便于比对与同步检查。
