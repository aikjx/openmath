# 05-行为准则（社区补充）

> 根目录的 [CODE_OF_CONDUCT.md](../../CODE_OF_CONDUCT.md) 是正式版。本文件补充**社区日常**层面的规范。

## 一、提问的方式

| 好的提问 | 不好的提问 |
| --- | --- |
| "这个定理的第三步，为什么可以交换极限与积分？" | "看不懂" |
| "我算出来 X，但记录说 Y，是我哪里错了？" | "这条记录是错的" |
| "有没有人知道这个结果的原始出处？" | "求文献" |

**要求**：提问时说明**你已经做了什么尝试**。这既是对他人时间的尊重，也常常能让你自己先找到答案。

## 二、回答的方式

| 好的回答 | 不好的回答 |
| --- | --- |
| "这一步需要一致收敛，见 [定理链接]" | "这显然需要一致收敛" |
| "我认为这里有漏洞：第三步……，建议改为……" | "这是错的" |
| "我不确定，但可能是……" | （编造一个确定的答案） |

**核心**：

1. 指出问题**同时**给出依据或替代方案
2. **不确定就说不确定** —— 这在数学社区是优点，不是缺点
3. 批评针对论证，不针对人

## 三、处理分歧

```
1. 先确认是"事实分歧"还是"术语分歧"
   └─ 术语分歧 → 查[术语表](../../00-宪章/05-中英术语对照表.md)，或提交术语 Issue
2. 事实分歧 → 各自列出证据与证据等级
3. 按[证据等级标准](../../00-宪章/03-证据等级标准.md)判定
4. 无法判定 → 标 DISPUTED，等待新证据
```

**记住**：**"我们暂时无法判定"是合法且体面的结局。**

## 四、"我不懂"的价值

在本社区，说"我不懂"是**受欢迎的**，因为：

- 它常常暴露出表述不清的地方
- 它给他人提供了解释的机会（解释是最好的学习）
- 它比假装懂要诚实得多

我们明确反对任何形式的"这都不会？"式反问。

## 五、对 AI 协作者的态度

| 做法 | 评价 |
| --- | --- |
| 用 AI 生成初稿，自己验证后提交并标注 | ✅ 推荐 |
| 用 AI 生成初稿，未验证就提交 | ❌ 违规 |
| 因为"AI 说的"而坚持某个结论 | ❌ 违规（资历/权威不构成证据） |
| 发现 AI 的错误并报告 | ✅ 有价值的贡献 |

**AI 是工具，不是权威。它的话和任何人的话一样，需要证据。**

## 六、隐私与安全

- 不在 Issue 中张贴他人个人信息
- 不上传含密钥/凭证的文件
- 举报行为准则违规时可要求保密

## 七、执行

违规行为的处理由治理组执行，分四级：提醒 → 限制提交范围 → 暂停评审权 → 移出项目。

**处理记录**写入 `03-会议与日志/`（涉隐私事件只记录处理结果，不记录细节）。
