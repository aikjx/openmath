# 07-社区

> **默认中文的全球化社区。**
> 中文是源语言，英文是第一翻译层，其他语言按需扩展。

## 一、为什么默认中文

1. **降低参与门槛**：中文母语者是世界上最大的单一语言群体之一，但数学内容的中文高质量资源相对稀缺
2. **术语需要建设**：现代数学术语的中译**尚未完全统一**（见 [术语表](../00-宪章/05-中英术语对照表.md)），一个活跃的中文社区能推动术语规范化
3. **不是排外**：英文内容同等欢迎，翻译组负责双向流通

**明确立场**：默认中文是**降低门槛**的措施，不是**设限**的措施。所有英文投稿同等接受。

## 二、语言政策

| 场景 | 语言 |
| --- | --- |
| 记录文件的 `title_zh` | 中文（必填） |
| 记录文件的 `title_en` | 英文（必填） |
| 记录正文（`.md`） | 中文优先 |
| 代码、字段名、枚举值 | **英文，不翻译** |
| Issue / PR 描述 | 中文或英文均可 |
| 会议记录 | 中文（附英文摘要） |
| 对外公告 | 中英双语 |

**关键**：**机器字段永不翻译**。这样工具链可以跨语言工作，也让不同语言的使用者能共享同一套索引。

## 五、沟通渠道

| 渠道 | 用途 |
| --- | --- |
| GitHub Issues | 问题、争议、提案 |
| GitHub Discussions | 开放讨论、想法 |
| Pull Requests | 内容与技术变更 |
| 本目录的 `03-会议与日志/` | 正式决策记录 |
| （待定）即时通讯 | 日常交流 |

**原则**：**决策必须落到仓库里**。即时通讯中的讨论不构成决策——这是知识库项目的生命线。

## 六、对新手的特别欢迎

本库对新手特别友好的原因：**数学中有大量"低门槛高价值"的工作**：

| 工作 | 门槛 | 价值 |
| --- | --- | --- |
| 录入教材中的标准定义与定理 | 低 | ★★★★ |
| 补充参考文献与 DOI | 低 | ★★★ |
| 翻译条目 | 低 | ★★★ |
| 找错别字与格式问题 | 极低 | ★★ |
| 为公式写验证脚本 | 中 | ★★★★★ |
| 建立反例库 | 中 | ★★★★★ |

**你不需要是数学家才能贡献。** 你需要的只是**诚实**——不填自己不确定的内容。
