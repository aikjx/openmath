# 00-入门

> 新人的前 30 分钟。目标：跑通一次完整的"提交 → 验证 → 看板更新"。

## 第 0 步：读红线（5 分钟）

**必读**：[00-宪章/02-诚实红线](../../00-宪章/02-诚实红线.md)

这不是形式主义。本库与其他数学项目最大的区别就在这一页。如果你不同意其中任何一条，本库可能不适合你——这没有关系。

## 第 1 步：搭环境（5 分钟）

```bash
git clone <repo>
cd openmath
pip install -e .
python -m openmath doctor
```

`doctor` 会告诉你哪些层级可用（缺 mpmath/sympy 时对应层级标 SKIP）。

## 第 2 步：逛一圈（10 分钟）

按这个顺序看：

1. [README](../../README.md) —— 全局地图
2. [01-数学体系/04-数论](../../01-数学体系/04-数论/README.md) —— 一个域的样子
3. [02-公式库/分析/OM-F-AN-0002](../../02-公式库/分析/OM-F-AN-0002-riemann-zeta-functional-equation.md) —— 一条完整条目的样子（**重点看它的"陷阱"一节**）
4. [03-难题与猜想/01-千年大奖难题/OM-P-NT-0001](../../03-难题与猜想/01-千年大奖难题/OM-P-NT-0001-riemann-hypothesis.md) —— 难题条目的样子

## 第 3 步：跑验证（5 分钟）

```bash
python -m openmath lint
python -m openmath verify --level L2
python 08-工具/examples/verify_OM-F-AN-0002.py
```

看输出中的**残差值**（不是"通过/失败"）。理解为什么我们要求输出残差。

## 第 4 步：你的第一个 PR（5 分钟+）

**推荐的第一件事**（任选其一）：

| 选项 | 难度 | 说明 |
| --- | --- | --- |
| 修正一个错别字 | 极低 | 直接改 |
| 给某条目补充 DOI/文献 | 低 | 必须是你确认过的 |
| 复制模板建立一条新公式 | 中 | 从你最熟悉的领域开始 |
| 为已有公式写验证脚本 | 中 | 价值很高 |

**提交前自检**：

```bash
python -m openmath lint      # 必须零错误
```

提交信息格式：`[域代码] 动词 + 对象`，如 `[NT] 新增 Mertens 函数上界公式`。

## 常见新手问题

### Q：我数学不好，能贡献吗？

**能。** 本库有大量低门槛工作：格式修正、文献补充、翻译、录入教材标准内容。**你需要的不是数学水平，是诚实**（不填不确定的东西）。

### Q：我发现一条条目是错的，怎么办？

1. 提交 Issue，说明错在哪（附依据）
2. 若有反例 → 条目标 `FALSIFIED`
3. 若是笔误 → 直接提 PR 修正

**不要**默默改掉——我们要保留错误被发现的痕迹。

### Q：AI 生成的内容可以提交吗？

可以，但必须：

- 标注 `provenance.ai_assisted: true`
- 通过 L2/L3 验证
- **AI 生成的内容不能作为 L4+ 的证据**

### Q：我不确定某个事实，能填吗？

**不要填。** 写 `fact_check.status: UNVERIFIED` 或留空并注明"待补充"。**留空比填错好。**

### Q：我的 PR 被拒了，是不是不适合这里？

被拒通常是因为：缺少假设、证据与等级不匹配、或格式问题。**这些都是可修的**。评审意见应该会告诉你具体原因。若没有，请追问。
