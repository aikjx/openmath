# 02-工作组

> 按**域**或按**横切任务**划分的常设小组。

## 一、两类工作组

| 类型 | 划分依据 | 例子 |
| --- | --- | --- |
| **域组** | 数学分支 | 数论组、拓扑组、分析组 |
| **横切组** | 跨越所有域的任务 | 形式化组、翻译组、工具组、反例猎犬组 |

**建议**：每人加入 **1 个域组 + 1 个横切组**。这样既有专业深度，又有跨领域交流。

## 二、横切工作组（优先级排序）

### 1. 反例猎犬组（Hound Pack）🔴 最高优先级

| 项 | 内容 |
| --- | --- |
| **任务** | 为 `OPEN` 猜想搜索反例；维护反例库 |
| **技能** | 编程、SAT/SMT、小规模穷举 |
| **产出** | 反例条目 + 搜索上界记录 |
| **为什么优先** | **这是本库当前最缺、且门槛相对低、收益最高的工作** |

### 2. 形式化组 🟠 高优先级

| 项 | 内容 |
| --- | --- |
| **任务** | 建立 Lean/Rocq/Isabelle 绑定；把条目形式化 |
| **技能** | 定理证明器、类型论 |
| **产出** | 形式化代码 + 绑定表 |
| **为什么重要** | L4 完全缺失，本库目前**没有任何"已证明"条目** |

### 3. 翻译组 🟡 中优先级

| 项 | 内容 |
| --- | --- |
| **任务** | 中英互译；术语统一 |
| **技能** | 双语 + 数学背景（**术语翻译需要专业知识**） |
| **产出** | 翻译条目 + 术语表更新 |

**注意**：数学术语翻译**不是**通用翻译。误译会造成长期危害。

### 4. 工具组 🟡 中优先级

| 项 | 内容 |
| --- | --- |
| **任务** | `openmath` CLI 开发；引擎实现；CI |
| **技能** | Python |
| **产出** | 可运行工具 |

### 5. 档案组 🟢 持续

| 项 | 内容 |
| --- | --- |
| **任务** | 条目录入、文献核查、状态追踪 |
| **技能** | 细心 + 领域知识 |
| **产出** | 条目 |

### 6. 教育组 🟢 持续

| 项 | 内容 |
| --- | --- |
| **任务** | 维护 [11-教育](../11-教育/README.md)；生成教学材料 |
| **技能** | 教学 + 数学 |
| **产出** | 路线图、讲义 |

## 三、域工作组

与 [01-数学体系](../01-数学体系/README.md) 的 17 个域一一对应。**域组在有人时才成立**——不为凑数设空组。

成立条件：≥ 3 名活跃贡献者 + 1 名领域负责人。

## 四、工作组运作

| 项 | 规则 |
| --- | --- |
| 会议 | 异步为主；重大事项开同步会 |
| 记录 | **必须**写入 `03-会议与日志/` |
| 决策 | 简单多数；争议升级到治理组 |
| 产出 | 进入仓库（不放群里） |

## 五、如何加入

1. 在 Issue 中留言，说明想加入的组与相关背景
2. 或者**直接开始做该组的工作**并提 PR（**更推荐**）
3. 累计 ≥3 个合并的 PR 后自动成为成员

**我们更喜欢"先做事，后加组"，而不是"先加组，再想做什么"。**
