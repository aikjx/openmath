# 04-标识与编号规范

## 一、为什么需要稳定 ID

引用一条数学知识时，"欧拉恒等式"这个说法至少指向三个不同的对象（等式本身、它的推广、它的几何解释）。**自然语言的歧义是知识工程的第一大杀手。**

因此本库的每一条记录都有**永久、唯一、不可复用**的标识符。ID 一经分配，永不改变、永不回收、永不被其他条目使用（即使原条目被 `FALSIFIED` 或 `DEPRECATED`）。

## 二、ID 格式

```
OM - <类型> - <域代码> - <4位序号>
```

示例：

| ID | 含义 |
| --- | --- |
| `OM-D-NT-0001` | 数论的第 1 条**定义** |
| `OM-F-AN-0042` | 分析的第 42 条**公式** |
| `OM-T-TG-0007` | 拓扑/几何的第 7 条**定理** |
| `OM-C-NT-0001` | 数论的第 1 条**猜想** |
| `OM-X-NT-0003` | 数论的第 3 个**反例** |
| `OM-A-CB-0114` | 组合的第 114 个**算法** |
| `OM-P-FD-0002` | 数学基础的**问题**（难题档案专用类型 P） |
| `OM-SYS-0005` | 第 5 个**统一纲领** |

### 类型码

| 码 | 全称 | 说明 |
| --- | --- | --- |
| `D` | Definition | 定义 |
| `F` | Formula | 公式 / 恒等式 / 不等式 |
| `T` | Theorem | 定理（含引理、推论、命题） |
| `C` | Conjecture | 猜想 / 开放问题 |
| `X` | Counterexample | 反例 |
| `A` | Algorithm | 算法 |
| `P` | Problem | 难题档案中的经典问题条目 |
| `SYS` | System/Programme | 统一纲领（**无域代码**，序号 4 位，全局连续） |

> 引理（Lemma）、推论（Corollary）、命题（Proposition）**不单独设码**，统一用 `T`，在记录内用 `kind` 字段区分。理由：三者的边界在文献中并不一致，额外分码只会制造无意义的编号碎片。

## 四、序号分配规则

1. 序号在每个「类型 + 域」下**单调递增**，从 `0001` 起。
2. **永不回收**：即使 `OM-F-NT-0007` 被证伪删除，下一个新条目仍是 `0008`。
3. **分配方式**：
   - 自动分配：`python -m openmath new formula --domain NT` 会扫描现有最大序号并分配下一个
   - 手动分配：编辑文件时自行填写，但 `lint` 会检查冲突
4. **预留区间**：`9001`–`9999` 保留给该域的"总览/综述"类条目。

## 五、文件命名

```
<ID>-<简短英文或拼音标识>.<扩展名>
```

- 机器可读记录：`.yaml`（如 `OM-F-NT-0001-riemann-zeta-fe.yaml`）
- 人类可读说明：`.md`（同名，如 `OM-F-NT-0001-riemann-zeta-fe.md`）
- **两者必须成对出现**，且 `md` 文件的 YAML front-matter 中 `id` 必须与文件名一致（`lint` 强制）

中文标题放在 `title` 字段与 `.md` 正文中，**不放在文件名里**（避免跨平台编码问题）。

## 六、版本与引用

### 条目版本

记录中的 `revision` 字段为整数，每次内容变更 +1。变更历史不写入记录本身（避免膨胀），交给 Git。

### 如何引用

推荐的引用格式：

```
OpenMath 联盟, 《黎曼 ζ 函数函数方程》, OM-F-AN-0002 (rev.3),
https://github.com/openmath-alliance/openmath/blob/main/02-公式库/分析/OM-F-AN-0002.md
```

**引用时必须带上 `rev` 号或访问日期**，因为条目的证据等级会随时间变化。

## 七、与其他标识系统的桥接

| 外部系统 | 字段 | 示例 |
| --- | --- | --- |
| MSC 2020 | `msc[]` | `msc: ["11M06"]` |
| OEIS | `oeis[]` | `oeis: ["A000040"]` |
| DOI | `doi[]` | `doi: ["10.1090/..."]` |
| arXiv | `arxiv[]` | `arxiv: ["math/0503435"]` |
| Lean mathlib | `formal.name` | `formal.name: "Complex.Gamma_integral"` |
| zbMATH | `zbmath` | `zbmath: "1234.56789"` |

桥接字段均为可选，但**有则必须准确**——一个错误的 DOI 比没有 DOI 更糟。
