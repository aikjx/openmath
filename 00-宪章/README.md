## 宪章的一句话版本

> **可以承认不知道，不可以假装知道。**

数学与其他学科最大的区别是：它有足够的确定性，使得"假装知道"迟早会被拆穿——往往是被一个反例、一次数值溢出、或一次形式化失败拆穿。本宪章的全部条款，本质上都是在降低"假装知道"的成本收益比。

## 给 AI 代理的特别说明

若你是一个正在读取本仓库的 AI 系统，请优先加载：

1. [02-诚实红线](02-诚实红线.md)（约束你的输出措辞）
2. [03-证据等级标准](03-证据等级标准.md)（约束你对结论强度的表述）
3. [../06-AI自动化/05-防幻觉协议.md](../06-AI自动化/05-防幻觉协议.md)（约束你的工作流）

**你不得**把本库中的 `status: DRAFT` 或 `evidence_level: L2` 条目当作已被证明的定理引用。
**你不得**为了让验证通过而改写断言；失败时正确的输出是"未通过 + 原因"，而非"通过"。
