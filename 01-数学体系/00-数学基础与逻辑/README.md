# 00-数学基础与逻辑（FD）

> MSC 2020：03（数理逻辑与基础）

## 一、本域研究什么

数学基础研究**数学推理本身**：什么是有效的证明？哪些命题可以被判定？一个理论能在自身内部证明自己的一致性吗？它还要回答一个令人不安的问题——**数学的确定性从哪里来，它的边界在哪里**。

本域是所有其他域的元层。它不研究特定对象，而研究**关于对象的陈述如何获得真值**。

## 三、核心对象

- **形式系统**（formal system）— 语言 + 公理 + 推理规则
- **一阶逻辑**（first-order logic）— 具有完备性与紧致性的核心逻辑
- **二阶逻辑**（second-order logic）— 表达力强但失去完备性
- **模型**（model）— 使一组语句为真的结构
- **可计算性**（computability）— 图灵机可计算的函数类
- **停机问题**（halting problem）— 不可判定的原型
- **哥德尔不完备定理**（Gödel's incompleteness theorems）
- **一致性强度**（consistency strength）— 理论之间的"信任排序"
- **构造性数学**（constructive mathematics）— 拒绝排中律的数学实践
- **反推数学**（reverse mathematics）— 反推定理所需的公理强度
- **Curry–Howard 对应**— 证明即程序，命题即类型
- **序数分析**（ordinal analysis）— 用序数度量理论强度

## 六、本域的验证要点

| 陷阱 | 说明 | 建议证据等级 |
| --- | --- | --- |
| **基础之争** | ZFC / 类型论 / 范畴基础 / 构造主义 各有拥护者；同一命题在不同基础下真值可能不同 | 必须声明 `foundation` 字段 |
| **"不可证明"的滥用** | 哥德尔不完备 ≠ 什么都证明不了；它只对足够强且递归可公理化的系统有效 | 独立性声明必须指明系统 |
| **排中律的隐含使用** | 大量"显然"的推理依赖 `A ∨ ¬A`；构造性框架下无效 | 构造性条目需显式声明 |
| **选择公理** | 许多"标准"结果（如每个向量空间有基）依赖 AC | 必须列在 `assumptions` |
| **一致性 vs 可靠性** | 一致的理论仍可证明假的算术语句（若 ω-不一致） | 语义论证需区分 |
| **形式化中的 `axiom`** | Lean/Coq 中新增公理会污染一致性 | L4 检查必须白名单化公理 |

## 七、为什么本域对 AI 自动化特别重要

1. **形式化验证的最终裁判**：L4 层完全建立在本域之上。
2. **幻觉的高发区**：AI 极擅长生成"听起来严谨的基础性断言"（"由哥德尔定理可知……"），而这些断言的适用条件往往被忽略。
3. **不可判定性的现实约束**：任何"全自动定理证明"方案都必须直面不可判定性，本域为 AI 流水线提供**能力边界的理论依据**——见 [06-AI自动化](../06-AI自动化/README.md)。
