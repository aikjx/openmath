# 09-计算数学与数值分析（NA）

> MSC 2020：65（数值分析）

## 一、本域研究什么

数值分析研究**如何用有限步运算逼近连续的数学对象**。它的三个核心问题与其他域截然不同：

1. **离散化误差**（截断误差）—— 方法本身的偏差
2. **舍入误差**—— 有限精度的累积
3. **稳定性**—— 误差是否被放大

Lax 等价定理给出本域的核心信条：**对于适定的线性初值问题，相容 + 稳定 ⇔ 收敛。**

## 三、核心对象

- **浮点算术与 IEEE 754** — 一切数值计算的地基
- **条件数**（condition number）— 问题本身的敏感度
- **稳定性**（前向 / 后向）— 算法的误差行为
- **插值与样条** — 函数的离散表示
- **数值积分** — Newton–Cotes、Gauss 求积、Monte Carlo
- **线性方程组** — LU、QR、SVD、共轭梯度
- **特征值算法** — QR 迭代、Krylov 方法
- **非线性方程** — Newton 法、同伦法
- **ODE 求解器** — Runge–Kutta、多步法、刚性问题
- **PDE 方法** — 有限差分 / 有限元 / 谱方法 / 有限体积
- **区间算术与验证数值** — 给出**严格**误差界
- **自适应方法** — 后验误差估计与网格自适应

## 六、本域的验证要点 —— **本域是验证方法论的供给者**

| 陷阱 | 说明 | 建议 |
| --- | --- | --- |
| **用双精度当"真理"** | 双精度 ~16 位，无法支撑 L2 的高精度要求 | L2 默认 mpmath 50 位 |
| **把迭代收敛判据当正确性** | "残差 < 1e-8" 只说明迭代停了 | 必须同时报告误差**估计** |
| **条件数未报告** | 病态问题下 15 位可能全丢 | 强制报告条件数 |
| **网格不收敛研究** | 单一网格结果无意义 | 需 ≥3 个网格的收敛阶 |
| **混沌系统的长期积分** | 指数放大使长期轨迹不可信 | 声明有效时间窗口 + 阴影引理 |
| **随机算法的种子** | 蒙特卡洛结果依赖 RNG | 记录种子、生成器、样本数 |
| **"我的机器上是这样的"** | 结果依赖 BLAS/编译器/硬件 | 记录环境指纹（见 L6） |

**本域对其他域的贡献**：`05-验证中心` 的 L2 层方法论（精度、条件数、收敛研究、环境指纹）**直接来自本域**。因此本域条目是验证中心建设者的必读内容。
