# 15-离散数学与理论计算机（TC）

> MSC 2020：68（计算机科学）、03D（可计算性与递归论）

## 一、本域研究什么

理论计算机科学研究**计算的可能与代价**：

- **可能性**：什么问题可计算？（可计算性理论）
- **代价**：需要多少时间与空间？（计算复杂性）
- **表示**：信息如何编码影响难度？（编码与结构复杂性）

本域与 [数学基础](../00-数学基础与逻辑/README.md) 有深刻重叠（可计算性同属 MSC 03D），区别在于**视角**：`FD` 关心逻辑与证明，`TC` 关心资源与效率。

## 三、核心对象

- **图灵机与可计算性** — 丘奇–图灵论题
- **停机问题与不可判定性** — 不可判定的原型
- **复杂度类** — P、NP、PSPACE、EXPTIME、BPP、BQP
- **NP 完全性与归约** — Cook–Levin 定理
- **随机算法** — BPP、Monte Carlo、Las Vegas
- **近似算法与不可近似性** — PCP 定理
- **通信复杂度** — 分布式计算的代价
- **电路复杂度** — 下界难题
- **密码学基础** — 单向函数、零知识证明
- **参数化复杂度** — FPT、W-层次
- **计算学习理论** — PAC 学习、VC 维
- **交互式证明** — IP = PSPACE、MIP = NEXP
- **去随机化与伪随机性** — 困难性与随机性的对偶
- **类型系统与程序语言语义** — Curry–Howard 对应（与 `CT` 交叉）

## 六、本域的验证要点

| 陷阱 | 说明 | 建议 |
| --- | --- | --- |
| **P/NP 的通俗误述** | "NP 就是非多项式"是错的：NP =  nondeterministic polynomial（可多项式验证） | L0 用词检查 |
| **"已证明是 NP 难的"** | 需要归约 | 引用归约来源 |
| **不可判定 vs 未解决** | 不可判定是**已证明**的结果 | 严格区分（[红线六](../../00-宪章/02-诚实红线.md)） |
| **复杂度下界** | 下界极难证明，勿把"没人找到算法"说成"已被证明下界" | 区分 |
| **平均情况 vs 最坏情况** | NP 难是最坏情况；实际输入可能易解 | 声明分析模型 |
| **丘奇–图灵论题是论题非定理** | 不可"证明" | 表述审查 |
| **AI 生成复杂度的幻觉** | 模型常生成错误的复杂度归属 | 必须引用 |

## 七、本域对 AI 自动化的特殊意义

本域为 [06-AI自动化](../06-AI自动化/README.md) 提供**能力边界的理论依据**：

- **不可判定性** ⇒ 全自动定理证明不可能完备
- **NP 完全性** ⇒ 反例搜索的规模受限
- **PCP 定理** ⇒ 概率可检验证明可行
- **交互式证明** ⇒ AI 生成的证明可通过**交互**被高效验证（而非重新阅读）

这是本库"**让 AI 生成，让机器验证**"架构的理论基础。
