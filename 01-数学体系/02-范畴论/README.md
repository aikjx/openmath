# 02-范畴论（CT）

> MSC 2020：18（范畴论与同调代数）

## 一、本域研究什么

范畴论研究**数学结构之间的关系本身**，而非结构的内部构造。核心信条是：**一个对象由它与所有其他对象的关系完全决定**（Yoneda 精神）。

它同时是：一种**语言**（现代数学的通用表述框架）、一种**基础候选**（ETCS、topos —— 见 [统一场论·范式清单](../../04-数学统一场论/01-范式清单/README.md)）、一种**组织原则**（伴随、泛性质、单子构成跨领域的统一模式）。

## 三、核心对象

- **范畴**（category）— 对象 + 态射 + 复合 + 单位元
- **函子**（functor）— 范畴间的保结构映射
- **自然变换**（natural transformation）— 函子间的态射
- **伴随**（adjunction）— "最优逼近"，数学中最普遍的模式
- **极限 / 余极限**（limit / colimit）— 泛性质的统一表述
- **Yoneda 引理** — 对象由其可表函子完全决定
- **单子**（monad）— 代数理论的范畴化；函数式编程核心
- **阿贝尔范畴**（abelian category）— 同调代数的舞台
- **导出函子** — Ext、Tor
- **拓扑斯**（topos）— 集合范畴的推广，自带内部语言
- **幺半范畴**（monoidal category）— 张量结构
- **(∞,1)-范畴** — 高阶范畴论，现代几何的基础语言

## 六、本域的验证要点

| 陷阱 | 说明 | 建议证据等级 |
| --- | --- | --- |
| **大小问题** | "所有集合的范畴"是真类，非集合；忽略会导致悖论 | L1 强制声明 universe 约定 |
| **对偶性的滥用** | 对偶成立的前提是显式对偶，不能凭"对称性"断言 | L3 需双向验证 |
| **图形追踪的正误** | 交换图看似成立但箭头方向/复合顺序错 | L4 形式化（mathlib 有丰富支持） |
| **自然性** | "自然同构"常被误用为"典范同构"；自然性需对态射验证 | L1 检查自然性条件 |
| **∞-范畴的直觉外推** | 1-范畴直觉在高阶失效（如等价与相等的关系变化） | 必须引用具体模型 |
| **形式化现状** | mathlib 的范畴论库强大，但高阶范畴支持仍在建设 | L4 前先查 mathlib 现状 |

## 七、为什么本域对"数学统一"是核心

范畴论是 [04-数学统一场论](../04-数学统一场论/README.md) 中最强的基础候选之一，原因：

1. **表达力**：几乎全部主流数学都能在范畴语言中表述
2. **结构化**：它把"结构"本身变成研究对象
3. **桥接能力**：伴随函子是跨域翻译的通用机制

但它有明确代价（见 [不可通约分析](../../04-数学统一场论/05-不可通约与冲突/README.md)）：

- **抽象税**：范畴语言的学习曲线陡峭，且有时会掩盖具体计算
- **基础循环**：定义范畴通常需要集合论或类型论作为前提
- **大小问题**始终需要外部处理（宇宙公理）
