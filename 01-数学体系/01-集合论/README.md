# 01-集合论（ST）

> MSC 2020：03E（集合论）

## 一、本域研究什么

集合论研究**无穷本身的结构与层级**：无穷是否只有一种大小？能否在 ZFC 中判定连续统的大小？无穷集合能否被良序？

它同时扮演两个角色：（1）数学的**标准基础**；（2）一个**独立的研究领域**，其核心方法（力迫法、内模型、大基数）已成为现代数学的工具箱。

## 三、核心对象

- **序数**（ordinal）— 良序序型的典范代表
- **基数**（cardinal）— 集合大小的度量；阿列夫数 ℵ_α
- **连续统假设**（CH）— 2^ℵ₀ = ℵ₁？已知独立于 ZFC
- **选择公理**（AC）— 等价于佐恩引理、良序定理
- **力迫法**（forcing）— 构造 ZFC 的扩张模型以证独立性
- **内模型**（inner model）— 构造 L、HOD 等"最小"模型
- **大基数**（large cardinal）— 不可达、可测、Woodin、超紧……
- **决定性公理**（AD）— 与 AC 冲突，给出"所有实数集都正则"的优美理论
- **马丁公理**（MA）— CH 的替代公理
- **Proper Forcing 公理**（PFA）— 强 forcing 公理，解决许多独立问题
- **可构成宇宙 L**（constructible universe）
- **基数特征**（cardinal characteristics of the continuum）

## 六、本域的验证要点

| 陷阱 | 说明 | 建议证据等级 |
| --- | --- | --- |
| **独立性被误写为"未解决"** | CH 不是"没人证出来"，而是"已证明不可判定" | 必须 `UNDECIDABLE` + `independent_of: ZFC` |
| **选择公理的隐含使用** | "每个向量空间有基""存在非测度集"均依赖 AC | 强制列 `assumptions` |
| **大基数假设的强度** | 不同大基数的一致性强度差异巨大，且大多不可证相容 | 声明 `consistency_strength` |
| **相对一致性 ≠ 绝对真理** | "Con(ZFC) → Con(ZFC+CH)" 不是说 CH 为真 | L4 必须区分 |
| **力迫构造的正确性** | 力迫扩张的验证极易出错 | L4 形式化强烈推荐 |
| **"所有集合"的说法** | 真类与集合的区别混淆会产生罗素式悖论 | L1 类型检查 |

## 七、给 AI 的特别警告

集合论是 AI 幻觉的**重灾区**，原因：

- 存在大量**反直觉但正确**的结果（Banach–Tarski、Goodstein、非测度集）
- 存在大量**看似正确但独立**的命题（CH、Suslin 假设、Whitehead 问题）
- 存在大量**依赖公理选择**而结论相反的命题（AD vs AC）

**强制要求**：本域任何条目的 `foundation` 字段必须写明确切的公理系统（如 `ZFC`、`ZF+AD`、`ZFC+CH`、`ZFC+PFA`）。缺失该字段的条目，`lint` 直接报错。
