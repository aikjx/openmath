# 14-运筹与系统科学（OR）

> MSC 2020：90B（运筹学与系统科学）、93（系统与控制理论）

## 一、本域研究什么

运筹学研究**复杂系统中资源的最优配置与调度**；系统科学研究**由大量相互作用部件组成的整体的涌现行为与控制方法**。

与 `GO` 的区别：`GO` 关注解的概念与理论，`OR` 关注**可实施的方案**；与 `DS` 的区别：`DS` 研究系统"自然演化"的长期行为，`OR` 研究如何**介入并控制**它。

## 三、核心对象

- **调度理论**（scheduling）— 单机/并行机、流水车间、NP 难性
- **排队论**（queueing）— 到达过程、服务机制、Little 定律
- **库存论** — (s, S) 策略、报童模型
- **网络流** — 最大流最小割、最小费用流
- **设施选址与车辆路径** — 组合优化的经典应用
- **可靠性理论** — 故障率、冗余
- **可控性 / 可观测性** — Kalman 判据
- **稳定性** — Lyapunov 稳定性、李雅普诺夫函数
- **反馈与最优控制** — LQR、MPC
- **随机控制与滤波** — Kalman 滤波、POMDP
- **系统辨识** — 从数据反推模型
- **复杂网络** — 小世界、无标度、传播动力学
- **多智能体系统** — 一致性协议、分布式优化

## 四、与其他域的接口

**上游**：`GO`（优化方法）、`PR`（随机过程、排队）、`DS`（稳定性理论）、`TC`（复杂度）
**下游**：`XS`（交通、能源、制造、医疗、供应链）

**交叉**：控制论 × 微分方程、复杂网络 × 图论、系统辨识 × 统计

## 六、本域的验证要点

| 陷阱 | 说明 | 建议 |
| --- | --- | --- |
| **NP 难性的表述** | "这是 NP 难的"需要归约证明 | 给出归约或引用 |
| **仿真验证的外推** | 仿真结果依赖参数设定 | 报告参数域与敏感性分析 |
| **稳态假设** | 排队公式常假设稳态 | 声明瞬态/稳态 |
| **Little 定律的条件** | L = λW 需要极弱假设，但 λ 的定义需明确 | 声明定义 |
| **稳定性证明** | Lyapunov 函数构造是充分非必要 | 区分充分/必要 |
| **模型与现实的差距** | 运筹模型是简化 | 声明模型假设与适用边界 |
