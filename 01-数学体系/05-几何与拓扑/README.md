# 05-几何与拓扑（TG）

> MSC 2020：51–58（几何、凸几何、微分几何、一般拓扑、代数拓扑、流形、整体分析）

## 一、本域研究什么

几何与拓扑研究**空间的形式、形变，以及在形变中保持不变的东西（不变量）**。

Klein 的 Erlangen 纲领给出了一个划时代的定义：**几何 = 在某变换群下不变的性质**。这一定式本身就是 [数学统一场论](../04-数学统一场论/README.md) 的早期范例：欧氏几何、仿射几何、射影几何、拓扑，由变换群的包含关系统一为一条谱系。

## 三、核心对象

- **拓扑空间**（topological space）— 由开集定义的连续性的最一般舞台
- **紧致性**（compactness）— 有限性的拓扑替代
- **同伦 / 同调**— 空间的代数摘要
- **基本群**（fundamental group）— 一维洞的代数记录
- **流形**（manifold）— 局部像欧氏空间的空间
- **切丛 / 联络**（tangent bundle / connection）— 微分几何的基础设施
- **曲率**（curvature）— 空间弯曲的度量；Gauss–Bonnet 联系局部与整体
- **层**（sheaf）— 局部数据的全局组织方式
- **上同调**— 层的导出函子；现代几何的核心工具
- **示性类**（characteristic class）— 丛的拓扑不变量
- **配边**— 流形的高阶等价关系
- **辛 / 凯勒流形**（symplectic / Kähler）— 力学与复几何的舞台
- **模空间**（moduli space）— "所有几何对象的空间"

## 六、本域的验证要点

| 陷阱 | 说明 | 建议证据等级 |
| --- | --- | --- |
| **紧致的定义分歧** | 有些文献的 "compact" 已含 Hausdorff，有些不含 | L1 强制声明 |
| **光滑 vs 拓扑 vs PL** | 三者在不同维数下不等价（四维最诡异） | 声明范畴 |
| **定向性** | 大量定理需要可定向 | `assumptions` |
| **曲率计算的符号约定** | 黎曼曲率张量的符号约定在不同教材中相反 | 必须注明约定（如 Besse / do Carmo） |
| **图形直觉的误导** | 高维/非 Hausdorff 空间中直觉失效 | 低维 L2 验证，高维 L3/L4 |
| **数值微分几何的离散化误差** | 离散曲率逼近需要细网格与收敛性检验 | L2 需网格收敛研究 |
| **同调计算** | 大规模复形计算需专用算法 | L2 注明算法与复杂度 |
