# 01-数学体系

> 本目录是 OpenMath 的**知识域地图**。它回答：数学有哪些分支、每个分支的边界在哪里、分支之间如何连接。

## 一、设计原则

### 1. 分类标准采用 MSC 2020

本库**不自创分类**，而是映射 [MSC 2020](https://mathscinet.ams.org/msc/msc2020.html)（Mathematics Subject Classification 2020）。理由：

- 它是国际通行标准，便于与外部数据库（zbMATH、MathSciNet、arXiv）对接
- 它经过数十年迭代，边界争议已被充分讨论
- 避免"重新发明轮子再争论一次"

**但我们做了合并**：MSC 的 63 个两位类对知识库而言过细（例如把 30 复分析与 31 位势论分开），本库合并为 **17 个知识域**，每个域在元信息中列出其覆盖的 MSC 码。

### 2. 边界是接口，不是墙

每个域的 README 都必须写明 **上游依赖** 与 **下游应用**。数学的价值大量产生在交界处（代数几何、算术动力学、量子信息……），因此本库专门用 `04-数学统一场论/03-跨纲领翻译表/` 记录跨域概念对应。

### 3. 域可无限扩展

新增一个域只需两步：

1. 建目录 `NN-域名/`，内含 `README.md` 与 `域元信息.yaml`
2. 在 [00-宪章/04-标识与编号规范](../../00-宪章/04-标识与编号规范.md) 的域代码表中追加一行

**不需要改任何代码。** 工具链通过扫描目录自动发现域。

## 四、每个域目录的标准结构

```
NN-域名/
├── README.md           域说明（本文件模板见 _模板/分支模板.md）
├── 域元信息.yaml        机器可读：域代码、MSC 映射、负责人、统计
├── 定义/               OM-D-XX-*.yaml + .md
├── 公式/               OM-F-XX-*.yaml + .md
├── 定理/               OM-T-XX-*.yaml + .md
├── 猜想/               OM-C-XX-*.yaml + .md
├── 反例/               OM-X-XX-*.yaml + .md
├── 算法/               OM-A-XX-*.yaml + .md
└── 子域/               可选，二级细分（不另设域代码）
```

**为什么不按"子域"再分层？** 层级过深会降低可发现性，且数学的多归属现象严重（一个定理同时属于代数几何与数论）。本库用 **标签（`tags`）+ 图索引** 代替深目录树：`python -m openmath index` 会生成多维索引。
