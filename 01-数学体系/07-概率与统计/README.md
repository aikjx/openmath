# 07-概率与统计（PR / SC）

> MSC 2020：60（概率论与随机过程）、62（统计学）

## 一、本域研究什么

概率论研究**随机现象的规律**；统计学研究**从数据反推产生数据的机制**。方向相反：

- 概率：已知模型 → 预测数据（演绎）
- 统计：已知数据 → 推断模型（归纳）

这一倒转使统计具有**哲学不对称性**：概率有公理化基础（Kolmogorov, 1933）；统计推断的正确性依赖额外准则（相合性、无偏性、有效性、覆盖率），而这些准则**存在本质冲突**。本库要求所有统计条目声明所用推断框架（`framework: frequentist | bayesian | minimax`）。

## 三、核心对象

- **概率空间** — (Ω, ℱ, P)
- **随机变量 / 分布函数** — 随机性的编码
- **期望 / 方差 / 矩** — 分布摘要
- **大数定律** — 频率稳定到概率
- **中心极限定理** — 和为渐近正态（数学最重要的定理之一）
- **条件期望** — 由 Radon–Nikodym 定义，现代概率的核心
- **鞅**（martingale）— 公平博弈的数学；随机分析与金融的基础
- **Markov 链 / 过程** — 无记忆演化
- **Brown 运动 / Itô 积分** — 随机微积分
- **随机微分方程**（SDE）— 含噪声动力学
- **大偏差原理** — 罕见事件的指数衰减率
- **充分统计量 / 似然** — 统计推断基石
- **假设检验 / 置信区间** — 频率派工具
- **后验分布** — 贝叶斯派工具

## 六、本域的验证要点

| 陷阱 | 说明 | 建议 |
| --- | --- | --- |
| **不相关 ≠ 独立** | 仅联合正态分布下等价 | L1 强制检查 |
| **几乎必然 / 依概率 / Lᵖ 收敛层级** | 三者互不包含（除特殊条件） | 精确声明收敛模式 |
| **条件期望的版本依赖** | 只在 a.s. 意义下唯一 | L1 声明 |
| **蒙特卡洛的"验证"** | 模拟 100 万次一致**不是证据** | 仅 L2，且必须给置信区间 |
| **重尾分布** | 方差不存在时 CLT 失效 | L2 检查矩条件 |
| **伪随机数质量** | 实验结论依赖 RNG 质量 | 必须记录种子与生成器 |
| **统计相合性 vs 一致性** | 与逻辑 consistency 同英文词 | [术语表](../../00-宪章/05-中英术语对照表.md) 强制区分 |
| **p 值误用** | p 值不是"原假设为真的概率" | 表述审查 |
