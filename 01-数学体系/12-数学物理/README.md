# 12-数学物理（MP）

> MSC 2020：70–86（力学、量子理论、统计力学、相对论、天文学、地球物理、光学、声学、流体力学）

## 一、本域研究什么

数学物理研究**物理理论的数学结构**，以及**为物理问题发展新的数学**。

本域具有本库中最特殊的认识论地位：**它是唯一有外部实验约束的数学域**。这带来两个后果：

1. **优势**：物理正确性是额外的验证通道（一个与实验冲突 20 个数量级的"理论"显然有问题）
2. **风险**：物理直觉会诱使数学家接受未经证明的"推导"（路径积分、重正化的许多步骤在数学上尚未严格）

**本库立场**：数学物理条目必须**区分"物理推导"与"数学定理"**。前者可录为 `status: DRAFT` + `evidence_level: L2`，后者才可标 `VERIFIED(L4)`。

## 三、核心对象

- **拉格朗日 / 哈密顿力学** — 力学的几何化（辛流形）
- **诺特定理** — 对称性 ↔ 守恒律（数学物理最深刻的定理之一）
- **作用量原理** — 最小作用量
- **偏微分方程** — Maxwell、Schrödinger、Navier–Stokes、Einstein 方程
- **希尔伯特空间 / 算符** — 量子力学的数学基础
- **谱理论** — 能级
- **路径积分** — 物理上强大，数学上多为形式化
- **重正化群** — Wilson 的洞见；数学严格化部分完成
- **规范理论** — 主丛上的联络；杨–米尔斯理论
- **共形场论 / 顶点算子代数** — 二维临界现象
- **广义相对论** — 伪黎曼几何、Einstein 方程、奇点定理
- **量子场论的公理化** — Wightman 公理、Osterwalder–Schrader
- **随机矩阵与可积系统** — 交叉工具
- **拓扑量子场论** — Atiyah 公理、Jones 多项式

## 四、与其他域的接口

**上游**：`AN`（PDE、泛函分析）、`TG`（微分几何、拓扑）、`AL`（李群、表示论）、`PR`（随机过程）
**下游**：`NA`（科学计算）、`OR`（最优控制）、`XS`（生物物理、地球物理）

**交叉**：
- **镜像对称 × 枚举几何** — 弦论预言了数学定理（Candelas 等的五次三维形计数）
- **可积系统 × 表示论** — 量子群、Yang–Baxter
- **随机矩阵 × 数论** — ζ 零点
- **规范理论 × 低维拓扑** — Donaldson、Seiberg–Witten、Floer 同调

## 六、本域的验证要点 —— **量纲是额外的免费检查**

| 陷阱 | 说明 | 建议 |
| --- | --- | --- |
| **量纲不一致** | 本域独有：量纲分析可免费发现大量错误 | **L1 强制量纲检查**（其他域无此通道） |
| **物理推导 vs 数学证明** | 路径积分、微扰展开多为形式化操作 | 必须声明 `nature: formal | rigorous` |
| **数值常数的实验依赖** | 物理常数有测量不确定度 | 引用 CODATA 并注明年份 |
| **单位制混用** | SI vs 自然单位 vs 高斯单位 | L1 强制声明单位制 |
| **发散级数** | 微扰级数常为渐近级数（发散） | 声明收敛性/渐近性 |
| **重正化的歧义** | 减除方案依赖 | 声明方案 |
| **经典极限的交换** | ℏ → 0 与 N → ∞ 不交换 | 声明极限顺序 |
| **与实验的符合** | 数值符合实验**不构成数学证明** | [红线一](../../00-宪章/02-诚实红线.md) |
