# 10-信息论与编码（IT）

> MSC 2020：94（信息论、电路、通信、编码）

## 一、本域研究什么

信息论研究**信息的度量、压缩极限与可靠传输极限**。Shannon 1948 年的开创性工作给出了三个基本极限：

- **无失真压缩极限** = 熵 H(X)
- **有失真压缩极限** = 率失真函数 R(D)
- **信道可靠传输极限** = 信道容量 C

编码理论研究**如何构造接近这些极限的具体码**。信息论给极限，编码论给构造——两者的张力驱动了本域七十余年的发展。

## 三、核心对象

- **熵**（Shannon entropy）H(X) = −Σ p log p
- **互信息 / 条件熵** — 信息的依赖度量
- **信道容量** — 可靠传输的上确界
- **率失真理论** — 有损压缩的极限
- **渐近均分性（AEP）** — 典型集，信息论的概率基础
- **线性码 / 循环码** — 代数编码的基础
- **Reed–Solomon 码** — 应用最广的代数码（CD、QR、深空通信）
- **LDPC 码 / Turbo 码** — 逼近容量的现代码
- **Polar 码** — 首个被证明达到容量的码（Arıkan 2009）
- **代数几何码** — 超越 GV 界的构造（Tsfasman–Vlăduţ–Zink）
- **界** — Hamming、Singleton、Gilbert–Varshamov、Plotkin、Elias
- **密码学接口** — McEliece、格密码（亦见 `TC`/`NT`）
- **量子信息** — 量子信道、量子纠错（交叉前沿）

## 四、与其他域的接口

**上游**：`PR`（概率是信息论的语言）、`AL`（有限域、代数编码）、`CB`（组合设计）
**下游**：`TC`（通信复杂度、密码学）、`MP`（统计力学联系）、`XS`（生物信息、神经编码）

**交叉**：
- **信息论 ↔ 统计力学** — 熵的两种面孔（最大熵原理）
- **信息论 ↔ 机器学习** — 信息瓶颈、率失真与表示学习
- **编码 ↔ 代数几何** — 代数几何码
- **量子信息** — 与 `MP`、`TC` 三方交汇

## 六、本域的验证要点

| 陷阱 | 说明 | 建议 |
| --- | --- | --- |
| **对数底的选择** | log₂ vs ln 相差常数因子；单位（bit / nat） | 显式声明 |
| **离散 vs 微分熵** | 微分熵可为负、非坐标不变 | 区分声明 |
| **容量的"存在性"证明** | Shannon 用的是随机编码论证，非构造 | 区分存在性与构造 |
| **码的参数一致性** | [n, k, d] 三个参数的约定（d 是最小距离） | L1 检查 |
| **有限域上的计算** | 必须在 GF(q) 上精确运算，不能用浮点 | L2 用整数/符号运算 |
| **译码复杂度** | 逼近容量 ≠ 可高效译码 | 分别声明码率与译码复杂度 |
| **"容量"的上下文** | 不同信道模型（DMC、AWGN、衰落）容量不同 | 声明模型 |
