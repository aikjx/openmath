# 11-动力系统与混沌（DS）

> MSC 2020：37（动力系统与遍历论）；部分 34C/34D、70K

## 一、本域研究什么

动力系统研究**一个状态按固定规则反复演化时的长期行为**。核心问题不是"下一步去哪"，而是"无穷多步之后会怎样"——会收敛、会周期、还是会永远复杂地游走？

本域最重要的发现是：**确定性的简单规则可以产生不可长期预测的复杂行为（混沌）**。这从根本上区分了"确定性"与"可预测性"。

## 三、核心对象

- **流 / 映射**（flow / map）— 连续时间与离散时间
- **不动点 / 周期轨** — 最简单的长期行为
- **稳定流形与不稳定流形** — 双曲结构的骨架
- **双曲性**（hyperbolicity）— 结构稳定性的来源
- **Lyapunov 指数** — 混沌的定量度量
- **熵**（拓扑熵、测度熵）— 复杂度的度量
- **遍历性 / 混合性** — 时间平均 = 空间平均
- **不变测度** — 长期统计的分布
- **分岔**（bifurcation）— 参数变化导致质性改变
- **奇怪吸引子** — Lorenz 吸引子
- **KAM 理论** — 可积系统在小扰动下的稳定性
- **符号动力学** — 用序列编码轨道
- **重整化与普适性** — Feigenbaum 常数
- **复动力系统** — Mandelbrot 集、Julia 集
- **Arnold 扩散** — 近可积哈密顿系统的缓慢漂移

## 四、与其他域的接口

**上游**：`AN`（微分方程、测度论）、`TG`（微分拓扑、辛几何）、`PR`（随机扰动）
**下游**：`MP`（经典力学、统计力学、湍流）、`OR`（控制）、`XS`（生态、经济、神经）

**交叉**：
- **哈密顿系统 × 辛几何** — KAM、Arnold 扩散
- **遍历论 × 数论** — 唯一遍历性在等分布中的应用、Furstenberg 对应（Szemerédi 定理的遍历论证明）
- **复动力 × 算术** — 算术动力学
- **混沌 × 数值** — 阴影引理、长期积分的可靠性

## 六、本域的验证要点 —— **本域是数值验证最危险的领域之一**

| 陷阱 | 说明 | 建议 |
| --- | --- | --- |
| **混沌使数值长期不可信** | 初值误差指数放大，双精度 ~50 步后完全失真 | L2 必须声明有效时间窗口 |
| **"看起来是吸引子" ≠ 存在吸引子** | 需要严格证明或区间算术验证 | Lorenz 问题的历史教训 |
| **时间平均 vs 空间平均** | 遍历性需证明，不能假设 | 声明是否已证遍历 |
| **周期窗口的误判** | 混沌区中存在稳定周期窗口 | 参数扫描需足够精细 |
| **分岔图的分辨率** | 分辨率不足会漏掉关键结构 | 报告分辨率 |
| **伪随机性误判** | 确定性混沌在统计检验中"看起来随机" | 不可作为随机性的证据 |
| **数值阴影性** | 数值轨是否接近真轨？ | 引用阴影引理，给出阴影距离 |
| **计算机辅助证明** | 需区间算术 + 严格舍入控制 | 优先 L4（如 Tucker 工作的形式化） |
