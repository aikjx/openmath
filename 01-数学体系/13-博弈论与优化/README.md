# 13-博弈论与优化（GO）

> MSC 2020：90（运筹学与数学规划）、91（博弈论、经济学、社会科学中的数学）

## 一、本域研究什么

**优化**研究：在约束下如何找到最好的选择。
**博弈论**研究：当"最好"取决于他人选择时，如何定义与求解"最好的选择"。

两者的分界点是**是否存在策略互动**。此外本域还有一个独特的哲学维度：**"理性"如何被公理化**——期望效用理论、Nash 均衡、机制设计，本质都是对理性的公理化刻画。

## 三、核心对象

- **线性规划 / 单纯形法 / 对偶** — 优化的基础
- **凸优化** — 唯一具有完整理论的大类
- **KKT 条件** — 约束优化的一阶必要条件
- **拉格朗日对偶与强对偶** — Slater 条件
- **整数规划与组合优化** — NP 难的主战场
- **Nash 均衡** — 博弈论的核心解概念
- **零和博弈与极小极大定理** — von Neumann
- **拍卖与机制设计** — 反向博弈（设计规则）
- **合作博弈与 Shapley 值** — 公平分配的公理化
- **演化博弈与复制动力学** — 与 `DS` 交叉
- **最优控制与 Pontryagin 极大值原理** — 连续时间优化
- **动态规划与 Bellman 方程** — 序贯决策
- **在线学习与后悔最小化** — 与 `TC` 交叉
- **随机优化与鲁棒优化** — 处理不确定性

## 四、与其他域的接口

**上游**：`AN`（凸分析、变分法）、`AL`（线性代数、多面体几何）、`PR`（随机优化）
**下游**：`OR`（供应链、调度）、`TC`（算法博弈论、机制设计与互联网的交叉）、`XS`（经济、生物演化）

**交叉**：
- **算法博弈论** — 均衡的计算复杂度（PPAD 完全性）
- **最优传输** — 与 `AN`、`PR`、`MP` 交汇
- **平均场博弈** — 与 PDE 交叉（Lasry–Lions）
- **信息设计 / 贝叶斯劝说** — 与 `IT` 交叉

## 五、顶级开放问题

| 问题 | 状态 |

| P vs NP（直接决定整数规划的复杂度） | 未解决（见 [千年难题](../../03-难题与猜想/01-千年大奖难题/README.md)） |

## 六、本域的验证要点

| 陷阱 | 说明 | 建议 |
| --- | --- | --- |
| **局部最优 vs 全局最优** | 非凸问题中 KKT 只是必要 | 声明最优性类型 |
| **对偶间隙** | 弱对偶恒成立，强对偶需条件（Slater、凸性） | 声明对偶条件 |
| **均衡的多重性** | Nash 均衡通常不唯一 | 解概念需声明精炼（子博弈完美、颤抖手等） |
| **"理性"公理的隐含假设** | 期望效用依赖独立性公理（Allais 悖论挑战） | 声明公理系统 |
| **NP 难的"未解"** | "问题很难" ≠ "已证明 NP 难" | 证明复杂度归属或声明"经验困难" |
| **数值求解器的容差** | 求解器返回的是满足容差的解 | 报告容差与对偶间隙 |
| **规模外推** | 小实例可解不代表大规模可解 | 报告规模与复杂度 |
