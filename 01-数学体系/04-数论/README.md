# 04-数论（NT）

> MSC 2020：11（数论）

## 一、本域研究什么

数论研究**整数（及其推广：代数数、函数域）的深层结构**，核心张力是**加法结构与乘法结构之间的互不兼容**——素数由乘法定义，但素数在加法序列（如 n²+1、p+2）中的行为却极难把握。这一张力产生了数学中最多、最著名的未解问题。

Gauss 称数论为"数学的女王"。它也是最"危险"的领域：**大量猜想被数值验证到天文数字量级后仍被证伪**。

## 三、核心对象

- **素数**（prime）— 乘法的原子
- **素数定理** — π(x) ~ x / ln x（已证明）
- **黎曼 ζ 函数** — ζ(s) = Σ n^{-s}，Re(s) > 1
- **黎曼假设**（RH）— 非平凡零点全在 Re(s) = 1/2 上
- **模形式**（modular form）— 具有极高对称性的复变函数
- **椭圆曲线**（elliptic curve）— 三次曲线， Fermat 大定理的关键
- **L-函数** — ζ 的推广；Langlands 纲领的核心对象
- **类数**（class number）— 度量唯一分解的失效程度
- **伽罗瓦表示**— 数论与表示论的桥梁
- **筛法**（sieve method）— 从序列中"筛出"素数
- **p-进数**（p-adic numbers）— 另一种完备化
- **自守表示**— 模形式的表示论推广

## 六、本域的验证要点 —— **最严格**

| 陷阱 | 说明 | 建议证据等级 |
| --- | --- | --- |
| **数值验证的欺骗性** | Pólya 猜想、Mertens 猜想、π(x) < li(x) 都在巨大范围内"成立"后被推翻 | **L2 永不可作为证明性证据**（[红线一](../../00-宪章/02-诚实红线.md)） |
| **"验证到 N" 的表述** | 必须写明确切 N、方法、误差 | L2 需完整环境指纹 |
| **条件性结果** | 大量定理依赖 RH / GRH，"在 GRH 下成立" ≠ 成立 | `status: CONDITIONAL` |
| **零点计算精度** | ζ 零点的高精度计算需特殊算法（Riemann–Siegel 公式） | L2 需 ≥50 位，注明算法 |
| **模形式的系数** | Fourier 系数是整数，浮点误差会导致错误 | L2 用整数/有理数运算 |
| **椭圆曲线的秩** | 秩的计算无通用算法保证终止 | 标注"已验证秩 ≥ r"而非"秩 = r" |
| **Skewes 数教训** | 任何"对所有 n 成立"的断言，其首次反例可能在 10^{10^{...}} 处 | 数值结果必须声明范围 |

## 七、本域与 AI 自动化

数论是 **AI 辅助发现反例**的最佳试验场：

- 对象是离散的、可穷举的
- 反例搜索（L5）成本低、收益高
- 但也是 AI 幻觉的温床：模型极易生成"看似合理的 ζ 恒等式"

**强制要求**：本域任何数值断言都必须给出**可重现的计算脚本**，且脚本必须输出残差而非仅仅"通过"。
