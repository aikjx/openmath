# 03-代数（AL / GR）

> MSC 2020：08, 12–17, 20, 22（一般代数系统、域论、交换代数、线性代数、结合环、非结合代数、群论、表示论）

## 一、本域研究什么

代数研究**运算结构及其对称性**。它的核心方法极其独特：**把研究对象变成可运算的代数对象，然后用代数不变量（秩、特征标、上同调、K-理论）回答原本的问题**。

代数是数学的"语法层"——它提供的语言（群、环、模、范畴）被几乎所有其他域借用。

## 三、核心对象

- **群**（group）— 对称性的代数学；有限单群分类是 20 世纪的伟业
- **环 / 域**（ring / field）— 数与函数的抽象
- **模**（module）— 环上的"向量空间"；同调代数的主战场
- **理想 / 商**（ideal / quotient）— 构造新结构的两大手段
- **伽罗瓦理论**（Galois theory）— 域扩张与群的子群格对应
- **表示论**（representation theory）— 把抽象群变成矩阵群
- **李代数 / 李群**（Lie algebra / group）— 连续对称性
- **特征标**（character）— 表示的一维摘要
- **同调代数**— Ext、Tor、导出范畴
- **代数 K-理论**— 环的高阶不变量
- **Hopf 代数 / 量子群**— 对称性的非交换推广
- **簇 / 概形**（variety / scheme）— 见 `TG`（代数几何）

## 六、本域的验证要点

| 陷阱 | 说明 | 建议证据等级 |
| --- | --- | --- |
| **交换律的隐含假设** | 大量公式只在交换环上成立（如 det(AB)=det(A)det(B) 在一般环上也成立，但许多其他公式不成立） | 强制声明交换性 |
| **特征为零 vs 特征 p** | 特征 p 时大量"显然"的代数事实失效（如 x^p − a 的导数恒为零） | 声明特征 |
| **有限生成 / Noether 性** | 许多定理需要 Noether 条件 | `assumptions` |
| **有限群的"小阶数验证"** | 群论是有限对象，天然可穷举，但阶数增长极快 | L2 穷举需说明上界 |
| **表示论中的数值陷阱** | 特征标表计算需高精度（涉及单位根） | L2 需 50 位精度 |
| **同调代数的交换图** | 与范畴论同：方向错误 | L4 推荐 |
| **形式化现状** | mathlib 的群论/环论库非常成熟，L4 可行性高 | 优先选择 L4 |
