# 08-组合与图论（CB / GT）

> MSC 2020：05（组合数学）、06（序、格、有序代数结构）

## 一、本域研究什么

组合数学研究**离散结构的计数、存在性与构造**——对象有限但数量爆炸，其难度常来自"搜索空间太大"而非"概念太深"。

图论研究**二元关系的结构**（顶点与边）。它是组合中发展最充分、应用最广的分支，也是**反例搜索最便宜**的领域——这使得本域成为 L5 对抗性验证的天然试验场。

## 三、核心对象

- **排列 / 组合 / 分拆** — 计数的三种原型
- **生成函数**（ordinary / exponential）— 把序列变成函数
- **Catalan 数** — 组合数学的" ubiquitous 常数"
- **图**（graph）— 顶点 + 边
- **树 / 森林** — 无环图
- **匹配 / 覆盖 / 独立集** — 三大基本问题
- **染色**（coloring）— 色数 χ(G)
- **平面图** — Kuratowski 定理、四色定理
- **Ramsey 数** — 完全混乱是不可能的
- **极值图论** — Turán 定理、Szemerédi 正则性引理
- **拟阵**（matroid）— 独立性的公理化
- **偏序集 / 格** — Möbius 反演、Dilworth 定理
- **代数组合** — 对称函数、Young 表、表示论接口
- **随机图** — Erdős–Rényi、相变

## 六、本域的验证要点

| 陷阱 | 说明 | 建议 |
| --- | --- | --- |
| **小参数穷举的外推** | n ≤ 10 成立 ⇒ n=11 成立？**不成立**，本域充斥此类反例 | L2 必须声明穷举上界 |
| **图的定义约定** | 是否允许自环、重边、有向、空图 | L1 强制声明 |
| **组合爆炸** | 图同构、Ramsey 数计算是 NP 难/极难 | 计算型条目需声明复杂度 |
| **构造性 vs 存在性** | 概率方法证明存在但给不出构造 | 区分声明 |
| **四色定理的性质** | 是**计算机辅助**证明，已形式化（Gonthier, Coq） | L4 已有范例 |
| **"显然"的图论直觉** | 高维/稠密图中直觉常失效 | 反例库必备 |
| **形式化现状** | mathlib 图论库成熟，Gonthier 的四色形式化是里程碑 | 优先 L4 |

## 七、本域与 AI 自动化 —— 反例搜索主战场

本域是 **L5 反例搜索**的最佳场所：

- 对象离散、有限 → 可穷举
- 性质一阶可表达 → 可用 SAT/SMT 求解
- 存在标准格式（DIMACS、graph6）→ 工具链成熟

**标准工作流**：

```
猜想条目 ──> 生成小参数候选（n ≤ 12）──> SAT/SMT 编码
        ──> 穷举/随机搜索 ──> 找到反例？
              │ 是 ──> status: FALSIFIED + 反例入库
              └> 否 ──> 记录搜索上界，**不升级证据等级**
```
