# 16-交叉与新兴（XS）

> MSC 2020：92（生物学与其他自然科学）、97（数学教育）、00（一般性）

## 一、本域的定位

本目录是 OpenMath 的**增长边界**。它的存在基于一个判断：

> **任何分类系统都会过时，而一个没有"未分类"出口的分类系统会被现实撑破。**

数学向外部学科渗透的速度远超分类修订的速度。本域承接两类内容：

1. **交叉应用数学** — 数学方法进入其他学科形成的稳定领域
2. **新兴方向** — 尚未成熟到可独立成域，但已显示出结构的新方向

## 二、收录标准（比他域更严）

新兴方向要进入本域，必须满足下列**至少两条**：

- [ ] 已有专门的期刊或长期会议
- [ ] 已有研究生教材或综述
- [ ] 已有可复现的基准问题集
- [ ] 已产生至少一项被主流数学承认的**新定理**
- [ ] 已形成自己的核心概念（不能只是"用 X 方法处理 Y 数据"）

**不满足者**请放入 [`99-沙箱/`](../../99-沙箱/README.md)，不计入质量门禁。

**毕业机制**：当某方向累计 ≥ 30 条 `VERIFIED(L3+)` 条目且有 ≥ 2 名评审者时，可申请独立成域（见 [扩展指南](../README.md)）。

## 四、AI × 数学（本库重点方向）

这是一个**自我指涉**的方向：本库本身就是一个 AI 与数学交叉的项目。我们把它作为研究对象收录，同时保持自我批判。

| 子方向 | 现状（诚实） | 本库相关模块 |
| --- | --- | --- |
| 自动定理证明（ATP） | 在特定领域（如 IMO 几何、部分竞赛题）有实质进展；一般研究级定理仍远未解决 | [05-验证中心/07-形式化](../05-验证中心/07-形式化/README.md) |
| 形式化自动化（autoformalization） | 叙述 → Lean 的自动翻译仍错误率高，是活跃瓶颈 | [06-AI自动化](../06-AI自动化/README.md) |
| AI 辅助猜想生成 | 已产生少数被证明的新猜想/反例；**绝大多数输出无价值** | [06-AI自动化/01-工作流](../06-AI自动化/01-工作流/README.md) |
| 符号回归与公式发现 | 在物理定律再发现上有效；外推能力有限 | [05-验证中心/06-探针](../05-验证中心/06-探针/README.md) |
| 机器学习求解 PDE | 有前景（PINN、算子学习）；**精度与收敛保证弱于传统方法** | [09-计算数学](../09-计算数学与数值分析/README.md) |
| 大语言模型的数学能力评估 | 基准（GSM8K、MATH、ProofNet、miniF2F）快速饱和；**饱和 ≠ 能力** | [05-验证中心/04-基线](../05-验证中心/04-基线/README.md) |

**本库立场（诚实边界）**：

- AI 在数学中的**已证实价值**：文献检索、形式化辅助、反例搜索、大规模计算、教学中
- AI 在数学中的**未证实宣称**：独立发现深刻定理、替代同行评审、自动证明开放问题
- **我们不做后者，且对宣称做成后者的说法保持系统性怀疑**

## 五、本域的验证要点

| 陷阱 | 说明 |
| --- | --- |
| **跨学科术语歧义** | 同一词在不同学科含义不同（如 "stability" 在动力学、控制、博弈中不同） |
| **模型的可辨识性** | 应用模型常有大量自由参数，拟合好 ≠ 模型对 |
| **数据的质量** | 应用数学结论依赖数据质量与预处理 |
| **"新颖方法"的对照缺失** | 新方法必须与已有基线比较，否则无意义 |
| **新兴方向的泡沫** | 热度过高的方向，负面结果与失败案例发表不足 |
