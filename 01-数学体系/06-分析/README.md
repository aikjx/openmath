# 06-分析（AN）

> MSC 2020：26, 28, 30–49（实变、测度与积分、复变、位势论、多复变、特殊函数、常/偏微分方程、动力系统、差分与函数方程、序列级数可和性、逼近与展开、调和分析、积分变换、积分方程、泛函分析、算子理论、变分法）

## 一、本域研究什么

分析研究**极限过程以及建立在极限之上的一切**：连续、微分、积分、无穷级数、函数空间。

它是数学中最大的域，也是**数值与符号验证最发达的域**——正因如此，分析也是幻觉最容易"看起来成功"的域：一个错误的恒等式往往在数值上精确到小数点后 15 位。

## 三、核心对象

- **极限 / 连续 / 一致收敛** — 分析的基石；一致收敛是最常被遗漏的假设
- **导数 / 积分** — 微积分基本定理把它们连接起来
- **测度**（measure）— 长度/面积/体积的一般化
- **Lebesgue 积分** — 比 Riemann 积分更强（控制收敛定理）
- **L^p 空间** — 函数空间的基本家族
- **Hilbert / Banach 空间** — 无限维的几何
- **解析函数** — 复可微 ⇒ 无限可微（复分析的奇迹）
- **留数定理** — 复积分的强大工具
- **Fourier 变换** — 把微分变成乘法
- **分布（广义函数）** — Dirac δ 的严格化
- **Sobolev 空间** — PDE 弱解的自然空间
- **谱理论** — 算子的"特征值"理论
- **特殊函数** — Γ、ζ、Bessel、超几何函数

## 六、本域的验证要点

| 陷阱 | 说明 | 建议证据等级 |
| --- | --- | --- |
| **极限交换** | ∫lim ≠ lim∫；需要一致收敛 / 单调收敛 / 控制收敛 | **最常被遗漏的假设**，L1 强制检查 |
| **条件收敛的重排** | Riemann 重排定理：条件收敛级数可重排成任意值 | L1 检查绝对收敛 |
| **分支切割** | 复对数/幂函数的主值选择；符号引擎常在此出错 | L3 需指定分支 |
| **几乎处处 vs 处处** | 测度论结论通常是 a.e. | 精确表述 |
| **数值精度** | 高振荡积分、接近奇点的求值损失精度 | L2 需 ≥50 位 + 条件数报告 |
| **SymPy 的假设系统** | 化简结果依赖符号的 positive/real 声明；未声明导致假结果 | L3 必须显式声明假设 |
| **病态函数** | Weierstrass 函数处处连续无处可微 | 反例库必备 |
| **PDE 的弱解 vs 古典解** | 数值"解出"的可能是弱解 | 声明解的类型 |

## 七、本域与符号/数值验证

分析是 L2/L3 层**能力最强**的域，因为：

- 有成熟的符号引擎（SymPy、Mathematica）
- 有高精度库（mpmath）
- 有大量经典闭式解可供对照

**但这也是风险所在**：工具太好用，容易让人忘记 L2/L3 不是证明。本域的所有条目模板都强制包含 `caveat` 字段，说明"该结论的数值验证存在哪些已知失效模式"。
