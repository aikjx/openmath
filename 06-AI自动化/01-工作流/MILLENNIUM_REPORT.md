## 2. 逐题：逻辑方程与有限影子

### RH · 黎曼猜想 Riemann Hypothesis　（`UNSOLVED`）

- **命题**：黎曼 ζ 函数的所有非平凡零点实部均为 1/2。
- **逻辑方程**：`∀ρ [ ζ(ρ)=0 ∧ 0<Re ρ<1 ] → Re ρ = 1/2`
- **量词结构**：forall ρ ∈ ζ 的非平凡零点（无限集）
- **待证谓词**：Re ρ = 1/2
- **反命题（证伪通道）**：`∃ρ : ζ(ρ)=0 ∧ 0<Re ρ<1 ∧ Re ρ ≠ 1/2`
- **有限影子**（范围 T = 600（实测；不是能力上限，只是本轮跑到的高度））：∀ρ [ ζ(ρ)=0 ∧ 0<Re ρ<1 ∧ |Im ρ| ≤ T ] → Re ρ = 1/2，本引擎实测到 T=600（Hardy Z 符号变号计数 341 个零点，另用辐角原理独立复核得 N(600)=341，两法一致）
- **影子是否蕴含原命题**：**否**
- **为什么否**：有限高度内无反例**不蕴含**全部零点都在临界线上：零点无限多，任何有限截断都可能漏掉第一个偏离的零点。这是数值验证与证明之间的本质鸿沟。
- **理论缺口**：本质困难在于零点的全局分布与素数分布之间缺少可机器化的结构桥梁。Hilbert–Pólya 路线（把零点编码为某自伴算子的谱）至今未构造出该算子。

### PNP · P vs NP　（`UNSOLVED`）

- **命题**：是否所有 NP 问题都能在多项式时间内求解（P=NP）。
- **逻辑方程**：`P = NP ? （判定性问题；等价于 ∃L∈NP : L∉P 是否成立）`
- **量词结构**：exists L ∈ NP 语言族（无限族）；forall M ∈ 确定性多项式时间图灵机（无限族）
- **待证谓词**：L ∉ P ⟺ ∀M ∀poly p : M 不能在 p(|x|) 内判定 L
- **反命题（证伪通道）**：`P = NP ⟺ 每个 NP 语言都有多项式时间算法`
- **有限影子**（范围 相变曲线 n = 40、α ∈ [3.0, 5.5]、每点 12 个实例；对账用 n = 12）：对随机 3-SAT 实例，在子句/变量比 α 的网格上测量可满足率与 DPLL 求解代价；并在 n = 12 的小实例上用 2^n 全枚举逐例对账求解器的判定
- **影子是否蕴含原命题**：**否**
- **为什么否**：**本实验对 P vs NP 本身提供的证据为零**。有限规模的求解曲线既不蕴含 P≠NP，也不蕴含 P=NP：任何多项式算法都可能在 n > 10^6 才显现，而指数下界需要证明**所有**算法都不行，不是抽样几条实例能得到的。把它列进来的唯一理由是：它是本引擎能真实跑出来的、与问题同域的计算，而不是因为它能推进判定。
- **理论缺口**：缺乏区分'搜索'与'验证'复杂度的代数不变量；relativization / natural proofs / algebrization 三重障碍使经典对角化方法失效。

### NS · 纳维–斯托克斯存在性与光滑性　（`UNSOLVED`）

- **命题**：三维不可压缩 Navier–Stokes 方程对光滑初值是否存在全局光滑解（千禧版含 R³ 与周期两种表述）。
- **逻辑方程**：`∀u₀∈C^∞_σ(R³) ∀T>0 ∃!u∈C^∞(R³×[0,T]) : ∂ₜu+(u·∇)u = −∇p+νΔu, ∇·u=0, u(·,0)=u₀`
- **量词结构**：forall u₀ ∈ 光滑无散 initial data（无限维）；forall T ∈ (0,∞)；exists u ∈ C^∞ 解
- **待证谓词**：解全局存在且光滑（无有限时刻爆破）
- **反命题（证伪通道）**：`∃u₀ ∃T*<∞ : 解在 T* 处失去光滑性`
- **有限影子**（范围 一维，网格 n = 150 / 300；t ≤ 1.6；dt = 2e-4）：在周期盒上用迎风有限差分演化**一维** Burgers 方程（u₀ = −sin x），用特征线法估计激波时刻，与解析解 t* = −1/min u₀′ 对账
- **影子是否蕴含原命题**：**否**
- **为什么否**：离散网格上不爆破**既不蕴含**连续问题不爆破（网格可能恰好抹掉奇性），也**不是**连续问题的反例。BKM 判据本身是**必要条件**方向的经典结果，我们只是在离散近似上观测它，不构成任何证明。
- **理论缺口**：缺少对非线性项 (u·∇)u 的、能控制所有尺度的先验估计；Leray–Hopf 弱解的唯一性与正则性仍是缺口。

### BSD · BSD 猜想 Birch–Swinnerton-Dyer　（`UNSOLVED`）

- **命题**：椭圆曲线 L 函数在 s=1 处的零点阶等于其有理点群的秩，且首项系数由算术不变量给出。
- **逻辑方程**：`∀E/Q : ord_{s=1} L(E,s) = rank E(Q) 且 L^{(r)}(E,1)/r! = Ω·R·∏c_p·|Sha| / |E_tors|²`
- **量词结构**：forall E ∈ Q 上的椭圆曲线（无限族）
- **待证谓词**：解析秩 = 代数秩，且首项系数公式成立
- **反命题（证伪通道）**：`∃E : ord_{s=1} L(E,s) ≠ rank E(Q) 或首项系数公式不成立`
- **有限影子**（范围 p < 500；曲线 4 条）：对若干具体曲线 E，计算 #E(F_p) 与 a_p = p+1−#E(F_p)，检验 Hasse 界 |a_p| ≤ 2√p（已知定理，作**校准件**），并给出截断的 L 值近似与已知代数秩对照
- **影子是否蕴含原命题**：**否**
- **为什么否**：Hasse 界是**已证明的定理**，在此只作求值器的校准件——能对上说明点计数代码没错，**不能**说明 BSD 成立。截断 L 值不等于 L(E,1)，有限个 p 的 a_p 也不决定解析秩。
- **理论缺口**：已知结果（Gross–Zagier、Kolyvagin）只覆盖解析秩 ≤ 1 的情形；秩 ≥ 2 时无一般性结果，Sha 的有限性本身也未解决。

### HODGE · 霍奇猜想 Hodge Conjecture　（`UNSOLVED`）

- **命题**：射影代数簇上的有理 (p,p) 型 Hodge 类是否都是代数闭链类的有理组合。
- **逻辑方程**：`∀X 光滑射影代数簇 ∀p : H^{2p}(X,Q) ∩ H^{p,p}(X) = span_Q{[Z] : Z 为余维 p 的代数闭链}`
- **量词结构**：forall X ∈ 光滑射影代数簇（无限族）；forall p ∈ 0 ≤ p ≤ dim X
- **待证谓词**：每个 (p,p) 型有理 Hodge 类都是代数闭链类的有理线性组合
- **反命题（证伪通道）**：`∃X ∃p ∃ Hodge 类不在代数闭链类张成的空间内`
- **有限影子**（范围 复形 ≤ 3 维，单形数 ≤ 54（S²: 4+6+4；T²: 9+27+18；S³: 5+10+10+5））：在有限单纯复形上做**组合 Hodge**（有理系数的上链复形 + 拉普拉斯），检验 Betti 数 b_k 与调和 k-形式维数 dim H^k_Δ 是否相等（Hodge 同构的离散类比）
- **影子是否蕴含原命题**：**否**
- **为什么否**：这是**离散类比**，不是霍奇猜想本身：有限单纯复形没有 (p,p) 型分解，也没有代数闭链的概念。b_k = dim H^k_Δ 是线性代数恒等式，能对上是**计算正确性的校准**，与猜想无关。
- **理论缺口**：缺少把 Hodge 类实现为代数闭链的构造性方法；即便 Lefschetz (1,1) 定理已知，p ≥ 2 时无对应工具。

### YM · 杨–米尔斯质量间隙 Yang–Mills Mass Gap　（`UNSOLVED`）

- **命题**：证明四维量子 Yang–Mills 理论存在质量间隙（千禧大奖的精确表述要求同时构造该理论）。
- **逻辑方程**：`∀ 紧单规范群 G ∃Δ>0 : 四维 Yang–Mills 理论的谱在 (0,Δ) 上为空`
- **量词结构**：forall G ∈ 紧单李群；exists Δ ∈ (0,∞)
- **待证谓词**：真空与第一激发态之间存在正的质量间隙 Δ
- **反命题（证伪通道）**：`谱在 0 处无间隙（存在任意低能激发）`
- **有限影子**：无。原因：**本题本引擎没有可算方面**。原因不是没做，而是问题的前提——四维量子 Yang–Mills 测度的构造——本身尚未完成，在测度都不存在的情况下不存在可计算的谱。格点 QCD 数值模拟属于未实现的 `lattice_qcd_numeric`，且即便实现也只是有限格点上的 L2 证据。此处如实留空，不编造实验。
- **理论缺口**：四维量子规范场论的严格构造（Wightman/Osterwalder–Schrader 公理）本身未完成；这是比质量间隙更前置的障碍。

### POINCARE · 庞加莱猜想 Poincaré Conjecture　（`SOLVED`）

- **命题**：任何单连通的闭三维流形都同胚于三维球面。
- **逻辑方程**：`∀M 闭三维流形 : π₁(M)=0 → M ≅ S³`
- **量词结构**：forall M ∈ 闭三维流形
- **待证谓词**：单连通 ⇒ 同胚于 S³
- **反命题（证伪通道）**：`∃ 单连通闭三维流形不同胚于 S³`
- **有限影子**（范围 三角化顶点数 ≤ 20）：对有限三角化的三维闭流形，检验同调型必要条件：H₀=Z, H₁=0, H₂=0, H₃=Z
- **影子是否蕴含原命题**：**否**
- **为什么否**：同调条件**只是必要不充分**：存在同调球面（homology sphere）其 H_* 与 S³ 相同但基本群非平凡（如 Poincaré 同调球面）。本题已由 Perelman 证明（2002–2003，基于 Hamilton 的 Ricci 流），此处的有限检验只用于确认同调计算代码正确，**不重复证明**。
- **已证者**：Perelman (2002–2003)，Ricci 流 + 手术；本仓库不声称贡献。

## 3. 套娃分解树

### combinatorial_hodge　（HODGE）

- **口径**：这是**离散类比**，不是霍奇猜想。有限单纯复形上没有 (p,p) 型分解，也没有代数闭链的概念；b_k = dim ker Δ_k 是线性代数恒等式（必成立）。能对上只说明链复形与拉普拉斯的代码正确。全部用 Fraction 做精确有理运算，故不存在'浮点刚好凑上'的可能。Betti 数与教科书值对账是硬校准件：初版因忘记展开单形的面而算出 S² 的 b=(0,0,4)，就是靠这条对账抓出来的。
