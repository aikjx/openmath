# 11-教育

> 从科普到研究生的路线图。**教育不是本库的副产品，而是让知识可传播的必要环节。**

## 一、为什么数学知识库需要教育层

1. **降低贡献门槛**：新人需要知道"从哪里开始学"
2. **验证理解**：能教明白，才说明真懂了
3. **术语建设**：教材是术语统一的最佳载体
4. **反例的价值**：教育是最需要反例的地方

## 四、反直觉案例（最高教育价值）

**为什么反直觉案例最重要**：它们精确地展示了**直觉在哪里失效**，而数学的严谨性正是为了对抗直觉的失效。

**案例清单**（待建立）：

| 案例 | 展示的教训 |
| --- | --- |
| Banach–Tarski 悖论 | 选择公理的后果；"体积"的直觉局限 |
| Weierstrass 函数 | 连续 ≠ 可微 |
| Cantor 集 | 无处稠密但不可数；测度与基数的分离 |
| Pólya 猜想的反例 | **数值验证的极限** |
| Mertens 猜想的反例 | 同上 |
| Skewes 数 | "对所有 n 成立"的首次反例可在天文数字处 |
| Dirichlet 函数 | Riemann 不可积 |
| Hilbert 旅馆 | 无穷的算术 |
| Goodstein 定理 | 真但 PA 不可证 |
| 生日悖论 | 概率直觉 |
| Simpson 悖论 | 统计直觉 |
| Banach–Tarski / 非测度集 | 依赖 AC |
| 高维几何直觉失效 | 维数灾难、体积集中 |

**其中 Pólya、Mertens、Skewes 三条是本库特别强调的**——它们直接支撑 [红线一](../00-宪章/02-诚实红线.md)。
