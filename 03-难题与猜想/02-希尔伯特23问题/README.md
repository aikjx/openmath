# 02-希尔伯特 23 问题

> 1900 年巴黎国际数学家大会上，David Hilbert 提出 23 个问题，深刻塑造了 20 世纪数学的走向。

## 一、为什么这组问题特殊

它不是一个"悬赏清单"，而是一份**研究纲领**。它的价值不在于奖金，而在于：

1. **定义了 20 世纪的议程**：大量数学分支的发展由这些问题驱动
2. **状态分布最能说明数学的本质**：有些被解决，有些被证明**不可能解决**，有些**表述本身有问题**
3. **第 1、2、10 题的答案是"我们问错了/不可能"**——这是数学史上最重要的元发现

## 三、三种"不是解决了"的结局

Hilbert 问题最有教育意义的地方，在于它们展示了数学问题的三种非常规结局：

### 1. `UNDECIDABLE`（第 1 题）

连续统假设——Hilbert 把它列为第一问题，期待一个"是/否"的答案。答案是：**在 ZFC 中两者都不可证明**。这不是失败，而是**人类第一次精确定位了一个数学问题的性质**。

### 2. `UNCOMPUTABLE`（第 10 题）

"是否存在算法判定任意丢番图方程是否有整数解"——答案是**不存在**。这是"算法"概念被严格化之后才能提出的问题类型，Hilbert 提出时尚无此概念。

### 3. `REFUTED`（第 3、14 题）

问题问"是否总是成立"，答案是"不"——一个反例就够了。这提醒我们：**"是否所有 X 都满足 P" 型问题，答案往往是否定的**。
