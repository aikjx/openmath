# 07-爱尔特希问题

> Paul Erdős（1913–1996）是史上最多产的数学家之一，也是**悬赏问题的开创者**：他用自己的钱为数百个问题标价，从 10 美元到 10000 美元不等。

## 一、为什么值得单列

1. **数量庞大**：Erdős 问题分布极广（数论、组合、图论、几何、集合论）
2. **表述简洁**：多数问题一句话可懂，但难度差异极大
3. **奖金机制**：Erdős 去世后由他人（主要是 Ronald Graham 与 Fan Chung）代付奖金——这是数学界的一种信用传承
4. **已有多条被解决**：近年（包括 AI 辅助的）有若干进展

## 二、Erdős 问题的分级建议

Erdős 本人 famously 认为某些问题"可能永远无法解决"，某些"明天就能解决"。本库建议对 Erdős 问题标注**他本人的估价**与**客观状态**两个维度：

| 维度 | 说明 |
| --- | --- |
| `erdos_bounty` | Erdős 本人的标价（越低往往越难——他给最难的题标价高但也承认无望） |
| `status` | 按本库标准状态 |
| `difficulty_note` | 客观难度说明（不依赖 Erdős 的个人判断） |

## 四、近年的 AI 相关进展（诚实）

近年有若干 Erdős 问题的**部分情形**通过 AI 辅助（包括大语言模型辅助文献检索与思路整理、SAT 求解器构造反例）得到解决或改进。

**本库的记录政策**：

- 区分"AI 辅助"与"AI 独立解决"——**目前公开可查的案例绝大多数属于前者**
- 必须给出可复现的产物（代码、构造、反例）
- 只解决"某个 Erdős 问题的一个特例"的，**不得**表述为"解决了 Erdős 问题"
- 状态升级仍需 L4 或 ≥2 名独立专家复核
