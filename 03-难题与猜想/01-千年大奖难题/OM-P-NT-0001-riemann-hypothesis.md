## 一、精确陈述

设 \(\zeta(s)\) 为 Riemann ζ 函数，由 \(\operatorname{Re}(s) > 1\) 上的级数

\[
\zeta(s) = \sum_{n=1}^{\infty} n^{-s}
\]

解析延拓到 \(\mathbb{C}\setminus\{1\}\)。ζ 的零点分为两类：

- **平凡零点**：\(s = -2, -4, -6, \dots\)（负偶整数）
- **非平凡零点**：位于临界带 \(0 < \operatorname{Re}(s) < 1\) 内

> **黎曼假设**：ζ 的**所有**非平凡零点都满足 \(\operatorname{Re}(s) = \dfrac{1}{2}\)。

等价表述：临界线 \(\operatorname{Re}(s) = 1/2\) 上集中了全部非平凡零点。

**推广形式**：

- **广义黎曼假设（GRH）**：对所有 Dirichlet L-函数同样成立
- **扩展黎曼假设（ERH）**：推广到数域的 Dedekind ζ 函数

## 二、为何困难

核心困难在于：**零点分布是解析性质，而素数分布是算术性质**，二者通过 Euler 乘积

\[
\zeta(s) = \prod_{p\ \text{素数}} \frac{1}{1 - p^{-s}}
\]

相连，但这条连接是"乘法 ↔ 加法"的对应，缺乏同时驾驭两者的工具。

已知的方法论障碍：

1. **Hardy–Littlewood、Selberg 等方法**能证明临界线上有**正比例**的零点（Selberg 1942；Conrey 1989 证明 ≥ 40%），但无法达到 100%
2. **随机矩阵理论**（Montgomery–Dyson）给出零点对关联的精确预测，数值吻合极好——**但这是类比，不是证明**
3. **Hilbert–Pólya 猜想**：零点对应于某个自伴算子的谱。若找到该算子，RH 立即成立。寻找该算子的努力（包括与量子混沌、算术量子化的联系）至今未成功
4. **函数域类比已被解决**（Weil 对有限域上曲线的证明，Deligne 推广），但**数域情形缺少"Frobenius"这一关键结构**——正是这一缺口使类比无法直接迁移

### 关键部分结果

| 年份 | 结果 | 作者 |

## 四、重要性与联系

- **蕴含**（RH ⇒）：

  \[
  \pi(x) = \operatorname{Li}(x) + O\!\left(\sqrt{x}\,\log x\right)
  \]

  即素数计数的最优误差界。此外还蕴含大量数论结论（如 Miller–Rabin 素性检验的确定性版本、某些 L-函数的界等）。

- **被蕴含**：无已知更弱命题蕴含 RH
- **等价表述**（部分列举）：
  - Robin 不等式：对所有 \(n > 5040\)，\(\sigma(n) < e^{\gamma} n \log\log n\)
  - Lagarias 表述：对所有 \(n \ge 1\)，\(\sigma(n) \le H_n + e^{H_n}\log H_n\)
  - Riesz 判据（Riesz 函数增长条件）
  - 某些随机游走/矩问题的表述
- **应用领域**：密码学（部分算法的复杂度分析受 RH 影响）、随机矩阵、量子混沌

## 五、可证伪性

RH 是"全称命题"，因此**可证伪性极明确**：

> 找到**一个**非平凡零点 \(\rho\) 满足 \(\operatorname{Re}(\rho) \ne 1/2\)，即推翻 RH。

这样的反例可以用高精度数值方法确认（需在临界带内精确求解 ζ 零点），因此 **RH 是本库中可证伪性最好的条目之一**。

**注意**：反过来，找到 10¹⁰⁰ 个在临界线上的零点**不能证明** RH。这是 [红线一](../../00-宪章/02-诚实红线.md) 的典型案例。

## 七、常见误解

| 误解 | 澄清 |
| --- | --- |
| "数值验证了万亿个零点，所以基本成立" | **数值验证不是证据**。Pólya 猜想在约 1.8×10³⁶¹ 处才有反例；Mertens 猜想在 10¹⁴ 以内"成立" |
| "RH 成立则素数分布完全确定" | RH 给出**误差项的最优阶**，不代表"精确预测"每个素数 |
| "RH 已被物理方法证明（量子混沌/谱解释）" | Hilbert–Pólya 是**纲领**，不是证明；现有结果的类比性质明确 |
| "ζ 函数方程的证明 = RH 的证明" | 完全不同。函数方程是**已证明的定理**（见 [OM-F-AN-0002](../../02-公式库/分析/OM-F-AN-0002-riemann-zeta-functional-equation.md)），RH 是**未证明的猜想** |
| "RH 只影响数论" | 影响范围远超数论，涉及 L-函数、随机矩阵、复杂度理论 |
