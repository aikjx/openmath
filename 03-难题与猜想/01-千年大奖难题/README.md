# 01-千年大奖难题

> 2000 年 5 月 24 日，美国克莱数学研究所（Clay Mathematics Institute, CMI）公布七个"千禧年大奖难题"，每个悬赏 100 万美元。
> 规则要点：解决者需在**同行评议的权威期刊发表**、并经过**两年以上的社区检验**方可获奖。

## 二、庞加莱猜想（已解决）

**过程**：

- 1904 年 Poincaré 提出：每个单连通的闭三维流形同胚于三维球面
- 1960 年代：Smale 证明 n ≥ 5 维；1982 年 Freedman 证明 n = 4
- 1982 年 Thurston 提出更强的**几何化猜想**
- 2002–2003 年 Perelman 在 arXiv 发布三篇论文，用 **Ricci 流**证明几何化猜想，从而证明庞加莱猜想
- 2006 年三篇独立团队的验证论文确认；Perelman 获 2006 年菲尔兹奖（**拒绝**）
- 2010 年 CMI 授予千禧年奖（**拒绝**，理由包括对奖励机制与 Hamilton 贡献的评价不满）

**本库的两点观察**：

1. **几何化猜想比庞加莱猜想更强**——这是数学中"通过证明更强的命题来解决原问题"的经典案例
2. Perelman 拒绝奖项一事，说明**数学共同体内部的承认机制与奖项机制并不重合**，本库治理设计（[宪章·治理](../../00-宪章/06-治理与决策.md)）明确以证据而非奖励为据

## 三、各题的"常见误解"（教育价值高）

| 问题 | 常见误解 | 正确说法 |
| --- | --- | --- |
| P vs NP | "NP 就是不能在多项式时间内解决" | NP = **非确定性多项式时间**，等价地"解可在多项式时间**验证**" |
| P vs NP | "大家都相信 P ≠ NP，所以差不多了" | 无证明；且存在"自然证明屏障"（Razborov–Rudich）与"相对化屏障"（Baker–Gill–Solovay）说明常用方法行不通 |
| 黎曼假设 | "数值验证了万亿个零点，基本是对的" | 数值验证**不构成证据**（[红线一](../../00-宪章/02-诚实红线.md)）；历史上 Pólya、Mertens 猜想都是前车之鉴 |
| 黎曼假设 | "RH 成立则素数分布完全确定" | RH 给出误差项的**最优阶**，不是"完全确定" |
| Navier–Stokes | "物理上流体是有解的，所以数学问题只是技术困难" | 千禧年问题问的是**存在性与光滑性的严格证明**，与工程计算无关 |
| Hodge 猜想 | "是说每个闭链都是代数的" | 准确表述涉及 **Hodge 类是否有理 (p,p) 型**；整数版本**已被反例推翻**（Atiyah–Hirzebruch） |
| BSD | "椭圆曲线的秩可以算出来" | 秩的计算**无保证终止的算法**；BSD 成立时可通过 L-函数导数判定，但仍是条件性的 |
| 杨–米尔斯 | "物理已经验证了杨–米尔斯理论" | 问题要求的是**数学上构造四维量子杨–米尔斯理论并证明质量间隙**，这是未完成的数学任务 |

## 四、关于"AI 解决了千禧年难题"的宣称

本库立场（适用于**所有**千禧年问题）：

- 截至本文件最后更新，七题中有六题状态为 `OPEN`
- 任何宣称解决者，本库要求：
  1. 公开完整证明（非摘要）
  2. 至少通过 L4 形式化，或经 ≥ 2 名独立专家复核
  3. 在同行评议期刊发表并完成 CMI 规定的两年检验期
- 未满足者一律记录为 `DISPUTED` + `fact_check.status: UNVERIFIED`，**不删除、不采信**
