# 人类最伟大猜想全集：方法、逻辑与归一化框架

> 整理自 OpenMath 知识库 `03-难题与猜想/` 全部子目录（千禧年七大、Hilbert 23、Landau 四题、经典未解、已证伪与反例、独立与不可判定）。
> 本文的**核心贡献**不是罗列猜想，而是把它们的方法与逻辑**归一化**到同一套字段与同一棵方法-逻辑树上，使跨猜想比较成为可能。

---

## 摘要

数学的伟大猜想构成学科的问题边界。本文在 OpenMath 的严格状态机与七层证据协议之上，提出一套**猜想归一化框架**：以 9 态状态机统一所有猜想的"完成度"，以 8 类方法范式统一"用什么做"，以 6 类推理逻辑统一"怎么想"。据此把 7+23+4+数十个猜想逐条归一化为可比记录，并归纳出可复用的解题逻辑模板。结论是：**"完成"在本框架中被重新定义为"经过分级验证且诚实标注证据边界"**，而方法的可迁移性远高于结论本身。

**关键词**：猜想；归一化；方法范式；推理逻辑；状态机；形式化；反例优先。

## 1. 归一化框架定义

### 1.1 状态归一化（9 态状态机）

所有猜想统一映射到以下状态，禁止混用（如 `UNDECIDABLE` 不得误标 `OPEN`）：

| 状态 | 含义 | 例 |
|---|---|---|
| `OPEN` | 未解决，无被接受证明 | 黎曼假设、P vs NP |
| `PARTIAL` | 有实质性部分结果 | 孪生素数（有界间隔 246）、哥德巴赫（1+2） |
| `RESOLVED` | 同行评议接受并复现的证明 | 庞加莱、费马大定理 |
| `RESOLVED_CA` | 已解决但依赖计算机辅助 | 四色定理、Kepler |
| `DISPUTED` | 宣称证明但社区未共识 | abc 猜想（IUT 争议） |
| `REFUTED` | 已被反例推翻 | Pólya、Mertens、Euler 幂和 |
| `UNDECIDABLE` | 在某公理系统既不能证也不能否证 | 连续统假设 |
| `UNCOMPUTABLE` | 不存在算法判定 | Hilbert 第十、停机问题 |
| `ILL_POSED` | 问题本身表述不精确 | Hilbert 第四、第二十三 |

### 1.2 方法范式归一化（8 类 `M`）

| 码 | 方法范式 | 典型技术 | 代表猜想 |
|---|---|---|---|
| `M1` | 解析 / 数论方法 | 复分析、ζ 函数、圆法、筛法、大筛、GPY 筛 | 黎曼假设、孪生素数、弱哥德巴赫 |
| `M2` | 代数 / 数论方法 | 互反律、模性提升、Langlands、分圆域 | 费马大定理、Catalan、Serre 模性 |
| `M3` | 代数几何方法 | 上同调、motivic 上同调、Hodge 类 | Hodge、Milnor、Andre–Oort |
| `M4` | 几何 / 拓扑方法 | Ricci 流、几何化、微分拓扑、等变同调 | 庞加莱、Kervaire、三角化（否定） |
| `M5` | 计算机辅助 + 形式化 | 放电法、区间算术、Flyspeck、穷举 | 四色、Kepler、Lorenz |
| `M6` | 逻辑 / 集合论方法 | 力迫法、内模型、反推数学 | 连续统假设、Hilbert 第十 |
| `M7` | 组合 / 图论方法 | 多项式方法、随机矩阵、交错多项式 | Erdős 不同距离、Kadison–Singer |
| `M8` | 计算理论方法 | 对角化、归约、屏障论证 | P vs NP、停机问题 |

### 1.3 推理逻辑归一化（6 类 `L`）

| 码 | 推理逻辑 | 说明 |
|---|---|---|
| `L-A` | 归约到更强命题 | 证明更强的命题 ⇒ 原命题（几何化 ⇒ 庞加莱） |
| `L-B` | 反证 / 屏障论证 | 证明"不可能"（力迫否定、自然证明屏障、相对化屏障） |
| `L-C` | 构造 / 存在性 | 给出显式对象或存在性证明（Littlewood 先证存在后构造） |
| `L-D` | 交叉验证 | 多引擎/多路径取最严格，反例优先 |
| `L-E` | 大规模协作 | 数百人、上万页的分布式证明 |
| `L-F` | 反推 / 强度量化 | 反推定理需要多强的公理系统（Big Five） |

### 1.4 统一元数据结构（每条猜想的归一化字段）

```
 conjecture:
   id: OM-P-<域>-<序号>
   name_zh / name_en
   domain: <MSC 域码>
   status: <9态之一>
   method: [M1..M8]          # 实际所用方法范式
   logic:  [L-A..L-F]        # 所用推理逻辑
   key_result: <最佳部分结果/结论>
   solver: <作者, 年份>
   falsifiability: <什么发现会推翻它>
   honest_boundary: <诚实边界/常见误解>
   evidence_level: <Lx>
```

## 8. 方法 × 逻辑 归一化矩阵（可复用解题模板）

| 方法范式 | 高频逻辑 | 典型产出状态 | 代表 |
|---|---|---|---|
| M1 解析/数论 | L-D 交叉、L-C 构造 | `RESOLVED`/`PARTIAL`/`OPEN` | 黎曼、孪生素数 |
| M2 代数/数论 | L-A 归约、L-D | `RESOLVED` | 费马、Serre 模性 |
| M3 代数几何 | L-C 构造、L-A | `RESOLVED`/`PARTIAL` | Hodge、Milnor |
| M4 几何/拓扑 | L-A 归约到更强命题 | `RESOLVED` | 庞加莱、Kervaire |
| M5 计算机辅助 | L-D 交叉 + 形式化 | `RESOLVED_CA` | 四色、Kepler |
| M6 逻辑/集合论 | L-B 屏障、L-F 反推 | `UNDECIDABLE`/`UNCOMPUTABLE` | CH、Hilbert 第十 |
| M7 组合/图论 | L-C 构造、L-D | `RESOLVED`/`PARTIAL` | Kadison–Singer |
| M8 计算理论 | L-B 屏障论证 | `OPEN`/`UNCOMPUTABLE` | P vs NP |

**可迁移逻辑模板**：
1. **能归约就归约**（L-A）：庞加莱靠几何化、费马靠模性提升、有限单群靠分类——证明更强的命题往往更简单。
2. **要证"不可能"用屏障**（L-B）：力迫法（独立性）、自然证明屏障 / 相对化屏障（P≠NP）、对角化（不可计算）。
3. **反例优先于通过**（L-D）：Pólya/Mertens 证明数值验证的脆弱；反例搜索只记上界、不升级等级。
4. **计算机辅助必须形式化**（M5）：四色、Kepler、Lorenz 依赖放电法/区间算术，最终以 Lean/Coq 复核才承认 `RESOLVED_CA`。
5. **量化"需要多强公理"**（L-F）：反推数学把"是否可证"转化为"在哪个系统可证"，是独立性问题的统一框架。

## 9. 结论与诚实边界

1. **归一化的价值**：把 7+23+4+数十个猜想压到 9 态状态机、8 类方法、6 类逻辑的三棵小树上，使跨猜想的方法迁移一目了然——方法范式的可复用性远高于单个结论。
2. **"完成"的重新定义**：在本框架中，`RESOLVED` 必须给年份/作者/文献，`DISPUTED` 须并列双方论据，`REFUTED` 永久保留且禁止改定义绕过，`UNDECIDABLE` 是高价值知识而非失败。
3. **哥德尔天花板（不可绕过）**：任何足够强的数学统一纲领，都不可能同时做到（a）涵盖全部数学真理、（b）自证一致、（c）递归可公理化。这是对"数学统一场论"的根本约束。
4. **本库现状诚实披露**：验证中心 L4=0，没有任何条目可称"已证明"；L0–L3 只筛错，L4 才确认真理。
