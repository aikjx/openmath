# 03-难题与猜想

> 数学的难题档案：未解的、已解的、已证伪的、以及**已被证明不可判定的**。
> 本目录的核心信念：**"已证明不可判定"是最高质量的知识之一，不是失败的记号。**

## 一、为什么单独设一个目录

难题的价值不在于"没做出来"，而在于：

1. **它们定义了领域的边界**——围绕着黎曼假设发展出的解析数论，比假设本身更有价值
2. **它们的部分结果是真实的进展**——有界素数间隔不是孪生素数猜想，但它是实质性突破
3. **它们的证伪同样重要**——Pólya 猜想、Mertens 猜想的反例教育了整个世纪
4. **它们是 AI 幻觉的重灾区**——"AI 证明了黎曼假设"式的宣称每个月都在出现

因此本目录对**状态标注的严格程度是全库最高的**。

## 二、状态定义（比通用状态机更细）

| 状态 | 含义 | 例 |
| --- | --- | --- |
| `OPEN` | 未解决，无被接受的证明 | 黎曼假设 |
| `PARTIAL` | 有实质性部分结果，但核心未解决 | 孪生素数猜想（有界间隔已解决） |
| `RESOLVED` | 已有被同行评议接受并复现的证明 | 庞加莱猜想 |
| `RESOLVED_CA` | 已解决但依赖计算机辅助证明 | 四色定理、Kepler 猜想 |
| `DISPUTED` | 存在被宣称的证明但社区未达成共识 | abc 猜想 |
| `REFUTED` | 已被反例推翻 | Pólya 猜想 |
| `UNDECIDABLE` | 已被证明独立于某公理系统 | 连续统假设 |
| `UNCOMPUTABLE` | 已被证明不可判定（非独立，是不可计算） | Hilbert 第十问题 |
| `ILL_POSED` | 问题本身表述不够精确 | Hilbert 第四问题 |

**强制规则**：

- 不得用 `OPEN` 描述 `UNDECIDABLE` 的问题（[红线六](../../00-宪章/02-诚实红线.md)）
- `RESOLVED` 必须给出年份、作者、文献
- `DISPUTED` 必须同时列出支持方与反对方的论据

## 四、条目模板

见 [`_模板/问题条目模板.md`](_模板/问题条目模板.md)。

**每个条目必须回答的六个问题**：

1. 精确陈述是什么？（含所有量词与限定条件）
2. 谁在什么时候提出的？
3. 当前状态是什么？（附证据）
4. 有哪些部分结果？
5. 为什么它重要？（蕴含什么、被什么蕴含）
6. **它可能被什么推翻？**（可证伪性说明）

第 6 问是最常被忽略的。一个说不清"什么样的发现会推翻它"的问题，往往表述有问题。

## 五、AI 相关的特别政策

### 关于"AI 证明了 X"类宣称

本库对这类宣称采用**三不原则**：

1. **不预设为真**：需要可复现的形式化或完整人类可核验的证明
2. **不预设为假**：若确实给出可检验证明，同等对待
3. **不删除记录**：即使被判定为无效宣称，也保留在 `08-已证伪与反例库/` 或专设的"宣称记录"中，并标注判定依据

### 近期结果的收录政策

对**尚未完成同行评议**的近期声明（如预印本）：

- 默认 `fact_check.status: UNVERIFIED`
- 状态为 `DISPUTED` 或 `OPEN`（不得标 `RESOLVED`）
- 记录来源（arXiv 编号）+ 归档日期
- 明确注明"待同行评议"

**这条政策适用于所有来源，包括人类数学家的预印本**——不是针对 AI，而是针对一切未经充分检验的宣称。

## 六、统计现状（诚实）

```
总条目数：      ~60（索引级）
完整条目：       2（黎曼假设 OM-P-NT-0001、第 n 个素数低复杂度公式 OM-P-NT-0002）
简表条目：       ~55
待补充：         其余全部（数以百计）
```

> ID 唯一性：黎曼假设 = `OM-P-NT-0001`（千禧年大奖难题档案的 `.md` 条目）；
> 第 n 个素数的低复杂度公式 = `OM-P-NT-0002`（数论/经典未解猜想的 `.yaml`+`.md` 记录）。
> 二者 ID 已从最初的冲突修正为不同序号，全库 ID 唯一。

**我们不追求快速填满这个目录。** 每个难题条目都需要核查状态、文献、部分结果，这是高度依赖专业知识的工作。宁可少而准。
