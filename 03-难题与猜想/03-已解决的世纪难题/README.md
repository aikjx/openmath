# 03-已解决的世纪难题

> 已解决的问题同样是资产。本目录不只记录"谁解决了什么"，更记录**解决过程中的方法论**——这才是后来者可复用的部分。

## 一、为什么单列"已解决"

1. **方法论价值**：Wiles 用的模性提升、Perelman 用的 Ricci 流、Hales 用的形式化验证，都是可迁移的工具
2. **反面教材**：某些"已解决"依赖计算机辅助，引发关于"什么是证明"的持续争论
3. **防止重复劳动**：明确记录已解决，避免有人重新尝试
4. **诚实校准**：真实地展示"解决一个问题要多久"——多数是几十年

## 三、三种"解决"方式（方法论分类）

### A. 人类可完整阅读的证明

例：费马大定理、庞加莱猜想、素数定理

- 特点：证明可写成长度有限（虽可能数百页）的可读文本
- 验证方式：专家逐行复核
- 本库对应等级：L5（多人复核）或 L4（若已形式化）

### B. 计算机辅助证明

例：四色定理、Kepler 猜想、Lorenz 吸引子

- 特点：证明的一部分是穷举/区间算术计算，人类无法逐行阅读
- 关键问题：**如何信任软件？**
- 解决路径：**形式化**（用 Coq/Isabelle/Lean 重新验证）
- 本库对应等级：**必须 L4**（否则不承认 RESOLVED_CA）

### C. 大规模协作证明

例：有限单群分类（数百人、上万页）

- 特点：没有任何单人完全掌握全部证明
- 风险：局部错误难以发现（历史上确实发现过缺口并修补）
- 本库立场：状态标 `RESOLVED` 但必须注明"存在协作规模导致的可核查性问题"

## 四、"已解决"之后仍开放的问题

诚实提醒：**很多"已解决"的问题留下了更深的开放问题**：

| 费马大定理 | 更一般的 abc 猜想（**争议中**） |
| 有界素数间隔 | 孪生素数猜想（间隔是否可为 2） |
| 庞加莱猜想 | 四维光滑 Poincaré 猜想 |
| 球堆积 d=3, 8, 24 | 其余维数 |
| 有限单群分类 | 第三代重写（GLS 计划） |
