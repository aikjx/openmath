# 08-已证伪与反例库

> **反例是数学中信息密度最高的对象之一。**
> 一个定理告诉你什么成立；一个反例告诉你**直觉在哪里失效**。

## 一、为什么这是本库最被低估的资产

1. **教育价值**：反例直接揭示"为什么需要某个假设"
2. **证伪效率**：推翻一个猜想只需一个对象，成本远低于证明
3. **AI 训练价值**：反例库是检验 AI 数学能力的**最佳测试集**（因为答案明确、可判定）
4. **防止重复错误**：被推翻的猜想如果不记录，会有人再次提出

**本库政策**：`FALSIFIED` 条目**永不删除**，且状态为终态。

## 二、经典被证伪的猜想

| 猜想 | 反例 | 年份 | 教训 |
| --- | --- | --- | --- |
| **Pólya 猜想**（对 n>1，≤n 的整数中奇因子个数为偶数的占多数） | 最小反例约在 9×10⁸ 量级（后续给出更小者） | 1958（Haselgrove 证明存在反例） | **数值验证的极限**：反例远超当时可计算范围 |
| **Mertens 猜想**（\|M(n)\| < √n） | 通过格基约化（LLL）证明存在反例，首个显式上界极大 | 1985（Odlyzko–te Riele） | 数值到 10¹⁴ 仍"成立"，**但被证明为假** |
| **π(x) < li(x)**（素数计数函数小于对数积分） | 首个反例在 Skewes 数附近（极大） | 1914（Littlewood 证明会无穷次反转） | **存在性证明先于构造**：先证明有反例，很久后才给出显式上界 |
| **Euler 幂和猜想**（n 个 n 次幂之和需要至少 n 项） | 27⁵ + 84⁵ + 110⁵ + 133⁵ = 144⁵ | 1966（Lander–Parkin） | 直觉在小样本上成立，但反例存在 |
| **Keller 猜想**（高维立方体平铺必有面相接） | 维数 ≥ 8 有反例 | 1990s（后续改进到 d≥8） | 低维直觉在高维失效 |
| **Borsuk 猜想**（d 维集合可分成 d+1 个更小直径的部分） | 高维反例 | 1993（Kahn–Kalai） | 维数增长使直觉失效 |
| **三角化猜想**（所有流形可三角化） | 维数 ≥ 5 的反例 | 2013（Manolescu） | 一个长期"默认正确"的假设被推翻 |
| **Hauptvermutung**（同胚的单纯复形必组合等价） | 反例 | 1960s（Milnor 等） | 拓扑与组合的鸿沟 |
| **Euler 36 军官问题** | 不存在（6×6 正交拉丁方） | 1900（Tarry 穷举） | 早期计算机前的穷举证明 |
| **Hilbert 第十四问题**（不变量环有限生成） | Nagata 的反例 | 1959 | 见 [02-希尔伯特23问题](../02-希尔伯特23问题/README.md) |
| **Hilbert 第三问题**（等体积四面体剖分等价） | Dehn 不变量给出反例 | 1900（Dehn） | Hilbert 问题中最快被解决者之一 |
| **von Neumann–Wigner"无交叉"规则过于绝对** | 存在交叉 | — | 需谨慎（本条需核实表述后收录） |

> ⚠️ 表中部分条目的具体数值（如 Pólya 猜想的最小反例）在文献中有不同版本。**引用前请核查原始文献**；本表给出的是量级与教训，不是精确数值。

## 三、反例的类型学

| 类型 | 特征 | 例子 |
| --- | --- | --- |
| **小反例** | 可显式写出、可手工验证 | Euler 幂和猜想的 5 个数 |
| **存在性反例** | 证明存在但给不出具体值 | Littlewood 的 π(x) − li(x) 变号 |
| **巨大反例** | 存在但超出可计算范围 | Pólya 猜想、Mertens 猜想 |
| **构造性反例** | 给出一族构造 | Nagata 的不变量环 |
| **条件性反例** | 依赖未证假设（**不算真反例**） | "若 RH 成立则 X 不成立" |
| **计算反例** | 依赖穷举/计算机验证 | 36 军官问题 |

**强制标注**：条件性反例必须标 `conditional: true`，**不得**用于推翻条目（因为依赖的假设本身可能不成立）。

## 四、反例搜索（与验证中心的接口）

本目录是 [05-验证中心/06-探针](../../05-验证中心/06-探针/README.md) 的**输入源**：

```
本目录的 OPEN 猜想 ──> 探针生成候选反例 ──> SAT/SMT/穷举/随机搜索
                                              │
                          找到 ───────────────┤
                                              │
                         未找到（记录搜索上界）┘
```

**关键纪律**：未找到反例**不升级证据等级**，只记录"搜索上界"。
