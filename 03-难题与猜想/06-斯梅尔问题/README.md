# 06-斯梅尔问题

> 1998 年，Steve Smale 应 Vladimir Arnold 之邀（仿照 Hilbert 1900 的先例），提出**面向 21 世纪的 18 个数学问题**。

## 一、与 Hilbert 问题的类比

| | Hilbert 1900 | Smale 1998 |
| --- | --- | --- |
| 数量 | 23 | 18 |
| 背景 | 19 世纪数学的总结 | 计算与复杂性兴起的时代 |

## 三、最有特色的两个问题

### 1. "线性规划是否有强多项式算法"

这是 Smale 列表中**最有计算特色**的问题之一：

- 单纯形法在实践中极快，但有指数时间的病态例子（Klee–Minty）
- 内点法是多项式时间的，但**不是强多项式**（依赖于输入矩阵的数值规模）
- 是否存在强多项式算法（复杂度只依赖维数，与数值大小无关）——**至今未知**

这与 P vs NP 密切相关，但**不等价**。

### 2. "人工智能的极限"

Smale 在 1998 年就把学习理论列入数学问题，具有前瞻性。本库对这一条的处理：

- 表述为开放问题（"学习问题的数学极限是什么"）
- 关联到 [16-交叉与新兴/AI×数学](../../01-数学体系/16-交叉与新兴/README.md)
- **明确区分**："AI 能做到什么"是技术问题；"学习是否具有数学极限"是可形式化的问题

## 四、与千年大奖难题的重叠

有 5–6 个问题同时出现在两个列表中（RH、P vs NP、Poincaré、NS、Hodge、BSD）。这反映了一个事实：

> **世纪之交的数学共同体对"最重要的问题"有相当高的共识。**

同时也要注意：**共识不等于正确**。问题被反复列出，也可能因为它恰好属于"表述清晰但工具缺失"的类型——而真正重要的突破往往发生在未被列出的地方。
