# 强哥德巴赫猜想 — 未证问题清单（整理稿）

> 整理时间：2026-09-22。口径：本清单只列**未证明 / 未闭合**的问题与已证负结果；已证为真的正向结论不列入（除非作为"某路线为何不行"的依据）。
> 状态标注：`OPEN` = 完全未证；`COND` = 条件性 / 部分；`NEG` = 已证不行（负结果）。
> 诚实红线：强哥德巴赫猜想状态 = **OPEN**，本清单不含任何"已证 / 100% / 终极"宣称。

## 〇、核心主问题

- **P0 强哥德巴赫猜想（OPEN）**：每个偶数 $N \ge 4$ 可表为两素数之和。已验证至 $4 \times 10^{18}$（Oliveira e Silva–Herzog–Pardi, Math. Comp. 83, 2014, 2033–2060），但 $\forall N$ 未证。

---

## 一、精确数学缺口（突破靶心 A–E + 唯一缺失不等式）

这些是现有数学下**唯一可能越障的把手**；目前**无一被填满**。

- **P1 靶心 A — 分布水平越过 1/2（OPEN）**：需素数在相关模上的水平 $D > N^{1/2+\delta}$（即 Elliott–Halberstam 在 $\theta>1/2$ 成立）。无条件仅 Bombieri–Vinogradov（$\theta<1/2$），"差一个 $\varepsilon$"。
- **P2 靶心 B — 双线性 / 弥散法打破 parity barrier（OPEN，最缺结构）**：奇偶障碍只约束**非负权**筛。Friedlander–Iwaniec (2004, $X^2+Y^4$) 已证可越障，但集合 $\{N-p : p\text{ 素数}\}$ 无已知此类代数 / 相消结构。需为它构造可证相消的结构。
- **P3 靶心 C — 圆法 + 真正 minor-arc 相消（OPEN，归约到 P1）**：需 minor-arc 上 $\sum_{p\le N} e(\alpha p)$ 足够小，等价于 P1。
- **P4 靶心 D — 新恒等式 / 结构引理绕过筛法（OPEN，空白）**：例如构造可证 $G(N) \ge 1$ 的"Goldbach 泛函"。范式转移候选，目前无任何具体候选。
- **P5 靶心 E — 条件归约（OPEN，不计进度）**：把猜想归约到某"差一点就证"的猜想；归约目标本身仍 OPEN ⇒ 不增加进度分子。
- **P6 唯一缺失不等式（OPEN）**：一致界 $|\text{minor-arc 误差}| < M(N)-1$（对所有大 $N$ 一致）。等价于 P1 / P3。这是把障碍**精确钉到**的那一条不等式。

## 三、已证不行的路线（负结果，列出以防重复投入）

- **N1 parity barrier（NEG，定理）**：非负权筛在 $s=1,\ u=2$ 下界恒为 0；非零下界必须引入 Möbius 型相消。
- **N2 加性组合密度不足（NEG，本轮 Attack A）**：$|P+P|$ 的平凡下界仅占偶数总数的 $\sim 30\%$（$N=2\times10^6$），**密度 $\neq$ 覆盖每个偶数**。
- **N3 "至多 vs 恰好"质变缺口（NEG 结构事实）**：$\le 4$ 个素数之和已无条件证；$\le 3 \iff \le 2 =$ 猜想，中间无任何台阶。
- **N4 反证法固定阶容斥不可行（NEG，A′）**：Bonferroni 截断判定反例不可行（三阶下界 $N=1000 \to -3$ 空谈），与 parity barrier 数值吻合。
- **N5 "每步删去量非负"辅助假设为假（NEG）**：$\Delta_{11}(2168)=-1$ 否证该全称假设；任何依赖单调性的路线须重建。
- **N6 "339 整除证书"非全局（NEG）**：$339=\delta(N_T)/2$ 只锁定一个最差偶数，不证阈值全局不可降，更不证猜想。
- **N7 生成式 / 和集覆盖路线（NEG）**：其判别条件（"两最大素数之和 > 某值"）**恒真无判别力**；"取最大"方向与实际覆盖方向相反；受限生成集必留空隙 ⇒ 不能证全覆盖。

## 四、外部候选理论的未证 / 缺陷

- **P11 王永启"素数无穷套娃公式"（OPEN / 缺陷）**：
  - **循环论证**：全部"定理"建立在"假设 `isComposite(x)` 完备"上，而完备 `isComposite` 即素性判定本身，体系未提供。
  - **唯一具体操作判定（第五节）经独立验证漏判率 97.1%**：奇数合数 9–1999 中 677/697 误判为素数（含 9, 15, 25, 27, 35, 49…）。
  - **与 Goldbach 无关**：是素数枚举方案，不产出"偶数 = 两素数之和"的存在性论证。
  - 结论：不构成证明，也不落在靶心 A–E 任一上。

---

## 五、有限验证与计算缺口

- **P12 有限验证天花板（OPEN）**：已证 $\forall N \le 4\times10^{18}$，但 $\forall N$ 未证；且无已知单调性能外推（N5 已否证单调性假设）。
- **P13 表示数下界缺失（OPEN）**：无对所有 $N$ 成立的 $r(N)$ 显式正下界（已知例外集密度为 0，但密度 0 $\neq$ 空集）。
