# OM-P-NT-0010 · Andrica 猜想

> **状态：OPEN。** 本条目不提供任何进展，只提供**等价形的精确化、一条已机械核对的蕴含，以及一个错标的更正**。

\[
\forall k\ge 1,\qquad \sqrt{p_{k+1}}-\sqrt{p_k}\;<\;1
\]

## 一、三型互推，但本库不靠推导自证

\[
A_k:=\sqrt{p_{k+1}}-\sqrt{p_k}<1
\quad\Longleftrightarrow\quad
g_k<2\sqrt{p_k}+1
\quad\Longleftrightarrow\quad
(g_k-1)^2<4p_k
\]

第三型是**纯整数**判据，于是"猜想在这一格成立吗"这件事可以不用浮点回答。
引擎 `08-工具/examples/verify_OM-P-NT-0010.py` 用两条互不相干的整数通道逐格判前两型与第三型：
平方路线，以及 \(2^{60}\) 定点平方根路线（`isqrt(p·4^60)` 给 \(\sqrt p\) 的严格下界）。
现数（载体 `scratch/T11_VERIFY_NT0010.txt`）：上界 \(p_k<3\times10^{7}\) 内素数 1857859 枚、间隙 1857858 枚，
两通道**违反 0 枚、异判 0 枚、定点缝内未决 0 枚**——这才是"等价式没写反"的证据，
而不是注释里那两行推导。

## 二、上确界在哪一格（一个诚实的读数）

同一张面在 50 dps 下复核浮点筛出的 20 名候选：

| 量 | 读数 |
| --- | --- |
| 最大 \(A_k\) | \(A_4=0.670873479290809258613316983031\)（\(p_4=7,p_5=11,g=4\)） |
| 亚军 | \(A_{30}=0.639281856849995474850881776814\)，差 \(0.03159162244\) |
| 分段极大 | 0.670873／0.463722／0.203053／0.108882／0.056651／0.023005（\(k\) 段依次 \(10^2,10^3,10^4,10^5,10^6\) 到界） |

分段极大**单调下降**，与启发式 \(A_k\approx g_k/(2\sqrt{p_k})\to0\) 同向。
但这**不**证明 \(\sup_k A_k=A_4\)：上界以内无反例只说明这一段里没有反例（红线一）。
到反证线的整数余量 \(4p_k-(g_k-1)^2\) 在全扫描的最小值是 8（\(k=1\)，即间隙 \(2\to3\)）——
最小余量出现在最小的 \(p\) 处，这一点本身也是"越大的 \(p\) 越安全"的读数。

## 三、本条目存在的直接理由：一处错标的更正

`OM-P-NT-0009`（Landau 第三问题 · Legendre 猜想）自 2026-09-18 起把

> 素数间隙形式：记 \(p_k\) 为第 \(k\) 个素数，则 \(g_k<2\sqrt{p_k}+1\)

列在自己的 `equivalent_forms` 名下。**那一式与本草稿三型等价，但它是 Andrica 猜想，不是 Legendre 猜想的等价形式。**
两者的正确关系是单向的：

\[
\text{Andrica}\ \Rightarrow\ \text{Legendre},\qquad\text{反向未证。}
\]

推导只需一枚不等式：设 \(p_k\) 是不超过 \(n^2\) 的最大素数，则

\[
p_{k+1}<( \sqrt{p_k}+1 )^2\le (n+1)^2,\qquad p_{k+1}>n^2,
\]

第一步是 Andrica，第二步是 \(\sqrt{p_k}\le n\)（按 \(p_k\) 的定义）。
引擎把这两步在 \(n=1..5476\) 逐窗口机械执行：界步整数化后的最小余量
\((n^2-p_k+2n)^2-4p_k=13\) @ \(n=2, p_k=3\)（非负即闭合），
Andrica 那一步在被触及间隙上的最小整数余量 11 @ \(n=2\)，空窗 0 个（同一张载体，判定4a–4c）。

**反向为什么不显然，也有一个现数的量。** Legendre 的每个窗口只调用 \(k=\pi(n^2)\) 那一枚间隙：
5476 个窗口只触及 1857858 枚间隙中的 5476 枚＝**0.2947%**（载体同上，判定4d）。
其余 99.7053% 的间隙即便违反 \(A_k<1\)，也不在任何 Legendre 窗口的管辖之内。
注意这条读数的地位：它否证的是"把间隙逐枚读成窗口条件"这条**推导通道**，
它**不是**"两命题不等价"的证明——那需要一个 Legendre 成立而某枚间隙违反 \(A_k<1\) 的模型，本库没有。

## 四、与第二台仪器的交叉核对

`OM-P-NT-0009` 的 `landau_scan.py` 在 \(n=1..2000\) 上印 \(\min c(n)=2\) @ \(n=1\)；
本引擎在同一张面上只对 \(n=1..2000\) 一段现算，印出的仍是 2 @ \(n=1\)。
两台仪器、一段重叠区间、同值——这不构成对猜想的任何加强，只说明两个筛没有互相说谎。
