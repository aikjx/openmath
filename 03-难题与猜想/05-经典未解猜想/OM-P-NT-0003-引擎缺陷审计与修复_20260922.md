## 1. 审计方法：不靠"看起来对"

四步闭环，每一步都留下可复核的落盘证据（产物在 `scratch/`，不进版本库）：

1. **基线快照**：修复前先把 5 个引擎的 JSON 全量存档为 `BEFORE_*.json`。
2. **单点探针定位**：对可疑公式构造**最小反例探针**（例如 `probe_rpp_diagonal.py` 直接对拍公式与暴力枚举），
   用"哪个 $N$ 上不符、符不符合某类结构"定位根因，而不是靠阅读代码猜。
3. **最小改动 + 单一真源**：复合指标抽成唯一函数，其余调用点全部改为调用它，杜绝"两处各写一遍"。
4. **重跑对拍**：修复后重跑，把字段严格分成两类——
   **必须 IDENTICAL**（结论性字段）与**预期会变**（受缺陷影响的字段），逐条裁定，不允许"整体漂移"含糊通过。

## 2. 缺陷清单

### D1（严重）$R_{pp}$ 对角项被重复计数

- **文件**：`goldbach_counterexample_20260922.py`
- **症状**：$\rho(N)=R_{pp}(N)/(S(N)\cdot N/2)$ 在 $N=2p$ 处系统性偏高。
- **根因**：旧实现对 $p\le q$ 一律累加 $2\log p\log q$，随后又额外加一次 $\log(N/2)^2$，
  于是**对角项（$p=q=N/2$）被计 3 次**，多计 $2\log^2(N/2)$。正确权重应为：$p<q$ 计 2、$p=q$ 计 1。
- **证据**（`probe_rpp_diagonal.py`）：$6\le N<2000$ 内 997 个偶数中 **167 个不符，且恰为全部 $N=2p$**。
  例：$N=34$ 的 $\rho$ 被抬高到 1.2009，真值 0.8656。
- **修法**：抽出 `count_and_rpp(N, odd_primes, is_prime)` 作**唯一真源**；新增独立枚举自检
  `rpp_by_full_enumeration` + `rpp_selfcheck`（抽样 201 个 $N$，相对容差 $10^{-11}$，**0 不符**）。
- **回归**：decade 表 median/max 下降（见 §3），`argmin` 未移动；锚点不受影响（其 $N/2$ 非素数）。

### D2（高）循环变量未逐轮重置，掩盖反例

- **文件**：`export_lambda_curve_20260922.py`、`goldbach_prime_side_20260922.py`
- **症状**：若某个偶数**没有**素对，代码会**沿用上一轮**的 $\lambda$ / $q$，把"未命中"伪装成"命中"。
- **根因**：命中标记变量在循环外初始化一次。
- **修法**：每轮开头重置（`lam = 0` / `q = 0`），并新增 `missing` 集合与
  `unrepresentable_count` 输出字段——**把静默失败变成可观测计数**。
- **回归**：`unrepresentable_count = 0`，即 $6\le N\le 2\times10^6$ 内**确无**未覆盖偶数；
  这个 0 现在是**真的** 0，而不是"变量没重置造成的 0"。

### D3（中）339 的口径错位：单点窗口 vs 沿 $N$ 聚合

- **文件**：`goldbach_coverage_frontier_20260922.py`
- **症状**：字段 `certificates_claim_339.match_any` 恒为 `False`，与已破译的结论（339 是可解释的）矛盾。
- **根因**：比对的一方是**单点证书窗口内的奇数个数**，另一方是**沿 $N$ 聚合的计数**——维度不同。
- **修法**：补字段 `decoded_single_point`（339 $=\delta(N_T)/2$，`match=True`），保留旧聚合口径并注明其边界。
- **回归**：`p3.certificates_claim_339.match=True`，`decoded.match=True`。

### D4（中）渲染器：字体度量与代码块

- **文件**：`render_paper_pdf_20260922.py`
- **症状 a**：换行宽度用**上一段的字号**计算，长段换行位置错乱。
  根因：`para()` 先 `wrap()` 后 `set_font()`，而 `wrap` 依赖 `get_string_width` 的**当前字体度量**。修法：调整顺序为**先 `set_font` 再 `wrap`**。
- **症状 b**：代码块绕过符号替换，$\Rightarrow$ / ✅ / ℙ 等直接触发缺字形。
  修法：代码块过 `ascii_safe()`（只做安全替换，不做数学清理）。

### D5（严重）展示公式完全未被处理

- **文件**：`render_paper_pdf_20260922.py`
- **症状**：旧记录 PDF 里残留 `\boxed`、`\mathbb`、`\\` 等**上百处**。
- **根因**：旧版只在段落里处理**单行** `$...$`；跨行的 `$$...$$` 与全部 `\[...\]` **完全没被处理**，
  而旧记录大量使用 `\[...\]`。
- **修法**：新增 `collapse_display_math()`，用 DOTALL 同时吞掉 `$$...$$` 与 `\[...\]` 并送入 `clean_math`；
  新增 `strip_front_matter()` 去除 YAML 头；补齐 `\begin/\end{env}`、`\\`（cases 行分隔 $\to$ " ; "）等映射。
- **回归**：见 §4，残留计数从 162/24/4 降到 0。

### D6（中）校验器只校验第 1 份 PDF

- **文件**：`verify_pdf_and_cleanup.py`
- **症状**：硬编码单份文件名，后续新增的论文 PDF **从未进入校验范围**（"绿灯"是假的）。
- **修法**：改为自动发现 `OM-P-NT-0003-*.pdf` 逐份校验。

### D7（严重）正文与表格里的"裸 LaTeX"泄漏 + 基数竖线被吞

- **文件**：`render_paper_pdf_20260922.py`
- **症状**：表格单元格与正文里的 `\|X\|`、`\mathbf{-3}`、`\bigl|`、`\setminus` 等**未被 `$..$` 包住**的
  片段不被 `clean_math` 接管，反斜杠与命令名原样排进 PDF。
- **附带症状**：`plain()` 把 `|` 一律替换为空格，于是基数符号 $\|X\|$ 被渲染成 `X`（**信息丢失**）。
- **修法**：
  1. 新增 `deslash()` 兜底：先重跑符号表，再把未识别命令降级为纯名字，最后清除所有残留反斜杠；
  2. 用占位符保护 `\|` 与数学环境内的 `|`，行末还原为可见竖线；
  3. **按实测频次表**（`census_commands.py` 普查 8 份 md 的全部 `\命令名`）补齐 30 余条映射——
     含 `\bigl/\bigr/\Bigl/\Bigr/\left/\right`（纯定界修饰，旧版会把 "bigr" 当文字排出）、
     `\bigcup/\bigcap`、`\checkmark`、`\sqrt`、`\tag`、`\pmod`、`\mathbf/\texttt/\mathcal/\overline` 等。
- **回归**：8 份 PDF 的**裸反斜杠计数全为 0**；HARD 命令名计数全为 0。

### D8（严重）字体缺字形导致静默丢字

- **文件**：`render_paper_pdf_20260922.py`、`render_all_papers.py`
- **症状**：渲染 stderr 报 `Font MPDFAA+NotoSansSC is missing the following glyphs: '₁' 'ₖ' 'ᵢ' '∤' …`。
  这些字符在 md 里是**内容**（如 $\alpha_i$、$p_k$、$E_0$ 的 Unicode 写法），缺字形时 fpdf2 **静默画空白**。
- **根因**：内容直接使用 Unicode 上下标；两款字体（NotoSansSC / DengXianBold）均不覆盖。
- **修法**：
  1. 在 `FIX` 表加入**全部** Unicode 下标/上标 $\to$ ASCII 映射（`ᵢ`→`_i`、`⁶`→`^6`、`₊`→`_+` …）；
  2. 实测缺字形的符号改用公认 ASCII 等价写法：`∖`→`−`（差集）、`↦`→`→`、`⌊⌋`→`[]`、`∅`→`Ø`、`∤`→`!|`；
  3. **把字体警告升级为门禁**：批量渲染器挂 logging 句柄捕获 `missing the following glyphs`，
     出现即返回非 0 退出码——**静默丢字不可能再蒙混过关**。
- **回归**：缺字形警告 **5 条 $\to$ 0 条**。

## 5. 方法学沉淀（可复用的判定规则）

1. **循环里"是否命中"的标记变量必须逐轮重置**。否则上一轮的值会冒充本轮的结论，
   症状是"看起来全命中"，而后果是**掩盖反例**——这是本次审计中最危险的一类缺陷。
2. **复合指标抽成单一真源函数 + 独立枚举自检**。自检要独立于主实现的算法路径（此处用暴力枚举），
   且容差用**相对**容差：$10^6$ 量级的求和顺序噪声有 $10^{-8}$ 量级，用绝对容差 $10^{-9}$ 会误报。
3. **同一个"数"可能有多种口径**（单点窗口 vs 沿 $N$ 聚合）。比对前先对齐维度，否则会得出"结论与引擎矛盾"的假警报。
4. **渲染器里所有"看起来是数学"的文本都必须过替换表**，包括**表格单元格与正文**中未用 `$..$` 包住的部分；
   定界符有三种：`$`、`$$`、`\[`，缺一种就是上百处残留。
5. **字体缺字形是静默的**。默认只打 stderr、不改退出码——必须挂句柄升级为**门禁**，
   否则"内容变空白"会被当作"渲染成功"。
6. **修复必须留基线快照，并把字段分成"必须 IDENTICAL"与"预期会变"两类**逐一裁定；
   只有这样才能区分"修复生效"与"回归漂移"。
7. **markdown 表格里的 `\|` 是转义竖线而非分隔符**，任何把 `|` 一律当分隔符处理的代码都会吃掉数学符号。
