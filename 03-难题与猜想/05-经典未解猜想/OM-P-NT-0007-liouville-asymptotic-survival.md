## 一、待答问题

OM-P-NT-0006 给出单矩充分判据 `M_1 < 0 ⇒ a_11 >= 1 ⇒ Goldbach`，但它只在 `N <= 6e4` 被扫过，
且 `kappa_1` 序列单调趋向 0。**本轮回答：这个趋势会不会最终穿越 0？**

答案分两条路读，强度不同，不许混：

| 路线 | 判定 | 强度 |
|---|---|---|
| 盲外推（1/log N 一次＋二次拟合） | **UNDETERMINED**，读数作废 | 方法论负面结果（保留） |
| 密度模型（可解析求极限） | `kappa_1(inf) = (log 2)^2 - 1 = -0.5195 < 0` ⇒ **ALIVE** | 启发式模型结论，**非定理** |
| 精确身份（块 1b） | `M_1 = a_22 - a_11 + 2c`，`c ∈ {0,1}` | **严格**，机器核对 |

## 二、严格的那一半

$$M_1=a_{22}-a_{11}+2c,\qquad c=\big[\mathrm{spf}(N-1)>\lfloor N^{1/3}\rfloor\ \text{且}\ \Omega(N-1)\ \text{为偶}\big]\in\{0,1\}$$

推导三步（结果档 §三-c，第 143–147 行）：`S_z` 上 `Omega <= 2`；反射 `n -> N-n` 是 `S_z` 上的对合、
互换类 `(1,2)` 与 `(2,1)` 使两项**精确相消**；只剩 `n = 1` 与 `n = N-1` 这一对，贡献 `1 + (-1)^{Omega(N-1)} ∈ {0, 2}`。

机器核对：**2021 个偶数**（密集段 `N <= 4000` 全部偶数＋块 1 全部实测点，最大 `N = 3000000`），
**违反 0 例**；其中 `2c = 2` 的情形 **303 例**——该项不恒为 0（第 149 行）。

后果：上一轮的 `eps >= 0` 被换成 `<= 2` 的**显式**项，所以密度模型里「修正项可忽略」
不再是假设而是定理；**被削弱的只剩 `kappa_w(inf) = (log 2)^2` 本身**（那是 Hardy–Littlewood 型输入）。

## 三、启发式的那一半（以及它的失效处）

`kappa_w(N) = (prod_p R_p) * c_B(N)^2`：`p <= z` 时 `R_p = 1` 精确，`p > z` 时 `R_p - 1 = O(1/p^2)` 故乘积趋 1；
`c_B(N) -> log 2` 由 `int_{1/3}^{1/2} du/(u(1-u)) = ln 2` 解析导出。

* 数值**不能确认** `log 2`：`N = 3e6` 处 `c_B` 实测 0.5907，两种拟合 0.538／0.793 只把它**夹在中间**（第 126–128 行）。
* 模型偏差**必须分尺度**：尾部（最大三个 N）`obs/model` 偏离 `<= 4%`，但**全程**范围
  `[0.648822172109222, 1.0944365703275272]`——不得用「3~4%」描述全程（第 229 行）。
* 两处独立性假设恰是奇偶障碍所在，故这是「判据是否值得作为归约目标」的正面指示，**不是**把 Goldbach 往前推了一步（第 215 行）。

## 四、外推为什么作废（自校验记录）

Hardy–Littlewood 预言 `kappa_x(inf) = 1`。外推给出的读数（阈值 0.25，第 74–82 行）：

| 序列 | kappa_x(inf) 二次／线性 | 偏离 1 | 外推可信 |
|---|---|---|---|
| N ≡ 0 (mod 6) | 0.093 ／ 1.201 | 0.907 ／ 0.201 | **False** |
| N ≡ 2 (mod 6) | 1.138 ／ 1.109 | 0.138 ／ 0.109 | True |

一条序列不过 ⇒ 总体 **UNDETERMINED**；两序列的 `kappa_1(inf)` 区间
`[-0.589, 0.245]` 与 `[-0.793, -0.529]` 甚至**异号**。
教训（第 216 行）：`kappa` 这类含 loglog／对数低阶项的量，在 `1/log N` 跨度仅 2 倍时做二次外推不可靠。

## 五、展开预算侧的两件事

* **块 2a**：`M_1 = sum_{d|P(z)} mu(d) Inner(d)` 及其 CRT／等差分解在 9 个案例（`N = 1000/2000/4000 × z = 7/11/13`）上逐项精确；
  关键陷阱是 `p | N` 时 `p|n ⇔ p|N-n`，该类素因子必须归入 `e = gcd(d, N)` 否则重复计数（第 167–180 行）。
* **块 2b**：`lambda` 在 AP 中的和实测**低于**目标预算（对平凡界最大 0.601、对预算 `x/log^2 x` 最大 0.500）
  ⇒ 障碍是**证明障碍**而非数值障碍；取值范围自陈只测 `x <= 1e6`、`q <= 2310`，
  早期版本因 `q = 1000/10000` 小样本触顶（`ratio_to_trivial` 有硬上界 1）而误报 1.0，**已剔除**（第 203–210 行）。
