## 1. 障碍的精确位置（为什么现有技术到不了）

### 1.1 奇偶障碍（parity barrier）

- 非负权筛只能区分"**至多 k 个**素因子"与"**少于 k 个**素因子"，**无法区分"恰好 1 个"与"至多 1 个"**。
- 对线性筛（维数 s=1，Goldbach 所处尺度），在临界尺度 u=2（即筛界 z=√N，因 log N / log z = 2）处，对"恰好 1 个素因子"集合的下界**坍塌为零**。换言之：任何非负权筛给出的"p 与 N−p 同为素数"的**下界为 0**——方法本身无法判定存在性，只能给出上界（例外不多）。
- **量化形态（level of distribution）**：要筛法对 Goldbach 计数给出正下界，需要素数在相关模上的分布水平 D = N^{1/2+δ}（δ>0，等价于 Elliott–Halberstam 在水平 >1/2 对相关和式成立）。无条件的 Bombieri–Vinogradov 只给 D = N^{1/2−ε}——**"差一个 ε"**。这正是 parity barrier 的量化表述。

### 1.2 "至多 vs 恰好"的质的跳跃

- 已证：充分大偶数 = **至多 4 个**素数之和（Helfgott 2013 三元哥德巴赫 ⇒ 至多 4；Ramaré 曾得至多 6）。
- 偶数 N 的"至多 3 个素数之和" **等价于** "2 个素数之和"（3 个奇素数之和为奇数 ≠ 偶数 N；若含偶素数 2，则 N−2 须为两素数之和）。
- 因此在"≤4"与"≤2 = 猜想"之间**没有任何中间无条件台阶**。这就是无法从已证区"渐进"到猜想的根因——不存在可累积的"半步"。

### 1.3 数值错觉（密度 0 ≠ 空集）

- ρ(N) = R_pp(N) / (S(N)·N/2) 的均值趋近 1（中位数 0.3348 → 0.6561 → 0.8808 → 0.9647 → 0.9829，锚点 10⁵=1.0006、10⁶=0.9977、2×10⁶=0.9981）。
- 但"反例密度为 0" **≠** "0 个反例"。Cramér 启发式预测反例期望有限，但那是**启发式不是证明**。平均趋近 1 不蕴含每个 N 都存在表示。

### 1.4 有限验证天花板

- Oliveira e Silva–Herzog–Pardi（*Math. Comp.* 83 (2014), 2033–2060）验证了 N ≤ 4×10¹⁸ 全部成立。但这是 **∀N ≤ 4×10¹⁸**，不是 ∀N。有限扫描不计入进度分子。

## 2. 五类突破靶心（可判定里程碑）

> 每个靶心给出：① 精确要填补的数学缺口；② 当前工具为何失败；③ **成功判据（单一可判定里程碑，yes/no）**；④ 当前最佳已知状态。
> "可判定"含义：该里程碑是一个可独立验证的真伪命题，填满即向证明推进；未填满则进度分子不变。

### 靶心 A — 分布水平越过 1/2（Elliott–Halberstam 型）

- **缺口**：需要素数在 Goldbach 相关模上的水平 D > N^{1/2}（即 EH[θ] 对某 θ>1/2 对相关加权和成立）。
- **当前为何失败**：无条件仅 Bombieri–Vinogradov（θ<1/2）。EH 猜想本身 θ=1，但仍是**猜想**。
- **可判定里程碑**：证明对 Goldbach 相关序列的某种加权和，EH[θ] 对**某个 θ>1/2** 成立 ⇒ 充分大偶数 Goldbach 成立（条件性结论，非最终定理）。
- **当前最佳状态**：Zhang / Maynard 推进了"有界间隔"（bounded gaps），**未**推进分布水平越过 1/2，故未触及此靶心。

### 靶心 B — 双线性 / 弥散法打破奇偶障碍（Friedlander–Iwaniec 型）

- **缺口**：parity barrier **只约束非负权筛**。若引入来自双线性和式（Type I/II 信息）的**相消**，可得正下界。
- **当前为何失败**：Friedlander–Iwaniec（2004，集合 X²+Y⁴）**首次打破** parity barrier；Matomäki–Radziwiłł（2016）短区间乘性函数相消、Tao 后续工作显示相消现象存在——但**尚无** Goldbach 集合 {N−p : p 素数} 的此类代数/自守结构。
- **可判定里程碑**：为 {N−p} 构造出可证明其双线性和式相消的结构（例如与某自守形式傅里叶系数、或 major-arc 相消的显式联系），并**导出正下界**。
- **当前最佳状态**：**唯一已被证明"可越障"的路线**（FI 对 X²+Y⁴）。对 Goldbach 最富希望、也最缺结构。

### 靶心 C — 圆法 + 真正 minor-arc 相消

- **缺口**：圆法给出 r(N) ~ S(N)·N/(log N)²，但要证 r(N)>0 需 minor-arc 上 |∑_{p≤N} e(αp)| 足够小——这又回到**靶心 A** 的分布水平。
- **当前为何失败**：minor-arc 相消界受 Bombieri–Vinogradov 限制，停在 1/2。
- **可判定里程碑**：在 minor-arc 上获得**优于** Bombieri–Vinogradov 的相消界（等价于 A 的某实例被填满）。
- **注**：三元情形（Vinogradov / Helfgott）成功是因为 ternary 的 parity barrier 阈值更高；binary 卡在 1/2。C 是 A 的"镜像"靶心。

### 靶心 D — 新恒等式 / 结构引理（绕过筛法）

- **缺口**：是否存在直接组合或代数恒等式，显式证明每个偶数 N 是两素数之和（如构造一个可证 ≥1 的"Goldbach 泛函" G(N)）。
- **当前为何失败**：无此类恒等式已知。现有所有攻击都仍落在筛法 / 圆法 / 解析数论的既有范式内。
- **可判定里程碑**：提出并证明一个对**每个**偶数 N 给出 r(N)≥1 的显式公式或不等式。
- **当前最佳状态**：最"白纸"的靶心，也最可能是"范式转移"所在；目前为一纸空白。

### 靶心 E — 条件归约到"差一点就证"的猜想

- **缺口**：将 Goldbach 归约为某分布水平略 >1/2 的 EH 变体（见 A），或归约为某自守/模形式判定。
- **当前为何失败**：所有已知归约目标本身仍为 OPEN。
- **可判定里程碑**：给出 Goldbach ⇒（某已部分推进的猜想）的严格归约，且该猜想的水平要求落在当前研究"差一点就到"的区间。
- **注（不计进度）**：若归约目标本身仍是 OPEN，则 Goldbach 仍为 OPEN。**条件性归约不增加进度分子**——它只把"unknown"搬运到另一个"unknown"。

## 3. 靶心与 PAIR 的映射

```
        [B] 双线性越障 (已证可越，缺结构)  ─┐
        [A] 分布>1/2   (差 ε)            ─┤
        [C] minor-arc  (A 的镜像)        ─┼──►  PAIR / parity barrier  [锁死之门]
        [D] 新恒等式   (范式空白)        ─┤        = 非负权筛 s=1,u=2 下界=0
        [E] 条件归约   (不计进度)        ─┘
```

- **PAIR（Theorem B）= parity barrier 本身** = "非负权筛在 s=1, u=2 下界为 0" 的闭合门。
- **唯一能撬动 PAIR 的钥匙 = {A, B, C, D, E} 中至少一个被填满。**
- 当前状态：
  - A：差 ε（无条件未达 1/2+）
  - B：缺结构（越障路线已知但无 Goldbach 实例）
  - C：归约到 A
  - D：空白
  - E：不增进度
- **结论**：五靶心目前无一被填满 ⇒ 不存在已知有效证明路径 ⇒ 猜想保持 OPEN。
