## 1. 从有符号偏差分出真正有害的部分

中央区间 I=(√N,N/2]∩Z。按 p₁<…<pₖ≤√N 筛选。
Sᵢ 表示第 i 层后的存活数，Kᵢ 为该层删除量，S₀=|I|，并定义

\[
\rho_i=\begin{cases}1&p_i\mid N\\2&p_i\nmid N,\end{cases}\qquad
\alpha_i=1-\frac{\rho_i}{p_i},\qquad
D_i=K_i-(1-\alpha_i)S_{i-1}.
\]

N 为偶数，所有 αᵢ>0。记尾权重 wᵢ=∏_{j>i}αⱼ，以及

\[
M=S_0\prod_i\alpha_i,\quad
E=\sum_iD_iw_i,\quad A=\sum_i|D_i|w_i,\quad
E_+=\sum_i\max(D_i,0)w_i.
\]

由逐层递推 Sᵢ=αᵢSᵢ₋₁−Dᵢ，精确得到

\[
H(N)=M-E,\qquad E_+=\frac{A+E}{2},\qquad
H(N)\ge M-E_+.\tag{1}
\]

这区别三种估计：

- E<M：与 H>0 **完全等价**；如果先算 H 再报告这个不等式，没有新增证明信息。
- A<M：充分但过强；有利的负偏差也被按损失扣除了。
- E₊<M：仍是充分条件，但只控制有害偏差，允许直接丢弃有利偏差。

若能独立证明 E≤M/2 或 E₊≤M/2，则 H≥M/2>0（N≥6）。
N=4 另外用 2+2 处理。这里的“独立”要求给出对所有目标 N 的估计，
不能引用待证的 H>0、观察到的 H 值，或未经证明的“幸存者均匀分布”。

## 2. 精确账本实验

对每个偶数 6≤N≤5000，共 2498 个，程序做三重核对：

1. 正向递推计算 M、E、A。
2. 逆向累乘尾权重，独立展开 ΣDᵢwᵢ 和 Σ|Dᵢ|wᵢ。
3. 直接统计中央素数对，核对 M−E=H。

所有比较采用整数和 Fraction 有理数，没有浮点容差，恒等式残差均为 0。

有符号候选 E≤M/2 在搜索范围没有反例。
最大 E/M 为 6/13，出现在 N=68：M=13/7，E=6/7，H=1。
这只是有限观察，不能把 6/13 固定为全局常数。

追加检验单侧预算 E₊≤M/2，仍在全部 2498 个偶数中没有反例，
最大 E₊/M 同样为 6/13（N=68）。这比只检查 E≤M/2 更强，
因为没有借用负偏差的抵消；但 E₊ 的数据仍由实际筛选得到，尚非独立的解析上界。

绝对值候选 A<M 出现反例，最早 N=6（A=M=1/2，严格不等式失败），
失败列表为 6、10、26。最大 A/M=2 出现在 N=10：
M=1/3，E=−2/3，A=2/3，H=1。
这里恰恰是负偏差增加了存活数，使用 A 会把好处误记成损失。

因此本轮保留单侧误差预算作为研究目标，否定“所有偏差绝对值总和总小于主项”的全范围版本。
有限范围内看不到更多反例，并不能说明它在大数自动成立。

## 3. 扩大相邻迁移：允许两边同时改变

上一轮的固定一边方法失败在 38→40。
本轮把迁移扩为

\[
(p,q)\longmapsto(p+d,q+2-d),\qquad |d|\le r,
\]

要求四个涉及的数均满足相应的素性条件。
每个 N 的所有**有序**表示都参与搜索，避免只保留较小素数而遗漏迁移。
利用排序后的表示集合求最小 |d|；98 个小样例另以双重穷举交叉核对。

逐偶数搜索 6≤N≤20000，目标偶数实际覆盖至 20002，共 9998 次迁移：

| 半径 r | 没有符合半径迁移的 N 数 |
|---|---|
| 0 | 2197 |
| 2 | 0 |
| 4、8、16、32 | 各为 0 |

最小所需半径的最大值为 2，最早在 N=38 达到。
具体补救是 38=19+19 → 40=17+23，取 d=−2。
只改一边的失败因此可以在这个样例中用双边迁移修补，但不能从有限样例推广。

## 4. 反向审查：半径 2 的全局命题会同时要求孪生素数无穷多

对 N≥6 的偶数，双素数表示两边都是奇素数，因此 d 必为偶数。
|d|≤2 只剩 d=−2、0、2：

- d=0：q 与 q+2 是孪生素数。
- d=2：p 与 p+2 是孪生素数。
- d=−2：p−2 与 p 是孪生素数，另要求 q 与 q+4 为素数。

假设孪生素数对只有有限多组，令 F 为这些对中所有素数构成的有限集合。
任意上述迁移的原表示 N=p+q，至少有一项属于 F。

对每个 f∈F 选互不相同的奇素数 ℓ_f。中国剩余定理允许同时满足

\[
N\equiv0\pmod2,\qquad N\equiv f\pmod{\ell_f}\quad(f\in F).
\]

这些解形成无限等差数列。取其中足够大 N，使 N−f>ℓ_f 对所有 f 成立，
则每个 N−f 都是 ℓ_f 的倍数且为合数。
此 N 没有包含 F 中任何素数的双素数表示，因此不存在半径 2 的迁移。
F 为空时结论更直接。

所以候选命题

> 所有充分大偶数 N 都存在半径 2 的素数对迁移

将蕴含孪生素数对无穷多，同时它本身也包含这些 N 的 Goldbach 表示存在性。
这说明它承担额外证明任务，不能把程序找到迁移直接写成无条件归纳引理。
