# 04-兰道问题

> 1912 年，Edmund Landau 在国际数学家大会上提出四个关于素数的"凭当代数学无法解决"的问题。
> **一个多世纪后，四个问题全部未解决。**

## 一、为什么单列

Landau 四问题是一个**极好的诚实教材**：它们全部表述简单到小学生能懂，全部至今未解。它们集中体现了数论中"加法与乘法结构的张力"。

它们同时也是**AI 幻觉的高发区**——因为表述简单，模型极易生成"简单的证明"或错误的状态描述。

## 二、四问题状态表

| # | 问题 | 陈述 | 状态 | 最佳部分结果 |
| --- | --- | --- | --- | --- |
| 1 | **哥德巴赫猜想（强）** | 每个大于 2 的偶数可表为两个素数之和 | `PARTIAL` | 陈景润 1966/1973："1+2"——充分大的偶数 = 素数 + 至多两个素数的乘积 |
| 2 | **孪生素数猜想** | 存在无穷多对相差 2 的素数 | `PARTIAL` | 张益唐 2013：存在无穷多对间隔 < 7×10⁷ 的素数；经 Polymath8 与 Maynard 改进至 **246**（间隔为 2 仍未解决） |
| 3 | **Legendre 猜想** | 对每个 n ≥ 1，n² 与 (n+1)² 之间至少有一个素数 | `OPEN` | 弱于"素数间隙为 O(√n)"的已知结果；完整猜想开放 |
| 4 | **n²+1 素数猜想** | 存在无穷多个形如 n²+1 的素数 | `OPEN` | Iwaniec 等证明存在无穷多个 n²+1 为**至多两个素数之积** |

## 三、弱哥德巴赫猜想（已解决，不属于四问题之一，但常被混淆）

| 项目 | 内容 |
| --- | --- |
| 陈述 | 每个大于 5 的奇数可表为三个素数之和 |
| 状态 | `RESOLVED` |
| 年份 | 2013 |
| 解决者 | Harald Helfgott |
| 方法 | 圆法（Hardy–Littlewood–Vinogradov）的精细化 + 大规模数值验证 |

**重要区分**：弱哥德巴赫猜想的解决**不蕴含**强哥德巴赫猜想。这是最常见的混淆。

## 四、常见误解

| 误解 | 澄清 |
| --- | --- |
| "张益唐证明了孪生素数猜想" | 他证明的是**有界间隔**（< 7000 万，后改进至 246），孪生素数要求间隔**恰好为 2** |
| "陈景润证明了 1+1" | 他证明的是"1+2"（素数 + 半素数），不是哥德巴赫猜想的"1+1" |
| "弱哥德巴赫解决了，强的也快了" | 弱猜想用的是三素数问题（圆法适用），强猜想是二素数问题（圆法不够），**方法不可迁移** |
| "n²+1 素数在数值上很多，所以成立" | 数值证据**不构成证明**；且这类序列的稀疏性使得数值外推尤其危险 |

## 五、可证伪性

| 问题 | 推翻方式 |
| --- | --- |
| 强哥德巴赫 | 找到一个不能表为两素数之和的偶数（**注意**：需排除 2 本身；且必须大于已验证范围） |
| 孪生素数 | 证明孪生素数只有有限个（需给出上界或证明收敛） |
| Legendre | 找到某个 n 使得 (n², (n+1)²) 间无素数 |
| n²+1 | 证明形如 n²+1 的素数只有有限个 |
