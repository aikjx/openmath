# 04-兰道问题

> 1912 年，Edmund Landau 在国际数学家大会上提出四个关于素数的"凭当代数学无法解决"的问题。
> **一个多世纪后，四个问题全部未解决。**

## 一、为什么单列

Landau 四问题是一个**极好的诚实教材**：它们全部表述简单到小学生能懂，全部至今未解。它们集中体现了数论中"加法与乘法结构的张力"。

它们同时也是**AI 幻觉的高发区**——因为表述简单，模型极易生成"简单的证明"或错误的状态描述。

## 二、四问题状态表

| # | 问题 | 陈述 | 状态 | 最佳部分结果 |
| --- | --- | --- | --- | --- |
| 1 | **哥德巴赫猜想（强）** | 每个大于 2 的偶数可表为两个素数之和 | `PARTIAL` | 陈景润 1966/1973："1+2"——充分大的偶数 = 素数 + 至多两个素数的乘积 |
| 2 | **孪生素数猜想** | 存在无穷多对相差 2 的素数 | `PARTIAL` | 张益唐 2013：存在无穷多对间隔 < 7×10⁷ 的素数；经 Polymath8 与 Maynard 改进至 **246**（间隔为 2 仍未解决） |
| 3 | **Legendre 猜想** | 对每个 n ≥ 1，n² 与 (n+1)² 之间至少有一个素数 | `OPEN` | Baker–Harman–Pintz 2001：\([x,x+x^{0.525}]\) 必有素数；猜想所需指数为 **1/2**，仍有 0.025 的指数缺口 → [OM-P-NT-0003](../../02-公式库/数论/OM-P-NT-0003-legendre-conjecture.md) |
| 4 | **n²+1 素数猜想** | 存在无穷多个形如 n²+1 的素数 | `OPEN` | Iwaniec 1978：存在无穷多个 n²+1 为**至多两个素数之积**（\(P_2\)）；筛维数与孪生素数同为 1 → [OM-P-NT-0004](../../02-公式库/数论/OM-P-NT-0004-landau-n2plus1-primes.md) |

> **问题 3 / 4 此前在本库只有状态表中的一行，没有独立条目、没有引擎。**
> 2026-09-18 补齐：新增公式库条目 OM-F-NT-0003 / OM-F-NT-0004（精确恒等式，L2）
> 与问题条目 OM-P-NT-0003 / OM-P-NT-0004（状态 `OPEN`），
> 并由新引擎 [`landau_scan.py`](../../05-验证中心/01-引擎/landau_scan.py) 支撑。
> 补齐的是**缺口的精确定位**（指数差 0.025、筛余项/主项比值 \(10^{19.5}\)），
> **不是**问题的进展。

## 三、弱哥德巴赫猜想（已解决，不属于四问题之一，但常被混淆）

| 项目 | 内容 |
| --- | --- |
| 陈述 | 每个大于 5 的奇数可表为三个素数之和 |
| 状态 | `RESOLVED` |
| 年份 | 2013 |
| 解决者 | Harald Helfgott |
| 方法 | 圆法（Hardy–Littlewood–Vinogradov）的精细化 + 大规模数值验证 |

**重要区分**：弱哥德巴赫猜想的解决**不蕴含**强哥德巴赫猜想。这是最常见的混淆。

## 四、常见误解

| 误解 | 澄清 |
| --- | --- |
| "张益唐证明了孪生素数猜想" | 他证明的是**有界间隔**（< 7000 万，后改进至 246），孪生素数要求间隔**恰好为 2** |
| "陈景润证明了 1+1" | 他证明的是"1+2"（素数 + 半素数），不是哥德巴赫猜想的"1+1" |
| "弱哥德巴赫解决了，强的也快了" | 弱猜想用的是三素数问题（圆法适用），强猜想是二素数问题（圆法不够），**方法不可迁移** |
| "n²+1 素数在数值上很多，所以成立" | 数值证据**不构成证明**；且这类序列的稀疏性使得数值外推尤其危险 |

## 五、可证伪性

| 问题 | 推翻方式 |
| --- | --- |
| 强哥德巴赫 | 找到一个不能表为两素数之和的偶数（**注意**：需排除 2 本身；且必须大于已验证范围） |
| 孪生素数 | 证明孪生素数只有有限个（需给出上界或证明收敛） |
| Legendre | 找到某个 n 使得 (n², (n+1)²) 间无素数 |
| n²+1 | 证明形如 n²+1 的素数只有有限个 |

## 十、强哥德巴赫条目的当前结论（2026-09-13）

$\tau_z$ 判素体系的**代数与组合部分已被精确认证**（$\tau'_0(q^a)=1/a$、两温核的精确刻画 $D_{s,t}(n)=0\iff\omega(n)=2$ 且无平方因子、$\eta_2=\tfrac12$ 与 $\eta_3=\tfrac13-\tfrac{s^2}{6\rho}$ 的闭式、主项常数 $\Psi(\rho,c)=\frac{e^{\rho c}-\rho e^c}{1-\rho}<1$、$\mathfrak S_N(0)\ge2C_2$）；
但 **USSD 与"每个偶数的 Hardy–Littlewood 渐近"同深度**，缺口收敛为单一命题：$\tau_z$ 的 Bombieri–Vinogradov 型分布定理（水平 $\ge 1/2$，对 $|z|\asymp1/\log\log N$ 一致）。
**状态仍为 `PARTIAL`（未解决）。**

二维均方 dispersion（BGD→DWSC）路线（2026-09-13）已核验：换元恒等式 (5)(6) **精确成立**（双路径相符到 $6\cdot10^{-10}$）、gcd 能量 $\|W_N\|_2^2\asymp N^2/M$ **成立**、对角项稀释**渐近成立**；但"只需 $N^{-1/4}$ 节省"是 Cauchy 的假象（真预算为 $\log^{-A}$），且 (2) 在可算尺度被 Poisson 噪声（每对仅 $5\sim14$ 个事件）掩盖、数值不可达；新暴露的致命脆弱点是模型 $\mathcal M_N$ 的局部因子（$p\mid N$ 处 $\nu(p)$ 取错即造成 $\approx30\%$ 系统偏差）。缺口仍为：**水平 $1/2$ 的素数对相关的对数级节省**。详见 [01B-强哥德巴赫_二维均方Dispersion与DWSC.md](./01B-强哥德巴赫_二维均方Dispersion与DWSC.md)。
