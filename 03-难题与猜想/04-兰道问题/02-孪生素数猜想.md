# 02-孪生素数猜想（Landau 问题 #2）

> 陈述：存在无穷多对相差 2 的素数 (p, p+2)。
> 状态：`OPEN`（张益唐 2013 证有界间隔 < 7×10⁷，Polymath8/Maynard 改进至 246；间隔恰为 2 仍未解决）

## 一、严格的 Hardy–Littlewood 渐近（标定基准）

真正的解析渐近由 Hardy–Littlewood 圆法给出，主项为：

```
π₂(x) ~ 2·C₂ · x / (ln x)²
```

孪生素数常数：

```
C₂ = ∏_{p≥3} (1 - 1/(p-1)²) = ∏_{p≥3} p(p-2)/(p-1)² ≈ 0.6601618158468698
```

## 三、可证伪性（红线一）

- 数值证据只能**支持**，不能**证明**无穷多孪生素数。
- 推翻方式：证明孪生素数只有有限个（给出上界或证明 ∑_{p} 1/p(p+2) 收敛）。
- 张益唐结果（有界间隔）≠ 孪生素数猜想（间隔恰为 2），勿混淆。
