# 09-独立与不可判定

> 本目录收录**答案是"不可能"的问题**。
> 这类结果是数学最深刻的成就之一：**它精确地说明了我们能知道什么、不能知道什么。**

## 一、三种"不可能"（必须严格区分）

这是本目录最核心的分类，**混淆三者是常见错误**：

| 类型 | 含义 | 例子 |
| --- | --- | --- |
| **`UNDECIDABLE`（独立）** | 在某公理系统中**既不能证明也不能否证** | 连续统假设（独立于 ZFC） |
| **`UNCOMPUTABLE`（不可计算）** | 不存在算法判定 | 停机问题、Hilbert 第十问题 |
| **`UNPROVABLE_IN`（在某系统内不可证）** | 在弱系统中不可证，但在强系统中可证 | Goodstein 定理（PA 中不可证，ZFC 中可证） |

**关键区别**：

- 独立 ⇒ 加新公理可以解决（两个方向都可以）
- 不可计算 ⇒ 加公理**无用**，因为问题在于没有算法
- 系统内不可证 ⇒ 换更强的系统即可

## 二、独立性问题（`UNDECIDABLE`）

| 命题 | 独立于 | 关键结果 |
| --- | --- | --- |
| **连续统假设（CH）** | ZFC | Gödel 1940（L 中成立）+ Cohen 1963（力迫使 ¬CH 成立） |
| **选择公理（AC）** | ZF | Gödel（L 中成立）+ Cohen（力迫否定） |
| **Suslin 假设** | ZFC | 独立于 ZFC |
| **Whitehead 问题** | ZFC | Shelah 证明：在 V=L 下成立，在 Martin 公理下不成立 |
| **平行公理** | 绝对几何（前四公设） | 非欧几何的构造 |
| **Kaplansky 猜想（Banach 代数）** | ZFC（某些版本） | 需核实 |
| **Borel 猜想** | ZFC | 与 forcing 公理相关 |

**注意**：独立性证明的技术核心是**力迫法**（Cohen）与**内模型**（Gödel），两者配合给出"两个方向都相容"的结论。

## 三、不可计算问题（`UNCOMPUTABLE`）

| 问题 | 结果 | 年份 |
| --- | --- | --- |
| **停机问题** | 图灵：不存在判定程序 | 1936 |
| **Hilbert 第十问题**（丢番图方程可解性） | Matiyasevich（基于 Davis–Putnam–Robinson）：不存在算法 | 1970 |
| **群的字问题**（word problem） | Novikov, Boone：存在有限展示群使字问题不可判定 | 1950s |
| **流形同胚问题**（维数 ≥ 4） | Markov：不可判定 | 1958 |
| **Post 对应问题** | Post：不可判定 | 1946 |
| **Wang 砖块（平铺）问题** | Berger：不可判定 | 1966 |
| **一般程序等价性** | Rice 定理 | 1953 |
| **矩阵 Mortality 问题** | 不可判定 | 1970s |

## 四、系统内不可证（`UNPROVABLE_IN`）

这类结果极其重要，因为它们**量化了"需要多强的公理"**：

| 命题 | 在 PA 中 | 在 ZFC 中 |
| --- | --- | --- |
| **Goodstein 定理** | 不可证（Paris–Kirby 1982） | 可证 |
| **Paris–Harrington 原理** | 不可证（1977） | 可证 |
| **PA 自身的一致性 Con(PA)** | 不可证（Gödel 第二不完备定理） | 可证（Gentzen 亦给出超限归纳证明） |
| **Kruskal 树定理** | 不可证 | 可证（需更强的序数分析） |

**教育意义**：Goodstein 定理是关于自然数的**真**命题，却在皮亚诺算术中不可证。这说明"真"与"可证"不是同一回事——这是哥德尔不完备性的直接体现。

## 五、反推数学：量化"需要多强的公理"

**反推数学**（Reverse Mathematics, Simpson）是本目录的理论框架：不从一个公理系统推导定理，而是**反推**定理需要多强的公理系统。

五大系统（"Big Five"）：

| 系统 | 强度 | 对应 |
| --- | --- | --- |
| `RCA₀` | 最弱（递归理解） | 可计算数学 |
| `WKL₀` | 弱 König 引理 | 紧致性、许多分析定理 |
| `ACA₀` | 算术理解 | 大多数经典分析 |
| `ATR₀` | 算术超限递归 | 描述集合论部分 |
| `Π¹₁-CA₀` | 最强 | 大部分经典描述集合论 |

**重要发现**：绝大多数经典数学定理恰好落在这五个系统之一（"Big Five 现象"）。但近年也发现了例外（"动物园"），这本身是活跃研究方向。

## 六、哥德尔不完备性的精确表述（防止误用）

**常见误述**："哥德尔证明了数学有无法解决的问题。"

**精确表述**：

> 第一不完备定理：任何**一致**的、**递归可公理化**的、且**足够强**（能表示基本算术）的形式系统，都存在一个在该系统中既不可证也不可否证的命题。

> 第二不完备定理：这样的系统**不能**在自身内部证明自身的一致性。

**关键限定词**（缺一不可）：

- **一致**：若系统不一致，则一切命题可证
- **递归可公理化**：公理集必须可被算法枚举
- **足够强**：必须能表达基本算术（如 Presburger 算术太弱，是完备的）

## 八、对"数学统一场论"的根本约束

**必须诚实写下的事实**：

> 哥德尔不完备性意味着：任何足够强的数学统一纲领，**都不可能同时做到**：
> （a）涵盖全部数学真理；（b）在其中证明自身的一致性；（c）递归可公理化。

这不是某个纲领的缺陷，而是**任何统一尝试的天花板**。任何声称"完全统一且自证一致"的纲领，要么不够强，要么不一致，要么不可公理化。

见 [04-数学统一场论/README.md](../../04-数学统一场论/README.md)。
