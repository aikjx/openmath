## `OM-SYS-0001` · ZFC 集合论

| 项 | 内容 |
| --- | --- |
| **类型** | 基础 |
| **提出** | Zermelo 1908；Fraenkel–Skolem 1922 补充替换公理 |
| **核心信条** | **一切数学对象都是集合**；数学命题都是关于集合的陈述 |

**公理假设**：外延、空集、配对、并集、幂集、无穷、替换、正则（基础）、**选择公理**。

**成就**：

- 为 20 世纪全部数学提供了统一的工作基础
- 使独立性证明成为可能（CH、AC 的独立性正是**关于 ZFC** 的元定理）
- 一致性强度的层级研究（大基数）成为精确的比较工具

**代价（诚实）**：

- **编码任意性**：自然数编码为 ∅、{∅}、… 还是别的方式，数学上无关但形式上有区别。这说明"集合"作为基础带有**非本质的实现细节**
- **与数学实践脱节**：几乎没有数学家真的用 ∈ 语言工作；"结构"（群、空间）才是实践单位
- **大小问题**：真类（所有集合的类）在 ZFC 中不存在，需额外处理（NBG 或 Grothendieck 宇宙）
- **选择公理的争议**：构造主义者拒斥

**可证伪预测**：若发现 ZFC 内部矛盾（如推出 0=1），则本纲领崩溃。（**至今未发现，但也不能自证**）

**形式化成熟度**：极高。Isabelle/ZF、Mizar、Metamath 均基于集合论；Mizar 的库规模巨大。

**评估**（初步）：表达力 5 / 解释力 3 / 生成力 3 / 可执行性 4

## `OM-SYS-0002` · 布尔巴基结构主义

| 项 | 内容 |
| --- | --- |
| **类型** | 结构 |
| **提出** | Nicolas Bourbaki（集体笔名），1939 年起《数学原理》 |
| **核心信条** | 数学对象 = 集合 + **结构**；结构分三类**母结构**：代数结构、序结构、拓扑结构，其他结构由它们复合而成 |

**成就**：

- 重塑了 20 世纪数学的**表述标准**（现代教科书的语言几乎都是布尔巴基式的）
- "结构"概念使跨领域的类比成为系统方法
- 推动了严格性与术语的统一

**代价（诚实）**：

- **抽象税极高**：批评者指出过度抽象掩盖了具体问题的直觉（如不谈具体的群，只谈"代数结构"）
- **对分析的覆盖不足**：布尔巴基传统上弱于分析、概率、应用数学
- **纲领已停止**：随着数学爆炸式增长，"写一套完整的基础"已不可行
- **教育后果争议**："新数学"运动的失败常被（有争议地）归咎于布尔巴基式抽象

**可证伪预测**：（历史纲领）若某重要数学领域无法归入母结构的复合，则其"完备性"主张失效。

**形式化成熟度**：中。结构概念在类型论/代数层级中已被形式化（如 Lean 的 typeclass）。

**评估**：表达力 4 / 解释力 4 / 生成力 2 / 可执行性 3

## `OM-SYS-0003` · Erlangen 纲领

| 项 | 内容 |
| --- | --- |
| **类型** | 结构 |
| **提出** | Felix Klein，1872 |
| **核心信条** | **几何 = 在某变换群下不变的性质**；变换群越大，几何越"软"（不变量越少） |

**成就（生成力极高）**：

- 把欧氏、仿射、射影、双曲、共形几何统一为**一条谱系**（由群的包含关系给出）
- **直接催生**了李群理论、不变量理论的发展
- 至今仍是理解几何分类的标准框架

**代价**：

- **不适用于无齐性的空间**：一般黎曼流形没有足够大的变换群，纲领失效
- **已被更一般的框架吸收**：Cartan 几何、主丛上的联络可视为推广
- **拓扑不属于此框架**：同伦论无法由变换群定义

**可证伪预测**：（历史纲领）不适用于非齐性空间——这**已经发生**，故其适用范围被限定。

**形式化成熟度**：高（相关群论与几何在 mathlib 中丰富）。

**评估**：表达力 2（仅限几何）/ 解释力 5 / 生成力 5 / 可执行性 4

> **本库特别标注**：Erlangen 纲领是**统一的最佳历史范例**——它在有限范围内达成了近乎完美的统一（解释力与生成力均满），代价是**明确的范围限制**。这比"什么都想统一"的纲领更有价值。

## `OM-SYS-0004` · 范畴论 / ETCS

| 项 | 内容 |
| --- | --- |
| **类型** | 基础 |
| **提出** | Eilenberg–Mac Lane 1945（范畴论）；Lawvere 1964（ETCS） |
| **核心信条** | **对象由它与所有其他对象的态射关系决定**（Yoneda 精神）；结构由泛性质刻画，而非由内部构造刻画 |

**公理假设**：ETCS 用**八个（或等价的）范畴公理**公理化"集合的范畴"，不提及 ∈ 与元素归属关系。

**成就**：

- 提供了**结构不变的表述**：不再有"3 ∈ π"这类因编码而生的无意义命题
- 伴随函子成为**跨域翻译的通用机制**
- 使"自然性"成为可精确定义的概念

**代价（诚实）**：

- **基础循环**：定义范畴通常需要某种集合论或类型论作为前提（或用范畴公理化范畴，仍不彻底）
- **大小问题依然存在**：需要 Grothendieck 宇宙或类-集合区分
- **学习曲线**：抽象层次高，与具体计算的接口不直观
- **实践中多作语言而非基础**：绝大多数数学家把范畴论当工具，不当基础

**可证伪预测**：若存在某个主流数学领域，其基本概念**无法**用泛性质/伴随刻画，则"范畴论作为通用语言"的主张受限。

**形式化成熟度**：高。mathlib 有庞大的范畴论库；但高阶范畴（∞-范畴）形式化仍在建设中。

**评估**：表达力 5 / 解释力 4 / 生成力 4 / 可执行性 3

## `OM-SYS-0005` · 拓扑斯理论

| 项 | 内容 |
| --- | --- |
| **类型** | 基础 |
| **提出** | Grothendieck 1960s（几何起源）；Lawvere–Tierney 1970s（逻辑面向） |
| **核心信条** | **拓扑斯 = 广义的集合论宇宙**；每个拓扑斯自带**内部语言**（直觉主义高阶类型论），在其中可"做数学" |

**关键洞察**：拓扑斯同时统一了**几何与逻辑**——

- 几何面：拓扑斯是"广义空间"（层范畴）
- 逻辑面：拓扑斯的内部语言是直觉主义逻辑，排中律在其中不必成立

**成就**：

- 提供了**不需要排中律**的数学基础（对构造性数学意义重大）
- 统一了集合论、层论、与力迫法（力迫可视为在拓扑斯中工作）
- 催生了代数几何中的 étale 上同调等工具

**代价**：

- **内部语言的直觉主义性质**：许多经典定理在一般拓扑斯中**不成立**（需要排中律或选择公理）
- **"哪个拓扑斯是真的？"** 没有答案——这是多元主义，也意味着没有唯一标准
- **技术门槛极高**

**可证伪预测**：若某类数学现象无法在**任何**拓扑斯的内部语言中表述，则表达力主张受限。

**形式化成熟度**：中。相关逻辑已被形式化，但完整拓扑斯理论的形式化仍在推进。

**评估**：表达力 4 / 解释力 4 / 生成力 4 / 可执行性 2

## `OM-SYS-0006` · 同伦类型论 HoTT

| 项 | 内容 |
| --- | --- |
| **类型** | 基础 |
| **提出** | Voevodsky 2006–2009（单价模型）；HoTT 专著 2013（IAS 特别年） |
| **核心信条** | **类型 = 空间（∞-群胚）；等价 = 相等（单价公理）**；同一性的证明是路径 |

**公理假设**：Martin-Löf 类型论 + **单价公理（Univalence）** + （可选）高阶归纳类型 HIT；（立方类型论中还用"计算性"替代/补充单价公理）

**成就**：

- **天生可计算**：类型是程序，证明是可执行对象
- **等价即相等**使得"沿同构传输"成为语言内置操作，消除了大量样板
- **高阶归纳类型**为商空间、命题截断等提供了优雅表述
- 使**形式化数学**的门槛显著降低（相比集合论基础）

**代价（诚实）**：

- **构造性默认**：排中律与选择公理不是内置的（可作为假设加入，但会破坏计算性）
- **与经典数学的接口**：主流数学大量依赖排中律；经典数学在 HoTT 中的表述需要额外公理
- **单价公理的计算解释**：立方类型论解决了这一问题，但增加了复杂度
- **社区规模**：相对 ZFC 仍小；mathlib 基于 Lean 的**经典**类型论而非 HoTT

**可证伪预测**：

1. 若存在无法在类型论中自然表述的经典数学分支 → 表达力受限
2. 若"等价即相等"在某些结构中导致不可接受的副作用 → 单价公理需修正

**形式化成熟度**：**最高**。Coq/Agda/Lean 的生态成熟；Cubical Agda 提供计算性单价。

**评估**：表达力 4 / 解释力 4 / 生成力 3 / 可执行性 **5**

## `OM-SYS-0007` · Langlands 纲领

| 项 | 内容 |
| --- | --- |
| **类型** | 桥接 |
| **提出** | Robert Langlands, 1967（给 Weil 的信） |
| **核心信条** | **数论（伽罗瓦表示）↔ 表示论（自守形式）↔ 几何**之间存在系统的对应；L-函数是共同的载体 |

**成就（本库中生成力最高者）**：

- **费马大定理**的证明正依赖其特例（模性定理 —— Wiles）
- **Sato–Tate 猜想**、**Serre 猜想**、**基本引理**（Ngô）等重大成果由其催生
- 已发展出**几何 Langlands**（Beilinson–Drinfeld，与量子场论联系），近年有重大突破性进展
- 被视为"数学的大统一理论"

**代价**：

- **极其技术化**：入门门槛可能是全数学最高之一
- **覆盖面选择性**：主要覆盖数论与表示论，对分析、概率、组合等直接触及少
- **大量开放**：纲领的"一般形式"远未证明

**可证伪预测**：若找到某个自守表示**不对应**任何伽罗瓦表示（在纲领断言的范围内），则纲领需修正。

**形式化成熟度**：**极低**（这是本库指出的一个重要缺口）—— 现代数论的形式化本身仍在起步阶段。

**评估**：表达力 2 / 解释力 5 / 生成力 **5** / 可执行性 1

> **本库观察**：Langlands 在"生成力"上的表现远超所有基础型纲领，但在"可执行性"上几乎为零。**这一反差是本目录最有意思的发现之一**——它说明"统一"的价值与"可机械化"是**两个独立的维度**。

## `OM-SYS-0008` · Weil 罗塞塔石碑

| 项 | 内容 |
| --- | --- |
| **类型** | 桥接 |
| **提出** | André Weil, 1940s |
| **核心信条** | **数域 / 函数域 / 黎曼曲面（复曲线）**三列之间存在系统的类比；同一命题在三者中有对应的版本 |

**成就**：

- 函数域上的**黎曼假设**被 Weil 证明（1940s），为数域情形提供了模板与希望
- 直接启发了**代数几何的重建**（Weil 的《代数几何基础》）
- 是**算术几何**这一整个领域的方法论基础
- 启发了 Langlands 纲领（Weil 是收信人）

**代价**：

- **类比不总是成立**：三列的对应是启发式的，不是定理；存在"类比失败"的情形
- **数域情形额外困难**：缺少 Frobenius 作用这一关键结构，使其无法直接照搬
- **是方法论而非理论**：它不提供证明，只提供猜想的方向

**可证伪预测**：（作为方法论纲领）若发现系统性类比失效的模式，需限定范围。

**形式化成熟度**：低。

**评估**：表达力 2 / 解释力 5 / 生成力 5 / 可执行性 1

## `OM-SYS-0009` · 概形与 Motives

| 项 | 内容 |
| --- | --- |
| **类型** | 结构 |
| **提出** | Grothendieck, 1960s– |
| **核心信条** | 代数几何的基本对象是**概形**；所有上同调理论都应是某个**万有上同调（motives，母题/动机）**的实现 |

**成就**：

- 概形语言统一了代数几何与数论，使 Weil 猜想可被陈述与证明（Deligne 1974）
- **Motives 纲领**给出了"为什么不同上同调理论给出相容的结果"的解释
- 催生了导出范畴、ℓ-进上同调、晶体上同调等整套工具

**代价**：

- **标准猜想（Standard Conjectures）未证明**：Motives 的构造**依赖**这些未证明的猜想。这是纲领的**核心缺口**
- **技术复杂度极高**："Grothendieck 的抽象"成为梗，但也反映了真实的学习成本
- **Motives 类别的存在性**在一般情形下仍未完全建立

**可证伪预测**：

- 若标准猜想被**证伪**，则 motives 的现有构造路径失效
- 这是本库**最明确的可证伪预测之一**

**形式化成熟度**：低—中。Lean 的代数几何库（如 `Mathlib/AlgebraicGeometry`）正在建设中，概形已被形式化。

**评估**：表达力 4 / 解释力 5 / 生成力 5 / 可执行性 2

## `OM-SYS-0010` · 镜像对称

| 项 | 内容 |
| --- | --- |
| **类型** | 桥接 |
| **提出** | 1990–1991（Candelas 等的五次三维形工作；源自弦论的 T-对偶） |
| **核心信条** | 卡拉比–丘流形**成对出现**（镜像对），其中一个的**辛几何**对应于另一个的**复几何** |

**成就（生成力极高，且是"预测性"的范例）**：

- **Candelas–de la Ossa–Green–Parkes 1991**：用镜像对称**预测**了五次三维形上有理曲线的数目，这是枚举几何中长期未解的难题
  - **这正是"事前统一"的典范**：物理启发的纲领**预测**了数学结果，后来被数学家证明
- 催生 **Gromov–Witten 不变量**、**Floer 同调**、**同调镜像对称**（Kontsevich 1994）
- 深刻改变了枚举几何与辛拓扑

**代价（诚实）**：

- **数学上大量未严格化**：物理推导（路径积分）在数学上多为形式化操作
- **同调镜像对称猜想**在一般情形下未证明
- **依赖物理直觉**：这既是其优势也是其风险

**可证伪预测**：

- 若镜像对的枚举预测与直接计算不符 → 纲领需修正（历史上确有修正，如早期公式的更正）
- 同调镜像对称的一般情形若被证伪 → 核心主张受损

**形式化成熟度**：低。

**评估**：表达力 2 / 解释力 4 / 生成力 **5** / 可执行性 1

## `OM-SYS-0011` · 非交换几何

| 项 | 内容 |
| --- | --- |
| **类型** | 结构 |
| **提出** | Alain Connes, 1980s– |
| **核心信条** | **空间 = 谱三元组 (A, H, D)**，其中 A 是（可能非交换的）代数；交换代数对应普通空间，非交换代数对应"非交换空间" |

**成就**：

- 统一了**几何与算子代数**：Riemann 几何的许多概念（距离、维度、曲率）可推广到非交换情形
- 为**标准模型**提供了几何解释（粒子物理的谱作用原理）
- 催生了循环上同调、非交换积分等工具
- 在叶状结构、商空间（"坏商"）等问题上有实质应用

**代价**：

- **物理应用的可检验性存疑**：谱作用原理导出的物理预测尚未被实验确认（部分预测已被 LHC 数据约束/排除）
- **抽象层次高**，与主流数学的接口有限
- **"非交换空间"的直觉**难以建立

**可证伪预测**：

- 谱作用原理导出的粒子质量/耦合常数预测若与实验冲突 → 该应用方向受损
- 这是**少数有外部（实验）可证伪性**的数学纲领

**形式化成熟度**：低。

**评估**：表达力 3 / 解释力 4 / 生成力 3 / 可执行性 1

## `OM-SYS-0012` · 反推数学

| 项 | 内容 |
| --- | --- |
| **类型** | 度量（元层次） |
| **提出** | Harvey Friedman 1970s；Simpson 及其学派系统化 |
| **核心信条** | 不问"从公理能推出什么"，而问"**要推出这个定理，需要多强的公理**"；绝大多数经典数学定理恰好落在五个系统之一（Big Five） |

**成就**：

- 给出了数学定理的**精确的公理强度度量**——这是一种**元层次的统一**
- **Big Five 现象**的发现本身是深刻的经验规律
- 揭示了"哪些定理本质上是可计算的，哪些不是"（RCA₀ ↔ 可计算数学）
- 近年发现的"动物园"（非五大系统的定理）推动了纲领的深化

**代价**：

- **不提供新工具**：它不帮你证明定理，只告诉你定理"有多难"
- **二阶算术的框架限制**：主要处理"可编码为二阶算术"的数学，对高抽象数学（如范畴论、代数几何）覆盖不足
- **度量型纲领的固有局限**：统一的是标准，不是对象

**可证伪预测**：

- 若 Big Five 现象被系统性地破坏（大量定理落在五大系统之外），则纲领的核心主张需修正——**这已在发生**（"动物园"），故需持续跟踪

**形式化成熟度**：中（相关逻辑系统已被形式化）。

**评估**：表达力 2 / 解释力 **5**（在适用范围内）/ 生成力 3 / 可执行性 4

> **本库评价**：反推数学是被最严重低估的纲领。它不声称统一对象，但提供了**统一的度量**——而这恰恰是可操作、可比较、可证伪的。在本库的四维评估中，它在"解释力"上表现突出。

## `OM-SYS-0013` · Curry–Howard–Lambek 三角

| 项 | 内容 |
| --- | --- |
| **类型** | 桥接 |
| **提出** | Curry 1934（观察）；Howard 1969（正式）；Lambek 1980s（范畴面） |
| **核心信条** | **逻辑 ↔ 计算 ↔ 范畴** 三者是同一结构的三个面向：<br>命题 = 类型 = 对象；证明 = 程序 = 态射 |

**成就（对计算机科学影响最大）**：

- 是**全部现代证明助手**的理论基础（Coq、Agda、Lean 都建立在此对应上）
- 使"程序正确性证明"成为实际工程
- 催生了类型论、函数式语言（Haskell、OCaml、Rust 的类型系统均受影响）
- 直接支撑本库的 L4 层

**代价**：

- **构造性限制**：对应天然对应直觉主义逻辑；经典逻辑需要额外机制（如 call/cc、双重否定翻译）
- **不覆盖"非构造性"的数学实践**：主流数学大量使用排中律
- **是对应而非统一**：它连接三个领域，但不声称其中之一"更基本"

**可证伪预测**：（作为已确立的对应关系）若发现某类证明无法给出计算内容，则对应需限定范围（事实上这**已经发生**：经典逻辑的对应需要扩展）。

**形式化成熟度**：**最高**——它本身就是形式化工具的理论基础。

**评估**：表达力 3 / 解释力 5 / 生成力 5 / 可执行性 **5**

## `OM-SYS-0014` · 信息 / 熵纲领

| 项 | 内容 |
| --- | --- |
| **类型** | 结构（松散） |
| **提出** | Shannon 1948；Jaynes 1957（最大熵原理）；后续由统计力学、信息几何（Amari）等发展 |
| **核心信条** | **熵与信息是跨越概率、统计、几何、物理、学习的统一不变量** |

**成就**：

- 熵统一了：热力学（Boltzmann–Gibbs）、信息论（Shannon）、统计推断（Kullback–Leibler）、机器学习（交叉熵损失）
- **最大熵原理**为统计推断提供了统一的推导原则
- **信息几何**把统计模型族视为带有 Fisher 度量与对偶联络的流形，统一了统计与微分几何
- 熵在遍历论（Kolmogorov–Sinai 熵）与动力系统中提供统一的不变量

**代价（诚实）**：

- **纲领松散**：不同领域的"熵"概念虽有联系，但**不是同一个概念**（香农熵、KS 熵、热力学熵的公理化基础不同）
- **存在被过度推广的风险**："万物皆可熵"式的宣称频繁出现但缺乏实质
- **缺少统一的公理化**：目前没有一套公理同时刻画所有熵

**可证伪预测**：

- 若某领域的核心不变量无法与任何熵概念建立定量联系 → 该领域的覆盖主张失效
- 最大熵原理若在某些情形下给出与经验冲突的推断 → 需限定适用范围

**形式化成熟度**：中（信息论不等式、概率论已被部分形式化）。

**评估**：表达力 3 / 解释力 4 / 生成力 3 / 可执行性 3

> **本库提醒**：这是本清单中**最容易被滥用**的纲领。熵的概念在不同领域的形式相似性，极易被误认为实质统一。本库要求：引用本纲领时必须说明**具体是哪种熵、建立了什么定量联系**。
