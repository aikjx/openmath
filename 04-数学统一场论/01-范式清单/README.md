# 01-范式清单

> 数学统一纲领的**竞技场**。每个纲领以同一张卡片模板填写，便于横向比较。

## 一、分类体系

纲领按[统一的类型](../README.md#二三种不同类型的统一必须区分)分为四类：

| 类型 | 目标 | 纲领 |
| --- | --- | --- |
| **基础型** | 提供共同的公理与语言 | ZFC、ETCS/范畴论、拓扑斯、HoTT |
| **结构型** | 用一类结构描述多类对象 | 布尔巴基、Erlangen、概形/Motives、非交换几何 |
| **桥接型** | 在两个领域间建立字典 | Langlands、Weil 罗塞塔、镜像对称、Curry–Howard–Lambek |
| **度量型** | 提供统一的**度量标准** | 反推数学、信息/熵纲领 |

**注意**：度量型纲领常被忽略，但它们提供的是**元层次的统一**——不统一对象，而统一"衡量标准"。本库认为这类纲领的价值被严重低估。

## 三、卡片模板

新增纲领**必须**填写下列全部字段。缺项的纲领不予登记。

```yaml
id: OM-SYS-XXXX
name_zh: <中文名>
name_en: <English Name>
type: foundation | structural | bridging | metric
proposed: {year: , by: }
core_slogan: <一句话核心信条>
axioms:            # 见 02-假设空间
  - ...
scope:             # 目标覆盖的 MSC 区域
  - ...
achievements:      # 生成力：本纲领催生/预测的结果（必须可引用）
  - ...
costs:             # 抽象税与已知代价（必须诚实）
  - ...
falsifiable_predictions:   # 见 06-可证伪预测
  - ...
formalization:     # 形式化成熟度
  system: ""
  status: ""
current_status: active | historical | contested
evaluation:        # 见 07-评估矩阵（0–5 分，需附证据）
  expressivity:
  explanatory:
  generative:
  mechanizability:
```

**三个最容易缺的字段**：`costs`、`falsifiable_predictions`、`evaluation` 的证据。缺前两者的纲领一律退回。

## 四、登记政策

1. **任何人可登记新纲领**，但必须通过卡片完整性检查
2. **不得登记本库自己的纲领**（[README](../README.md) 第七节明确拒绝自我指涉）
3. **已停纲领不删除**，标 `current_status: historical`（布尔巴基、Erlangen 的教训仍有价值）
4. **争议纲领**（如 IUT）可登记，但必须同时列出支持与反对的论据

## 五、为什么不做排名

排名会把四维评估压缩成一维，必然丢失信息，且会激励"争夺名次"而非"澄清假设"。

**替代方案**：[07-评估矩阵](../07-评估矩阵.md) 给出多维分数 + 每个分数背后的证据。使用者可按自己的需求加权。

## 六、给 AI 代理的提示

生成或讨论统一纲领时：

- **必须**说明纲领的**类型**（基础/结构/桥接/度量）——很多争论源于混淆类型
- **必须**区分"纲领的**信条**"与"已**证明**的结果"——Langlands 纲领是**纲领**，其内部有大量猜想
- **不得**因为某纲领有未解决的猜想就说它"失败"（几乎所有活跃纲领都有）
- **不得**因为某纲领"覆盖面广"就说它"更正确"
