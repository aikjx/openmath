# 02-假设空间

> **本目录的目的**：把每个纲领赖以为生的公理假设**显式化**。
> 隐藏的假设是数学争论的主要来源——两个纲领看起来在争"谁对"，实际上在争"该接受哪些公理"。

## 一、为什么必须显式化

同一命题在不同假设下真值不同，这在数学中极其常见：

| 命题 | 在 ZFC 中 | 在 ZF 中 | 在构造性数学中 |
| --- | --- | --- | --- |
| 每个向量空间有基 | 成立（依赖 AC） | 不可证 | 需特殊条件 |
| 存在不可测的实数集 | 成立（依赖 AC） | 与"所有集可测"相容（需大基数） | 依赖系统 |
| 每个实数列有收敛子列 | 成立（Bolzano–Weierstrass） | 成立（不需 AC） | 需构造性重述 |
| 排中律 \(P \lor \lnot P\) | 成立 | 成立 | **不成立** |

**因此**：任何跨纲领比较，第一件事是把假设摆到桌面上。

## 二、核心假设维度

本库用下列**七个维度**刻画一个纲领的假设空间。每个纲领必须逐项声明。

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| **基础系统** | ZFC / ZF / NBG / MLTT / HoTT / ETCS / IZF / CZF | 底层形式系统 |
| **排中律** | 接受 / 拒绝 / 局部接受 | 经典 vs 构造 |
| **选择公理** | 完全 AC / 可数选择 / 依赖选择 / 无 | 影响范围极大 |
| **无穷公理** | 有 / 无 / 更强（大基数） | 是否需要实无穷 |
| **外延性** | 集合外延 / 函数外延 / 命题外延 / 单价 | 相等如何定义 |
| **非直谓性** | 允许 / 禁止 | 是否允许用整体定义部分（impredicativity） |
| **一致性强度** | 相对排序 | 在哪种意义上"更强" |

## 三、主要纲领的假设对照

| 纲领 | 基础系统 | 排中律 | 选择公理 | 外延性 | 一致性强度 |
| --- | --- | --- | --- | --- | --- |
| `OM-SYS-0001` ZFC | ZFC | ✅ | ✅ 完全 | 集合外延 | 基准 |
| `OM-SYS-0002` 布尔巴基 | ZFC（+隐含宇宙） | ✅ | ✅ | 集合外延 | ≈ ZFC |
| `OM-SYS-0004` ETCS | 范畴公理 | 通常 ✅ | 需**额外**添加 | 由泛性质决定 | ≈ ZFC 减去替换（有争议） |
| `OM-SYS-0005` 拓扑斯 | 局部笛卡尔闭范畴 | ❌（内部语言为直觉主义） | 需额外添加 | 依拓扑斯而定 | 依拓扑斯而定 |
| `OM-SYS-0006` HoTT | MLTT + 单价 | ❌（可选添加） | 需额外添加（且破坏计算性） | **单价公理**（等价即相等） | 已知与 ZFC 有对应（需小心表述） |
| `OM-SYS-0009` Motives | ZFC + **标准猜想** | ✅ | ✅ | 集合外延 | ≥ ZFC（依赖未证明猜想） |
| `OM-SYS-0012` 反推数学 | 二阶算术片段 | 依系统 | 依系统 | 集合外延 | **低于** ZFC（核心特征） |

> ⚠️ **诚实提示**：上表中"一致性强度"的相对排序在文献中有技术细节（例如 HoTT 与 ZFC 的强度比较依赖是否加入排中律与某些大基数式构造）。**引用具体结论前请核查文献**。本表给出的是导航，不是权威裁定。

## 四、假设的"成本"

每个额外假设都有成本。本库要求纲领**申报假设成本**：

| 假设 | 成本 |
| --- | --- |
| **选择公理** | 产生非构造性存在（Banach–Tarski）；与"所有集可测"不相容 |
| **排中律** | 破坏计算性：证明无法提取程序 |
| **大基数** | 一致性不可证（由哥德尔不完备）；依赖信念 |
| **标准猜想** | **未证明**——整个 Motives 纲领以此为前提 |
| **单价公理** | 计算性实现需要立方类型论等扩展；与某些经典构造的交互仍在研究 |

**关键原则**：**假设越少，结论越强**。因此反推数学的价值正在于它**最小化**假设。

## 五、"隐含假设"的常见来源

本库在评审中特别留意下列隐含假设：

| 来源 | 典型表现 |
| --- | --- |
| **教材惯例** | 某定理在教材中默认"有限维""可定向""第二可数"，但未说明 |
| **领域习俗** | 代数几何默认代数闭域；分析默认完备性 |
| **编码依赖** | 结论依赖于某种具体编码（如自然数的 von Neumann 编码） |
| **大小忽略** | 忽略"范畴是否小""真类问题" |
| **构造性滑移** | 在构造性框架下使用了排中律的技巧 |

**评审规则**：发现隐含假设即退回，不看结论对错。（[红线三](../../00-宪章/02-诚实红线.md)）

## 六、假设可组合性

一个重要问题：**不同纲领的假设能否叠加？**

| 组合 | 可行性 | 说明 |
| --- | --- | --- |
| ZFC + 大基数 | ✅ | 标准做法 |
| HoTT + 排中律 | ⚠️ | 可行，但破坏计算性 |
| HoTT + 选择公理 | ⚠️ | 可行（有对应形式），同样影响计算性 |
| 构造性 + 完全选择公理 | ❌ | 会导致排中律（Diaconescu 定理） |
| 拓扑斯内部 + 排中律 | ⚠️ | 只有当拓扑斯是布尔的（如集合拓扑斯） |

**Diaconescu 定理**是一个极好的例子：在拓扑斯/构造性类型论中，**选择公理蕴含排中律**。这说明假设之间不是独立的——这是一条**定理**，不是观点。
