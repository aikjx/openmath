# 05-不可通约与冲突

> **纲领之间的真冲突，比表面的偏好差异少得多，但确实存在。**
> 本目录区分"真冲突"与"伪冲突"——这是本目录的主要价值。

## 一、伪冲突 vs 真冲突

| | 伪冲突 | 真冲突 |
| --- | --- | --- |
| 本质 | 术语、强调点、审美的差异 | **结论在同一问题上不同** |
| 可否调和 | 翻译后可发现说的是同一件事 | 不可调和，必须选择 |
| 例子 | "范畴论 vs 集合论"作为**工具**之争 | 是否接受排中律 |
| 处理 | 记入[翻译表](../03-跨纲领翻译表/README.md) | 记入本目录 |

**大量被当作"基础之争"的争论其实是伪冲突**——它们争的是"哪个更好用"，而这个问题有上下文依赖的答案。

## 二、真冲突清单

### 冲突一：排中律（Law of Excluded Middle, LEM）

| 立场 | 主张 | 后果 |
| --- | --- | --- |
| **经典数学** | 接受 \(P \lor \lnot P\) | 非构造性存在证明合法；存在不可计算的实数 |
| **构造/直觉主义数学** | 拒绝 LEM | 每个证明给出算法；但许多经典定理需重述 |

**这是真冲突**：存在在经典数学中为真、在构造性数学中**不可证**（甚至为假）的命题。

**不是**偏好问题：例如"每个实函数在某个点连续"在非构造性框架下有不同的含义与真值。

**可调和的部分**：通过双重否定翻译（Gödel–Gentzen），经典数学可嵌入直觉主义数学，但**结论强度改变**。

### 冲突二：选择公理（AC）

| 立场 | 主张 | 后果 |
| --- | --- | --- |
| 接受 AC | 任意族的积非空 | Banach–Tarski、非测度集、良序定理 |
| 拒绝 AC（或只接受可数选择） | 需构造选择函数 | 分析的大部分仍可做（可数选择通常足够），但代数与拓扑的部分"标准"定理失效 |

**真冲突**：存在依赖 AC 的命题，其在 ZF 中不可证。

**重要技术事实**（不是观点）：**Diaconescu 定理**——在拓扑斯/构造性类型论中，AC **蕴含** LEM。因此这两个冲突**不是独立的**。

### 冲突三：非直谓性（Impredicativity）

| 立场 | 主张 |
| --- | --- |
| 允许 | 可用包含该对象本身的整体来定义该对象（如幂集、全称量化 over 所有命题）|
| 禁止（直谓性） | 禁止循环定义，保证定义的"良基性" |

**影响**：MLTT 中 `Prop` 的非直谓性、System F 的非直谓多态、ZFC 的分离公理模式是否非直谓。

**后果**：拒绝非直谓性会失去部分数学，但获得更强的规范性/一致性保证。

### 冲突四：外延性 vs 内涵性

| 立场 | 主张 |
| --- | --- |
| 外延 | 对象由其内容决定（集合由其元素） |
| 内涵 | 对象的"给出方式"有独立意义（类型论中常见） |

**HoTT 的位置**：单价公理是一种**极强的外延性**（等价即相等），但类型论本身带有内涵成分（不同证明的同一命题可以有不同"证据"）。这使得 HoTT 中的外延性讨论极为微妙。

### 冲突五：基础循环问题

这是**所有基础型纲领共有的难题**：

- 用集合论定义范畴 → 范畴论不"基础"
- 用范畴论定义集合（ETCS）→ 但范畴本身用什么定义？
- 用类型论定义一切 → 类型论的元理论用什么表述？

**本库立场**：**这不是可以"解决"的问题，而是必须接受的结构性事实**。任何基础都需要一个**元语言**，而元语言本身又需要元-元语言……

这不是缺陷，而是**塔斯基不可定义性定理**与哥德尔不完备性的直接后果。

### 冲突六：多元主义 vs 唯一基础

| 立场 | 主张 |
| --- | --- |
| **唯一基础** | 存在一个正确的基础，其他都是便利的记法 |
| **多元主义**（如拓扑斯多元） | 存在多个合法的数学宇宙，无优劣之分 |

**这是哲学层面的真冲突**，但不影响具体数学实践。本库采取**方法论多元主义**：在同一条目中允许不同基础的表述，但**必须标注**所用基础。

## 三、不可通约性（Incommensurability）

**定义**：两个纲领的基本词汇**不可互译**，且这种不可译不是技术困难，而是**概念结构上的差异**。

| 概念 | 在 ZFC 中 | 在范畴论中 | 可否互译 |
| --- | --- | --- | --- |
| 元素 | 原始概念（∈） | 派生概念（态射 1 → X） | ❌ 本体论不同 |
| 相等 | 外延相等 | 同构（实践中）/ 单价（HoTT） | ⚠️ 需重新定义 |
| 结构 | 附加在集合上的关系 | 对象在范畴中的位置 | ⚠️ 部分 |
| 真 | 模型中的满足关系 | 内部语言的命题 | ⚠️ 依拓扑斯而定 |

**库恩式的观察**：数学中的"不可通约"比自然科学中温和得多——因为数学有**形式化**这一共同的裁判。但这不改变概念结构差异的事实。

## 四、冲突的记录规范

登记冲突时必须填写：

```yaml
conflict:
  id: OM-CONFLICT-000X
  parties: [<纲领 A>, <纲领 B>]
  is_genuine: true           # 必须论证为何是真冲突而非伪冲突
  point_of_conflict: <精确描述分歧点>
  proposition_differing: <给出在某个命题上真值不同的具体例子>
  reconcilable: partial | no | yes
  reconciliation: <若部分可调和，说明如何>
```

**关键**：`proposition_differing` 必须给出**具体命题**。说不出具体命题的冲突，是伪冲突。

## 五、本库的元立场

1. **不做裁决**：本库不宣布哪个纲领"正确"
2. **要求标注**：任何条目必须声明所用基础与关键假设
3. **记录后果**：每个选择（LEM/AC/…）的后果必须记入 [02-假设空间](../02-假设空间/README.md)
4. **承认天花板**：[哥德尔不完备性](../README.md#六诚实的天花板必须写在最前面) 决定不存在"完备且自证"的统一基础
