# 06-可证伪预测

> **本目录是本项目的守门人。**
> 一个说不出"什么结果会让我放弃它"的纲领，不是研究纲领，是信仰。

## 一、为什么必须要求可证伪预测

数学统一纲领有一个致命的流行病学特征：

> **它们几乎从不被证伪，只被冷落。**

原因：纲领的表述通常是"X 可以用来理解 Y"——这类断言既不能被证明，也不能被否证，只能被"觉得有用"或"觉得没用"。

**这使得"统一纲领"成为一个几乎零成本的宣称**。本目录通过强制要求可证伪预测，抬高这一成本。

## 二、什么叫"可证伪预测"

一个合格的预测必须：

1. **具体**：指向一个明确的数学命题（不是"会有更多成果"）
2. **可判定**：原则上能确定它是否成立
3. **有风险**：纲领错误时，它**很可能**不成立
4. **有时限感**：不是"总有一天"

| 不合格 | 合格 |
| --- | --- |
| "范畴论会继续产生洞见" | "若存在主流数学分支，其基本概念无法用伴随/泛性质刻画，则范畴论作为通用语言的主张受限" |
| "Langlands 纲领将深化" | "若找到某自守表示不对应任何伽罗瓦表示（在纲领断言范围内），纲领需修正" |
| "HoTT 是更好的基础" | "若某经典数学分支无法在类型论中自然表述，则表达力主张受限" |
| "Motive 理论会统一上同调" | "若标准猜想被证伪，则 motives 的现有构造路径失效" |

## 三、各纲领的预测登记

| 纲领 | 预测（P） | 若 P 失败 | 当前状态 |
| --- | --- | --- | --- |
| `OM-SYS-0001` ZFC | ZFC 一致（无矛盾） | 纲领崩溃 | 未发现矛盾（**但不可自证**） |
| `OM-SYS-0004` 范畴论 | 主流数学概念可用泛性质/伴随刻画 | 作为通用语言的主张受限 | 未见反例；但"刻画"的严格标准本身有争议 |
| `OM-SYS-0006` HoTT | 经典数学可在类型论中自然表述（+LEM 等公理） | 表达力受限 | 大量数学已形式化；但"自然"程度有争议 |
| `OM-SYS-0009` Motives | **标准猜想成立** | 构造路径失效 | **未证明**（纲领的核心风险） |

| `OM-SYS-0011` 非交换几何 | 谱作用原理导出可与实验对照的预测 | 物理应用方向受损 | 部分预测已被 LHC 数据约束 |
| `OM-SYS-0012` 反推数学 | 新定理大多落在 Big Five 内 | 核心经验规律需修正 | **已在发生**："动物园"现象（非五大系统的定理） |
| `OM-SYS-0013` C-H-L | 对应可扩展到经典逻辑与更多类型系统 | 对应需扩展 | 已在发生（经典逻辑需额外机制） |

**本库最欣赏的预测**：Motives 的"标准猜想"——它是**最明确、风险最高**的一条。若标准猜想被证伪，整个 Motives 纲领的现有路径失效。这就是好的预测应有的样子。

## 四、预测的追踪机制

```yaml
prediction:
  id: OM-PRED-000X
  programme: OM-SYS-0009
  statement: "标准猜想成立"
  falsification_condition: "找到反例或证明其否定"
  risk_level: high        # high | medium | low
  deadline_note: "无硬性时限；但每 2 年复核一次"
  last_review: 2026-09-10
  status: UNRESOLVED      # UNRESOLVED | CONFIRMED | REFUTED | PARTIAL
  evidence: []
```

**复核要求**：`risk_level: high` 的预测每 2 年复核一次；复核记录写入 `07-社区/03-会议与日志/`。

## 五、"预测被确认"不等于"纲领正确"

**重要的逻辑区分**：

- 预测被确认 ⇒ 纲领**未被推翻**（仅此而已）
- 预测被推翻 ⇒ 纲领**需要修正**（不一定是整体放弃）

这与 [证据等级标准](../../00-宪章/03-证据等级标准.md) 一致：验证的作用是**证伪**，不是确证。

**历史教训**：Weil 猜想（在有限域上的 RH 类比）在**函数域**情形被证明，给数域的 RH 带来了希望——但**六十多年过去，数域 RH 仍未解决**。类比的成功不构成对另一侧的证据。

## 六、AI 生成纲领的额外要求

若某纲领由 AI 参与生成（[红线五](../../00-宪章/02-诚实红线.md)），额外要求：

1. **必须**给出至少一条 `risk_level: high` 的预测
2. **必须**说明该纲领**不能**做什么（负面预测往往比正面更诚实）
3. **必须**经过至少一名人类专家复核预测的有效性（"这是否真的是有风险的断言？"）

**常见失败模式**（AI 生成的纲领极易出现）：

- 预测是重言式（"若纲领错误，则会出现不一致"）
- 预测无风险（"会有更多应用"）
- 预测不可判定（"最终会被理解"）
