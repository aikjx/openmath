# 04-桥接定理

> **桥接定理是本目录唯一的硬通货。**
> 纲领可以空谈，桥接定理不能——它们要么成立，要么不成立。

## 一、为什么桥接定理最重要

在 [00-问题定义](../00-问题定义/README.md) 的四维度中，"生成力"最有区分度；而**桥接定理是生成力的具体体现**：

- 基础统一纲领给出**语言**
- 结构统一纲领给出**分类**
- 桥接定理给出**新的事实**

**判断标准**：若去掉某个纲领后，某些**已知为真的定理**会变得无法陈述或无法证明——那么这个纲领有真实价值。桥接定理就是这个判断的检验点。

## 四、桥接定理的类型学

| 类型 | 特征 | 例 |
| --- | --- | --- |
| **对偶（Duality）** | 双向、反变等价 | Gelfand–Naimark、Spec 对偶 |
| **等价（Equivalence）** | 双向、共变 | Curry–Howard、Lambek |
| **表示（Representation）** | 一个对象由另一类对象完全决定 | Cayley、Tannaka–Krein |
| **指标定理（Index）** | 分析量 = 拓扑量 | Atiyah–Singer |
| **函子性（Functoriality）** | 保持结构的映射 | 同调函子、基本群 |
| **不变量（Invariant）** | 单向、有损 | 同调群、熵 |

**关键区分**：**对偶与等价是无损的**，不变量是**有损的**。混淆二者是常见错误（例如把"同调群"当作空间的完全描述）。

## 五、如何验证一条桥接

| 层级 | 验证方式 |
| --- | --- |
| L1 | 两侧的类型/结构声明一致；函子性检查 |
| L2 | 在具体例子上数值比对（如 Atiyah–Singer 在标准流形上的指标） |
| L3 | 符号验证：在具体情形的两侧计算结果一致 |
| L4 | **形式化**：Lean / Coq 中的对偶证明（mathlib 已有 Gelfand 对偶等相关工作的部分形式化） |
| L5 | 与文献一致性、多证明交叉 |

**本库最看重的**：桥接定理是 **L4 形式化的最佳候选**，因为它们结构清晰、结论强、且通常已有完整的教科书证明。

## 六、桥接 vs 统一（重要区分）

| | 桥接 | 统一 |
| --- | --- | --- |
| 范围 | 两个领域之间 | 全部数学 |
| 断言 | "这两个领域在谈同一件事" | "所有数学都可归约为 X" |
| 可证伪 | 强（找到反例即可） | 弱（几乎不可证伪） |
| 产出 | 具体定理 | 语言与组织 |

**本库立场**：**桥接是已验证的部分，统一是纲领。** 把纲领的成功归功于"统一"，往往是把桥接的成果记在了纲领的账上。

**具体例子**：Langlands 纲领的声誉来自**它的特例被证明了**（模性定理 ⇒ 费马大定理），而不是来自"纲领是对的"。后者至今未证。
