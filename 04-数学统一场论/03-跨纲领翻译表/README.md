# 03-跨纲领翻译表

> **本目录的诚实前提**：跨纲领翻译**大多是部分的、有损的**。
> 建立翻译表的价值，一半在于展示能翻译的部分，另一半在于**精确地标定不能翻译的部分**。

## 一、翻译的三种类型

| 类型 | 描述 | 例 |
| --- | --- | --- |
| **忠实翻译** | 存在定理保证双向保持 | 有限维向量空间 ↔ 对偶（需有限维） |
| **部分翻译** | 只在某子类上成立 | 空间 ↔ 交换代数（Gelfand 对偶，**仅对紧 Hausdorff**） |
| **类比翻译** | 结构相似但无严格对应 | 数域 ↔ 函数域（Weil 罗塞塔） |

**本库要求**：每条翻译必须标注类型。**把类比写成忠实翻译是严重错误**。

## 二、核心概念的跨纲领对照

### 2.1 "对象"在不同纲领中

| 纲领 | "数学对象"是什么 |
| --- | --- |
| ZFC | 集合（元素归属的层级结构） |
| 布尔巴基 | 集合 + 结构 |
| ETCS/范畴论 | 范畴中的对象，由态射关系决定 |
| 拓扑斯 | 内部语言中的项 / 层 |
| HoTT | 类型（= ∞-群胚） |
| 非交换几何 | 谱三元组中的代数 A |

**不可通约点**：ZFC 中"元素属于"是原始的、不可分析的；范畴论中"元素"是**派生概念**（态射 1 → X）。这不是同一概念的不同说法，而是**不同的本体论**。

### 2.2 "相等"在不同纲领中

| 纲领 | 相等的含义 |
| --- | --- |
| ZFC | 外延相等（相同元素） |
| 范畴论 | 同构（实践中）；严格相等在技术上存在但很少用 |
| HoTT | **等价即相等**（单价公理）；相等类型是路径空间 |
| 拓扑斯 | 内部语言中的相等 |

**关键点**：HoTT 的单价公理正是为了**消除**"同构但不相等"造成的样板代码。其他纲领中，同构与相等是**不同层级**的概念。

**不可通约点**：在 ZFC 中，"两个同构的结构是否相等"是**无意义的问题**（取决于编码）；在 HoTT 中，这是**有意义的**，且答案是"是"。

### 2.3 "空间"在不同纲领中

| 纲领 | 空间 = |
| --- | --- |
| 一般拓扑 | 集合 + 开集族 |
| Erlangen | 集合 + 变换群 |
| 代数几何 | 概形（素谱 + 结构层） |
| 拓扑斯 | 层范畴（广义空间） |
| HoTT | 类型（高阶群胚） |
| 非交换几何 | 谱三元组 (A, H, D) |

**经典对照定理**（部分翻译的范例）：

| 对应 | 定理 | 范围限制 |
| --- | --- | --- |
| 紧 Hausdorff 空间 ↔ 交换 C*-代数 | **Gelfand–Naimark** | 仅紧 Hausdorff |
| 仿射概形 ↔ 交换环 | **Spec-对偶** | 仅仿射 |
| 布尔代数 ↔ Stone 空间 | **Stone 表示定理** | 仅布尔代数 |
| 局部紧群 ↔ 群 C*-代数 | 部分 | 需调和分析结构 |

这些是**忠实翻译**（在各自范围内），是跨纲领翻译的黄金标准。

## 三、跨领域桥接字典（精选）

| 领域 A | 领域 B | 对应 | 类型 |
| --- | --- | --- | --- |
| 数论（伽罗瓦表示） | 表示论（自守形式） | L-函数相等 | 类比→部分（Langlands） |
| 数域 | 函数域 | Frobenius ↔ 素理想 | 类比（Weil） |
| 辛几何 | 复几何 | Fukaya 范畴 ↔ 凝聚层范畴 | **猜想性忠实**（同调镜像对称） |
| 逻辑（证明） | 计算（程序） | Curry–Howard | **忠实**（定理） |
| 逻辑 | 范畴 | Lambek 对应 | **忠实**（定理） |
| 统计模型族 | 微分几何流形 | Fisher 度量、对偶联络 | 忠实（构造性） |
| 几何（紧 Hausdorff） | 代数（C*-代数） | Gelfand 对偶 | **忠实**（定理） |
| 拓扑（空间） | 代数（同调群） | 函子性 | 部分（有损：同调不决定同伦型） |

## 四、翻译的信息损失（诚实标注）

| 翻译 | 损失了什么 |
| --- | --- |
| 空间 → 同调群 | 丢失了大量拓扑信息（同调相同的空间可以不同伦等价） |
| 空间 → C*-代数 | 在紧 Hausdorff 范围内**无损**（Gelfand 对偶），超出则失效 |
| 几何 → 范畴（Fukaya） | 构造本身极其困难；一般情形未完全建立 |
| 数论 → 表示论 | Langlands 对应是**猜想性**的，一般情形未证 |
| 经典数学 → 构造性数学 | 需要双重否定翻译等，结论强度减弱 |

## 五、翻译失败的模式（重要）

本库特别记录**翻译失败**的模式，因为它们界定了纲领的边界：

| 模式 | 例子 |
| --- | --- |
| **范围越界** | Gelfand 对偶用于非紧空间时失效（需改为局部紧 + 非交换推广） |
| **结构丢失** | 把几何问题代数化后，某些几何直觉不可恢复 |
| **强度降低** | 构造化后，定理的"存在性"变成"算法存在"，某些经典结论不再可得 |
| **循环依赖** | 用范畴论定义集合，又用集合定义范畴 |
| **编码依赖** | 结论依赖于具体编码，换编码后命题无意义 |
