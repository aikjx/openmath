# 07-评估矩阵

> **这不是排名。这是一张多维打分卡，每个分数背后必须有证据。**

## 一、评分规则

| 规则 | 说明 |
| --- | --- |
| 分数范围 | 0–5（整数） |
| 必须附证据 | 每个分数必须有具体的文献或事实支撑 |
| 可为空 | 证据不足时填 `—`，**不得猜测** |
| 复核 | 至少一名非本纲领评审者复核 |
| 更新 | 分数随证据更新，旧分数归档保留 |

## 二、四维定义（简要，详见 [00-问题定义](../00-问题定义/README.md)）

| 维度 | 一句话 |
| --- | --- |
| **表达力** | 能表述多少数学？ |
| **解释力** | 是否让既有结果更简单？ |
| **生成力** | 是否产出新定理/新预测？ |
| **可执行性** | 能否被机器检查？ |

## 四、读法与陷阱

### 陷阱 1：把矩阵当排名

**错误**：把所有列加起来得到一个总分，然后排序。

**为什么错**：四维是**独立**的，加权取决于使用目的。做形式化的人应该在意"可执行性"；做数论的人应该在意"生成力"。不存在普适权重。

**证据**：注意表中 Langlands（生成力 5，可执行性 1）与 HoTT（生成力 3，可执行性 5）——两者总分相近，但**完全不可互换**。

### 陷阱 2：认为表达力是核心

**错误**：表达力越强越好。

**为什么错**：几乎所有纲领都能达到接近满分的表达力（可以硬编码）。**表达力几乎没有区分度**。真正区分纲领的是生成力与可执行性。

### 陷阱 3：忽略抽象税

**错误**：只看四维不看抽象税。

**为什么错**：抽象税是**真实成本**——它表现为学习时间、证明膨胀、与具体计算的脱节。Motives 与 Langlands 的抽象税极高，这限制了它们的适用范围。

## 五、按使用场景的推荐（非排名，是"适配"）

| 你的目的 | 优先关注维度 | 适配纲领 |
| --- | --- | --- |
| **做形式化 / 机器验证** | 可执行性 | HoTT、C-H-L、ZFC |
| **找新定理 / 选题** | 生成力 | Langlands、镜像对称、Erlangen |
| **统一表述 / 写教材** | 表达力 + 解释力 | 范畴论、布尔巴基 |
| **分析"需要多强公理"** | 解释力（元层次） | 反推数学 |
| **跨领域迁移方法** | 解释力 + 生成力 | Weil 罗塞塔、C-H-L |
| **物理应用** | 生成力 + 实验可检验性 | 非交换几何、镜像对称 |
| **教学 / 降低门槛** | 低抽象税 | Erlangen、C-H-L、反推数学 |

## 六、本目录的自我评估（诚实）

OpenMath 本身是一个"元纲领"（提供比较框架），不是第 15 个统一纲领。按同一矩阵自我评估：

| 维度 | 分数 | 依据 |
| --- | --- | --- |
| 表达力 | — | **不适用**：本库不提供统一语言 |
| 解释力 | 3 | 提供了比较框架，但不产生数学洞见 |
| 生成力 | 1 | 不产生数学定理 |
| 可执行性 | 4 | 工具链纯标准库可运行；但覆盖率依赖内容填充 |

**诚实结论**：OpenMath 的价值是**基础设施性**的，不是数学性的。我们不假装它是数学纲领。
