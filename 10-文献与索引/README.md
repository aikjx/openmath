# 10-文献与索引

> 参考文献、交叉引用索引、知识图谱。**让知识之间的关系可被机器遍历。**

## 一、为什么需要单独的索引层

目录树是**树**，但数学知识是**图**：

- 一个定理同时属于多个域
- 一条公式被数十个定理引用
- 一个猜想蕴含另一个猜想

目录结构无法表达这些关系，因此本库用**显式索引**补充。

## 三、参考文献管理

**格式**：BibTeX（通用）或 YAML（本库原生）。

**必填字段**：

| 字段 | 说明 |
| --- | --- |
| `key` | 引用键，如 `titchmarsh1986` |
| `type` | book / article / preprint / misc |
| `title` | |
| `author` | |
| `year` | |
| `doi` / `arxiv` | **有则必须准确** |

**红线**：**不得编造 DOI、页码、年份。** 不确定时留空并标 `verified: false`。

## 四、引用方式

在条目中引用文献：

```yaml
provenance:
  sources:
    - type: doi
      value: "10.1090/..."
```

在 md 正文：`（Titchmarsh 1986, §2.1）`

**规则**：

- 引用必须**可解析**（在 `references.bib` 中有对应条目）
- 引用**必须带上具体章节/页码**（便于核查）
- 禁止"参见相关文献"式的模糊引用

## 五、交叉引用索引

`openmath index` 自动生成：

| 索引 | 内容 |
| --- | --- |
| 按 ID | ID → 文件路径 |
| 按域 | 域代码 → 条目列表 |
| 按标签 | 标签 → 条目列表 |
| 按证据等级 | L0–L6 → 条目列表 |
| 引用图 | 条目 → 被谁引用 |
| 术语索引 | 术语 → 出现位置 |

**生成**：

```bash
python -m openmath index
```

**2026-10-11 落地**：上面六张表此前只是承诺——`openmath index` 实际只写 `02-公式库/索引/index.json`，一张人读的表都没产过。现在由 `python -m openmath graph` 写进本目录的 `交叉引用索引/`，共**七张**（承诺的六张＋缺口检测）：`按ID.md`／`按域.md`／`按标签.md`／`按证据等级.md`／`引用图.md`／`术语索引.md`／`缺口检测.md`。每张表的行数由 `check_invariants` 的 `XREF-ROWS` 从图谱现推再比，渲染器不许自己证自己。

## 六、知识图谱

**节点**：条目（定义/公式/定理/猜想/反例/纲领）
**边**：

| 边类型 | 含义 |
| --- | --- |
| `generalizes` | A 是 B 的推广 |
| `specializes` | A 是 B 的特例 |
| `implies` | A 蕴含 B |
| `contradicts` | A 与 B 冲突 |
| `uses` | A 的证明用到 B |
| `related` | 相关 |
| `bridges` | 桥接（跨领域） |


**2026-10-11 实测**：节点＝记录（YAML）＋账本（仅 md）＋验证文档；已落地的边类型 7 种，枚数只读版面 `10-文献与索引/知识图谱/_版面/graph_face.txt`。上表里的 `contradicts` **没有实现**（图上 0 条：它要求记录里先有「与谁冲突」字段，而 schema 尚无该字段）——留着这一行是让读者分清「承诺」与「既有能力」。

**用途**：

- 影响分析：修改一条条目会影响谁
- 缺口发现：哪些重要概念没有定义就被使用
- 可视化：知识地图
- 导航：从已知到未知

## 七、缺口检测（本层的高价值功能）

自动检测：

| 缺口 | 检测方式 |
| --- | --- |
| 悬空引用 | 引用了不存在的 ID |
| 未定义概念 | `symbols` 中的概念无对应 `OM-D` 条目 |
| 孤立条目 | 没有任何入边或出边 |
| 证据倒挂 | 声称 L4 但无形式化脚本路径 |
| 术语不一致 | 同一概念多种写法 |

**这十三类判据已于 2026-10-11 落地**（此前写的是「计划中」）：`python -m openmath graph --check` 只判不写、有 DEFECT 即 rc=1；每类判据都被一枚指名变异体打破过，日志见 `10-文献与索引/知识图谱/_版面/graph_mutants_face.txt`。
