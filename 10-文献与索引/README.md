# 10-文献与索引

> 参考文献、交叉引用索引、知识图谱。**让知识之间的关系可被机器遍历。**

## 一、为什么需要单独的索引层

目录树是**树**，但数学知识是**图**：

- 一个定理同时属于多个域
- 一条公式被数十个定理引用
- 一个猜想蕴含另一个猜想

目录结构无法表达这些关系，因此本库用**显式索引**补充。

## 三、参考文献管理

**格式**：BibTeX（通用）或 YAML（本库原生）。

**必填字段**：

| 字段 | 说明 |
| --- | --- |
| `key` | 引用键，如 `titchmarsh1986` |
| `type` | book / article / preprint / misc |
| `title` | |
| `author` | |
| `year` | |
| `doi` / `arxiv` | **有则必须准确** |

**红线**：**不得编造 DOI、页码、年份。** 不确定时留空并标 `verified: false`。

## 四、引用方式

在条目中引用文献：

```yaml
provenance:
  sources:
    - type: doi
      value: "10.1090/..."
```

在 md 正文：`（Titchmarsh 1986, §2.1）`

**规则**：

- 引用必须**可解析**（在 `references.bib` 中有对应条目）
- 引用**必须带上具体章节/页码**（便于核查）
- 禁止"参见相关文献"式的模糊引用

## 五、交叉引用索引

`openmath index` 自动生成：

| 索引 | 内容 |
| --- | --- |
| 按 ID | ID → 文件路径 |
| 按域 | 域代码 → 条目列表 |
| 按标签 | 标签 → 条目列表 |
| 按证据等级 | L0–L6 → 条目列表 |
| 引用图 | 条目 → 被谁引用 |
| 术语索引 | 术语 → 出现位置 |

**生成**：

```bash
python -m openmath index
```

## 六、知识图谱

**节点**：条目（定义/公式/定理/猜想/反例/纲领）
**边**：

| 边类型 | 含义 |
| --- | --- |
| `generalizes` | A 是 B 的推广 |
| `specializes` | A 是 B 的特例 |
| `implies` | A 蕴含 B |
| `contradicts` | A 与 B 冲突 |
| `uses` | A 的证明用到 B |
| `related` | 相关 |
| `bridges` | 桥接（跨领域） |

**用途**：

- 影响分析：修改一条条目会影响谁
- 缺口发现：哪些重要概念没有定义就被使用
- 可视化：知识地图
- 导航：从已知到未知

## 七、缺口检测（本层的高价值功能）

自动检测：

| 缺口 | 检测方式 |
| --- | --- |
| 悬空引用 | 引用了不存在的 ID |
| 未定义概念 | `symbols` 中的概念无对应 `OM-D` 条目 |
| 孤立条目 | 没有任何入边或出边 |
| 证据倒挂 | 声称 L4 但无形式化脚本路径 |
| 术语不一致 | 同一概念多种写法 |

**这些检测是 `lint` 的扩展**，计划中（当前 L0 已含"引用可解析"检查）。
