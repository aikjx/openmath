## 一、三层结构

上游把"一个数学结果"拆成三层，本库要区分对待：

| 层 | 上游载体 | 本库看法 |
| --- | --- | --- |
| **家族（result family）** | `CONTENTS.md` 的 `**NNN. 标题.** 摘要` 行 + `overview.tex` 的 `\resultentry` | 主张的**单位**。372 个（A 段：两处各自解析出 372，交叉核对无孤立项） |
| **稿件（manuscript）** | `&emsp;[标题](preprints/…/x.pdf)` 行 | 家族的实现／ companion／ 替代证明。719 篇 |
| **形式化工件** | `lean/docs/NNN.md`（scope 说明）+ `lean/OAI/**.lean` + `lean/ComparatorChallenges/*.{json,lean}` | 唯一可机器检的一层，覆盖**不足全部家族**（见 03 号文档） |

学科分组只存在于 `overview.tex`（17 个 `\cataloguesection`，C 段）。`CONTENTS.md` 本身**不带学科**，
所以任何"按学科统计"都必须走 overview ↔ CONTENTS 的号连接——本库脚本做的正是这件事。

## 二、规模与其不均匀性（C 段）

- 372 家族 / 719 稿件 / 17 学科。每家族稿件数 **min 1 / max 14 / mean 1.93**（A 段）。
- 学科分布极不均衡：稿件最多的是 Probability and statistical mechanics（105 篇 / 29 家族），
  数论 58 篇 / 31 家族；家族数最多的是 Theoretical computer science（40）与 Combinatorics（37）。
- **形式化密度同样不均衡**：Mathematical logic 6/6、Combinatorics 33/37、TCS 34/40 接近全覆盖，
  而 Algebraic and complex geometry 只有 8/36，Topology 3/18。
  ⇒ "这个仓库的形式化程度"是一个**按学科差异极大**的量，任何全库平均数都会误导。
  （逐学科三列数字在 `by_subject.csv`，汇总行在 C 段 TOTAL。）

## 三、编号空洞：撤回不重编号（A + H/I4 段）

`CONTENTS.md` 解析出 372 个家族号，但号段是 **001..377**，空洞为
**045、061、070、123、163**（A 段）。这与 `history.md` 的记载一致：2026-10-07 因
"Weil 类代数性"一文的**符号错误**导致一个 stabilization-trace 消去失效，连带撤回 3 篇
（Weil classes / Kuga–Satake for K3 / rational Hodge conjecture for products of K3）。

**但两处对不上，本库记下而不替它编解释**：号段空洞是 **5** 个，`history.md` 只点名 **3** 篇撤回；
多出的 **123、163** 两个号在本库物理层探针里**没有**对应的"标题不在映射表内"目录
（I3b 的 3 个孤儿目录就是那三篇）。可能的情形是这两个号在更早的某次推送里连目录一起撤了
（本库只镜像了**当日 HEAD**，看不到历史），但**本库没有证据**，故只登记差异。

关键做法（值得本库学）：

1. **号不回收**：空洞永久保留，`overview.tex` 与 `CONTENTS.md` 都只列 372 项（A 段交叉核对
   "only in CONTENTS / only in overview = none"），编号不连续而总量连续。
2. **撤回件的目录仍在盘上，而且是"唯一没有标题对应物"的那 3 个**：H/I3b 段把 30 个"在盘上但不在
   映射表内"的 `preprints/` 目录**只用日期后缀做键**分了两类——
   **27 个**是同一标题的另一日期版本（上游改版后重新落目录，旧目录留着），
   **3 个**的标题在映射表里根本不存在，正是那三篇撤回件
   （`Algebraicity-of-Weil-classes-on-split-abelian-eightfolds-September-18-2026`、
   `Algebraicity-of-Kuga-Satake-Correspondences-for-K3-Surfaces-October-3-2026`、
   `The-rational-Hodge-conjecture-for-products-of-K3-surfaces-October-4-2026`；
   逐行标签在 `preprint_dirs.csv` 的 `why_not_in_map` 列）。
   ⇒ **"撤回"在物理层是可识别的，识别键不是"目录还在"（30 个都在），而是"标题不再被任何家族行引用"**。
   这条判据本库可以直接抄：`12-归档` 里区分"改版遗留"与"被撤回"要用的正是它。
   另：`Weil-classes-and-Hodge-classes-on-abelian-powers-September-30-2026` 被判为**旧版**而非撤回，
   因为同标题的 `…-October-6-2026` 正被家族 032 引用（`manuscripts.csv` 第 62 行、
   `preprint_dirs.csv` 第 740–741 行两行并列）——这正是 `history.md` 第 3 行那句
   "previously published editions remain accessible"与第 27 行"update references and version dates"
   在物理层留下的形状。
3. **撤回说明写在稿件自己的 README 里，而且本库已经把这三份取回来了**
   （`_镜像/withdrawal_notices/`，3 份共 **3,450 B**，逐份 md5 见 `PROVENANCE.md` §一）：
   三份标题都是 `[Withdrawal notice: …]`，都写 **"Withdrawn on October 6, 2026."**，
   第一份（Weil classes）**把错误算到了公式上**——逐字给出
   `I_new = I(f_1) − m = −2m ≠ 0`，并点明"这一步引用的 Eliashberg–Murphy 消去定理要求
   signed double-point count 为 0，故其前提不成立"；后两份只说"依赖同一处失效构造"。
   三份都留了一句关键界定："This withdrawal concerns the proof; it does not assert that
   the mathematical statement is false."（撤回的是证明，不是断言该命题为假）。
   目录里那个 PDF **已被换成 1 页通告**：三份分别是 **3,687 / 3,831 / 3,864 B**、
   `%PDF-1.4`、`/Count 1`、Producer = ReportLab（对照未撤回稿件的 `paper.pdf` ≈ 764 KB，
   见 `PROVENANCE.md` §三）；三份的 PDF **文件名还各不相同**（`paper.pdf` / `manuscript.pdf` /
   `hodge-conjecture-products-k3.pdf`）⇒ **"每篇稿件的正文都叫 paper.pdf"是不成立的假设**，
   任何按固定文件名抓正文的脚本都必须先列目录。
   原件没有删：README 用**钉死到旧 commit** 的链接指向它
   （`.../blob/adc7f1241b42e322a6451854ab7e4b4c146bf78a/preprints/Algebraicity-of-Weil-classes-…/paper.pdf`）。
   ⇒ 本库 `12-归档` 的"永不删除，只归档"是同一纪律，但**我们目前只在 `CHANGELOG.md` 记撤回，
   被归档文件自己不带"我为什么在这里"的说明**；上游的形状是三件套：
   **目录留 + 正文换成 1 页通告 + README 指向 pin 在旧 commit 的原件**。这条差距记在 §五 债表。
   另一条更狠的：上游把"证明失效"与"命题为假"**明确分开写**，而本库生命周期里
   `FALSIFIED` 一个状态同时承担这两种意思 ⇒ 引用本库条目的人无法从状态名判断
   被否定的是哪一层（本库需加限定字段，见 §六 债表第 4 行）。

## 四、物理层清点（H 段）与一次尺子事故

tracked 文件 **133,955** 个：

| `reasoning_traces/` | 11 | **10 份 PDF + 1 份同名 `.tex`**（`mezard-parisi-formula.tex`），与 README 表格列出的 10 条严格对齐 |

`lean/OAI` 的 12 万个 `.lean` **不能**读成 12 万个定理。H 段现在直接把这一层的形状数出来：
命名空间 **23** 个（Analysis **26,567**、NumberTheory **23,530**、Combinatorics **16,614**、
Geometry **14,057**、Probability **12,971**……最小 `Optimization` **2**），
扩展名**只有** `.lean`（**122,458**，即没有混入构建产物），而不同 basename 有 **113,334** 个，
重复最多的是 `Main.lean` **413** 次、`Model.lean` **248**、`Basic.lean` **138**
（典型路径 `lean/OAI/Algebra/AffineCancellation/BezoutFrame.lean`）

**文件数与定理数之间没有任何本库可引的换算**。
`ComparatorChallenges/*.json` 的 **416** 才是"可检声明容器"的张数（H 段两个数并列，不互相解释）。

### 尺子事故（A 段三把尺 + H/I0 段判决）

统计"稿件数"这件事在初版脚本上给出过**两个不同的答案**，而且两个都"看起来对"：

| 尺子 | 命中行数 | 抽出的不同路径 | 其中不存在于盘上的路径 |
| --- | --- | --- | --- |
| A：按 `&emsp;` 缩进标记数行 | 719 | —— | —— |
| B：非贪婪 `\((.*?)\)` | 719 | 719 | **1**（`…CAT(0` 被截断） |
| C：行尾锚定贪婪 `\((.*)\)$` | **718** | 718 | 0 |
| D：括号深度匹配（脚本采用） | 719 | 719 | 0 |

- B 数对了行数，却把**唯一一条路径里含括号的稿件链接**（家族 337，
  `preprints/Sharp-integral-fillings-in-CAT(0)-spaces-September-23-2026/paper.pdf`）截断成
  `…-in-CAT(0`，产出**一条盘上不存在的稿件路径**——行数正确、内容错。
- C 把唯一一条"链接后带散文"的行整行判为不匹配（家族 107 的
  `Complex-Matrix-Multiplication-Below-2.258-and-Rectangular-Bounds-…pdf) — secondary writeup`，
  `CONTENTS.md` 第 2661 行），**少计 1 篇**。
- 判决不靠数数，靠**与物理层求差**（H/I0 段）：只有 D 同时满足"行数 719＝路径 719＝盘上存在 719"。

本库纪律：**改尺子的那一轮必须同时跑一遍"抽出的键是否存在于对象集合"**，否则尺子越宽、假账越绿。

顺带一条对本库有用的安全性事实（H/I5 段）：全仓 133,955 条路径里含 `(` 的有 **15** 条，
**全部**住在那一个 `CAT(0)` 目录下（该目录含 15 个文件）；`lean/` 下 **0** 条。
⇒ 括号风险只发生在 preprints 一侧，且上游自己也只在这一处让字面括号进了路径。

## 五、扫描集与"拼写货币"（F 段）

F 段的扫描集在面上自报：**只扫 372 行家族行（166,741 B），不扫摘要、不扫 PDF/tex**。
在此之上，同一件事的两种拼写给出过**相反读数**：

| 探针 | 命中 | 探针 | 命中 |
| --- | --- | --- | --- |
| `erdos`（ASCII 折叠） | **0** | `ős` | **13** |
| `szemerdi`（ASCII） | **0** | `szemerédi` | **2** |
| `landau-siegel`（ASCII 连字符） | **0** | `siegel` | **2** |
| `mobius`（ASCII o） | **0** | `möbius`（U+00F6） | **1**：家族 071 |
| `obius`（子串，判 LaTeX `\"obius` 写法） | **0** | — | 上游没用 LaTeX 转义，用的是字面 `ö`；命中处是家族 071 标题行内的 "…conformal equivalence to another circle domain is **Möbius**…"（逐字） |

⇒ 四条纪律：①**0 命中只判决扫描集，不判决收藏**（面上已写死这句）；
②关键词表必须**同义词并列**并逐行印命中数，不能只印一个拼法；
③`pretentious` 这类带变音符的术语，探针要同时给 ASCII 与非 ASCII 两版——
本库 `06-AI自动化` 的语料扫描器目前只有一版，属同类盲区；
④**同一个数学术语在路径层也有多种拼法**（`_生成/manuscripts.csv`）：标题里都写 `CAT(0)`，
目录名却分别是 `…-in-CAT(0)-spaces-…`（家族 337）、`…-geometric-CAT0-action-…`（257）、
`…-geometric-CAT-0-action-…`（254）三种，**⇒ 不许从标题反推路径**，
任何"按标题找文件"的脚本都必须走映射表。

## 六、留给本库的四条债

| 债 | 现状 | 处置建议 |
| --- | --- | --- |
| 上游 `preprints/<dir>/README.md` 承载版本与撤回说明（H 段：772 份 README / 749 个目录；三份撤回通告已镜像到 `_镜像/withdrawal_notices/`，3,450 B） | 本库 `12-归档` 只在 `CHANGELOG.md` 记撤回，被归档文件自己不带"我为什么在这里"的说明 | 归档件补一行指向变更日志的说明，成本极低 |
| 上游每个家族号 ↔ `lean/docs/NNN.md` **严格同号**（B 段 "heads whose lean/doc number != family number: none"） | 本库 AKU 的 ID 与验证报告文件名当前不保证同号 | 若在 `05-验证中心` 引入家族/条目双层，直接抄这个同号约定 |
| 上游用 `overview.tex`（学科）↔ `CONTENTS.md`（稿件）两套结构各自成文，靠号连接 | 本库索引层同类风险：一处改号、另一处静默失效 | 交叉引用索引生成器要输出"only in A / only in B = none"这一行 |
| 上游把**"证明失效"与"命题为假"分开写**（三份撤回通告逐字："This withdrawal concerns the proof; it does not assert that the mathematical statement is false."） | 本库生命周期只有一个 `FALSIFIED`，读者无法判断被否定的是证明层还是命题层 | 给 `FALSIFIED` 加限定字段（`falsified: proof \| statement`），或在 `12-归档` 引入 `WITHDRAWN(proof)` 一档；引用外部撤回时**必须**带上这一区分 |
