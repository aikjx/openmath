# 外部仓库镜像 · openai/math

> 对 <https://github.com/openai/math>（OpenAI 内部模型产出的数学稿件与 Lean 证明工件集）的
> **只读镜像 + 结构化台账 + 口径分析**。
> 本目录**不承接**该仓库的任何数学结论作为本库证据；它只回答三个问题：
> **里面有什么、它的"已验证"是什么意思、我们能借哪一层工具。**

## 三、不做什么

- **不**把上游任何定理并入 `02-公式库`／`03-难题与猜想` 作为 `CANONICAL` 条目。
  它们在本库的最高合法状态是 `PROPOSED（外部主张，未经本库复算）`。
- **不**镜像 PDF/tex 全文。GitHub API 自报 `size = 822,061 KB`（≈822 MB，含全部 git 历史；
  该读数已记在 `_镜像/PROVENANCE.md` 抬头，未留 JSON）。本目录只镜像**目录与台账层**，
  现在总大小（2026-10-11 现测，两条口径并列，别混用）：按**块占用** `du -sk .` = **3,063 KB**
  （= 2.99 MiB；分项 `_镜像` 2,583 / `_生成` 384 / `_脚本` 40 KB），按**字节和** `os.walk`+`getsize`
  = **2,627,385 B**（= 2,566 KiB）。除以抬头那个 822,061 KB：块口径 **0.373%**、字节口径 **0.312%**
  ——同一个"占比"随币种差 0.06 个百分点，所以引用时必须连币种一起抄，且**别当成"压缩率"**。
  本行改完会让 5 份 `.md` 的和再挪一点，因此这两个数都只作**当时读数**，引用前现跑那两条命令。
  需要单篇稿件或 Lean 侧文件时按 `04-下载与复核操作手册.md` 定向抓取（实测 1–21 s / 目录）。
- **不**改写 `_镜像/` 里任何文件；抓取事故一律记录在 `PROVENANCE.md` §二（目前 3 枚：①同名覆盖、②截断未报错＋其 ②b 复测、③`-l` 按需取回）。
- **不**替上游判定"已证明"。本库连一次 `lake build`／`comparator` 都没跑过（04 号文档 §五 未测清单）。
