# 12-归档

> **永不删除，只归档。**
> 本目录存放：废弃的纲领、被取代的旧版本、历史决策、以及所有"曾经相信过"的东西。

## 一、为什么永不删除

| 理由 | 说明 |
| --- | --- |
| **引用完整性** | 删除会破坏其他条目的引用 |
| **历史教训** | 被放弃的路线说明了"为什么此路不通" |
| **可追溯性** | 需要能回答"这个结论是怎么演变的" |
| **纠错能力** | 若新证据推翻了"已解决"的结论，需要能回溯 |

**因此**：本库**不存在删除条目的流程**（[宪章第四条](../00-宪章/01-宪章总纲.md)）。只有状态变更与归档。

## 二、目录结构

```
12-归档/
├── README.md              本文件
├── 废弃纲领/               被放弃或已过时的研究路线
├── 旧版本/                 条目的历史版本（主要由 Git 承担）
├── 历史决策/               被取代的决策记录
└── 事件/                   重大事故与复盘
```

## 三、什么该归档

| 情形 | 处理 |
| --- | --- |
| 条目被更好的表述取代 | 标 `DEPRECATED`，保留在原位（不移动） |
| 纲领停止发展 | `current_status: historical`，保留在 [04-数学统一场论](../04-数学统一场论/README.md) |
| 纲领被放弃 | 移入 `废弃纲领/`，保留完整记录 |
| 决策被新决策取代 | 移入 `历史决策/`，注明被谁取代 |
| 内容整体迁移 | 旧位置留重定向说明 |

## 四、归档的元数据

归档条目必须保留：

```yaml
archived:
  date: YYYY-MM-DD
  reason: <为什么归档>
  superseded_by: <替代条目 ID，可空>
  archived_by: <操作者>
  retrievable: true     # 是否仍可被引用
```

**关键**：`retrievable: true` 意味着**归档条目仍可被引用**，只是不再推荐。

## 五、与 Git 的关系

| 内容 | 存放 |
| --- | --- |
| 条目的版本历史 | **Git**（不复制到本目录） |
| 被弃用的**完整条目** | 本目录 |
| 决策记录 | 本目录 + `07-社区/03-会议与日志/` |

**Git 负责版本，本目录负责"已经不推荐但仍有价值"的内容。**
